# 工具执行与权限

[文档索引](README.md) · [项目首页](../README.md)

## 执行边界

工具结果（包括读取到的文件内容）会发送给用户配置的模型。工作区文件工具只能读写当前绑定目录（项目内会话共享），不能访问其他项目、独立会话目录、模型配置或密钥；当前没有 Shell、跨应用控制或外部目录权限。旧版自带的“只能聊天”默认指令会自动更新，用户自定义指令保持原样。

- Agent 循环支持流式工具参数、多步执行和同一步多个工具，工具结果以对应的 `tool_call_id` 回传模型；只有模型流完整结束后才会执行工具。
- 每轮最多 200 次模型调用、每步最多 8 个工具，顺序执行；最后一次模型请求若仍要求工具，会停止并说明原因。工具失败作为错误结果交给模型处理；流式协议或持久化错误会终止本轮。
- 工具执行前保存意图、执行后保存结果；聊天中可展开查看参数和结果。停止会取消网络请求并阻止后续工具；已提交的写入保留，不自动回滚。重启后不自动重放工具，执行中断且无结果的调用会标为结果未知。

## 工作区文件工具

- 内置 `find_files`、`list_files`、`read_file`、`write_file`、`search_file_content`、`read_file_lines`、`edit_file`，仅访问当前会话绑定的工作区（项目内共享）。读写 UTF-8 文本，不再限制单文件 64 KiB；列表每页最多 200 项，文本搜索每页最多扫描 200 个文件并返回 100 处匹配。每次读取最多 2000 行或 50 KiB，返回 nextOffset/nextColumn 供 read_file 接续读取，超长单行也可分段。截断明确标记；拒绝越界路径与符号链接。写入自动建父目录，以临时文件和重命名完整覆盖目标文件。
- `edit_file` 优先使用 `edits: [{oldText, newText}, ...]`（1–32 项），兼容原来的顶层 `oldText/newText`，两种格式不能混用。所有编辑匹配同一份原文，要求唯一且不重叠，全部校验后一次写入；失败不会部分修改。只兼容 CRLF/LF 差异，不进行模糊匹配；保留 UTF-8 BOM、未修改区域的原始换行以及文件末尾有无换行，新内容沿用原文件主要换行格式。文件仍需整体读取，但一次批量编辑只读取一次原文。
- Agent 修改或覆盖已有文件前，必须在本轮运行中通过 `read_file/read_file_lines` 成功读取；本轮成功写入也更新已知版本。搜索和内部读取不授予修改资格，未读取时只能创建新文件。存储层在共享的文件串行队列中检查 SHA-256 内容版本，拒绝过期修改；版本与修改前后文本仅供本地校验和界面展示，不进入模型回执。每轮重新建立读取记录。同一路径在多个适配器实例间共享队列，不同文件可以并行；该队列不锁定应用外的其他进程。
- 文件检索支持 `find_files`（按名称或 glob 查找，不读取内容）和增强的 `search_file_content`：`glob` 支持 `*`、`**`、`?`，内容搜索可设置 `ignoreCase`、`context`（前后各 0–5 行）和 `limit`（1–100）。跳过隐藏文件和符号链接；片段附行号、列号，长行以匹配位置为中心截取。每页最多检查 200 个文件、100 批目录；即使本页没有匹配，只要 `truncated` 为 true 就可保持参数、用 `nextCursor` 续查。游标仅当前运行有效，保留最近 32 个续查位置；续查同一文件时内容变化会明确要求重搜，目录变化时不保证整个搜索是同一时刻快照。`list_files` 同样可用 `nextOffset` 接续目录列表。

## 代码执行与编排

- **代码沙箱**：`execute_code` 在独立 QuickJS Runtime 中运行同步 JavaScript，支持 JSON 输入、结构化结果和日志；固定 2 秒预算、32 MiB Runtime 分配限额及输出限制，可取消。聊天、团队与只读模式均可使用，无文件、网络或宿主工具访问。当前为同进程解释器隔离，详见[使用方式与边界](code-sandbox.md)。
- **工具编排**：`orchestrate` 支持异步 JavaScript，通过 `tools` 调用已授权的文件、网页、Skills 和 MCP 工具，处理并发、依赖与数据后统一返回汇总。保留完整子调用回执、原有权限和审批，支持取消与中断恢复；当前不支持后台执行单元或嵌套 Team 控制。详见[异步工具编排](code-sandbox.md#异步工具编排)。

## 工具结果与错误

- MCP 已接受的完整工具结果保存到现有会话回执中，不再先按 48,000 字符截断。模型请求仍经过上下文预算投影，超长结果以首尾预览和定位信息替代，通过 `read_tool_result` 分页补读；不重复执行远程操作。网络层限制和远端服务自身截断仍有效；完整结果目前仍会占用会话内存和磁盘，并非流式文件存储。
- 工具失败统一保留 `error` 文本并返回稳定 `code`、`recovery` 和可选 `details`。参数、权限、资源、配置、HTTP 鉴权/限流、超时等在知道原因的工具或适配层分类，未知异常返回 `UNKNOWN_ERROR` 并保留原始描述，不按文案猜测原因。文件诊断在 `details` 中携带 `path` 和 1 起始 `editIndex`；已有历史回执保持原样。恢复建议不授权自动重试。
- MCP 的 `isError` 回执和代码沙箱的失败状态会正确记为失败；MCP 原始错误结果保留在 `details.result`，沙箱/编排保留 `status`、日志和子调用记录。`USER_DENIED`、`CANCELLED`、`NOT_EXECUTED` 与 `OUTCOME_UNKNOWN` 分别表示拒绝、停止等待、未执行和中断后结果未知，远程取消不代表副作用撤销。持久化失败仍终止本轮，不转成可继续执行的普通工具错误。
- **重复调用提醒**：同一工具与规范化参数连续调用达到 3、5、8 次时，保存提示供模型调整方法；失败调用也计数，用户追加指令会重置计数，等待员工和用户表单不计数。不会自动重放或阻止合法工具操作。

## 回执展示与修改快照

- 聊天执行过程按正文分组，thinking 显示单行预览；仅含一个工具的分组直接显示工具行。聊天、Team 和编排子调用共用详情展示：文件带行号、修改区分替换前后、搜索按文件分组、目录区分类型、网页显示正文与来源、代码执行分离返回值与日志，计划与表单显示步骤及已提交回答，生成图片显示本地预览。未知工具保留结构化字段和原始记录。
- 新的文件写入与编辑回执显示统一差异卡片：文件名、实际增删行数、修改前后行号、红绿背景与 `+ / −` 标记，支持复制和分页查看完整差异。每次成功写入记录当次改动及前后 3 行上下文，仅作为界面元数据保存，不加入模型的工具结果；旧记录缺少当次基线时保留原有内容预览，不从当前文件猜测历史差异。
- 回答结束、失败或停止后，在末尾展示“本轮修改”：按路径比较本轮首次成功修改前与最后成功写入的内容，包含编排子调用，已改回原文的文件不计入净变化，新建空文件仍展示。可展开文件清单和分页差异；汇总快照随回执持久化，重启后不依赖当前文件，不进入模型上下文。旧回执没有本轮快照时不推算汇总；用户审阅用的原始恢复基线保持独立。
- 工具行仅显示简短预览，完整的本次回执在详情面板按结果、参数、日志和原始记录分页查看，正文每段最多 8000 字符，列表每页最多 30 项；界面分页和工具实际截断分别提示。查看回执不重新执行工具、不重新读取文件。展开状态与页码在当前消息或 Team 尝试内保留，收起外层或接收流式更新后不丢失阅读选择；主动展开过程后，回答完成不会强制收起。重新加载历史使用紧凑默认状态。

## 交互、图表与文件交付

- Agent 可调用 `request_user_input` 显示原生文字、数值、单选和多选表单，提交后继续执行；中断的表单可从工具记录重新填写并继续。`update_plan` 显示待办、进行中和完成状态。
- `publish_data_view` 支持表格、柱状图、折线图、瀑布图及指标卡。数据经过校验并保存于工具回执；显示来源、支持表格排序与 CSV 导出，不执行模型生成的脚本。
- **文件交付**：`present_files` 校验当前工作区内 1–8 个普通文件，成功工具回执在回答末尾显示文件卡片；点击进入现有预览、分享和导出。卡片引用当前文件，不保存文件内容副本；普通分支使用独立工作区，项目分支沿用共享工作区；文件不存在时显示错误。
- 配置支持 OpenAI 兼容图片接口的模型后启用 `generate_image`，可生成或编辑附件/工作区图片；调用前确认，结果展示在回答中并保存到工作区。未指定图片模型时不提供此工具；图片接口计费不纳入聊天 Token 账本。

## 远程 MCP

- **设置 → MCP 服务**：配置 HTTPS Streamable HTTP 服务，支持 Bearer Token、无鉴权、OAuth 公共客户端登录。OAuth 使用资源/授权服务器发现、PKCE S256、state 校验、资源绑定及刷新令牌；支持动态客户端注册，也可填写服务方提供的公共客户端 ID。回调地址为 `tinybot-harmony://oauth/callback`，服务需允许该回调；登录期间保持应用进程，可粘贴回调链接。凭据保存于 Asset Store。支持初始化、会话 ID、工具分页、JSON/SSE、连接测试及每个会话独立启停；工具可搜索、按需加载 schema，实际调用逐次确认。取消不承诺撤销远程副作用；未知结果不自动重试。当前不支持 stdio、旧 HTTP+SSE、服务端 sampling/elicitation 或资源订阅。
