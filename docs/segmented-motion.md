# 分段选择动效

`common/Widgets.ets` 的 `Segmented` 统一用于侧栏的对话/已归档、记忆/模板/MCP，以及设置/用量/备份。

参考 RubberSegment 的动效描述，用 ArkUI Animator 独立实现：前沿先到达目标，后沿跟随收拢，再向内轻压约 2 vp 后回正，完整周期 420 ms。不引入 React 或 motion，不移植示例源码。原有点击回调、页面切换和各处的配色、字体、尺寸、圆角、阴影保持原设计；侧栏通过尺寸参数保留其胶囊外观。

动画只作用于底块两条边，文字和点击区域不移动。连续切换从当前形状继续，旧动画通过代次隔离；销毁时取消动画，尺寸或选项数变化时重新定位。重复生成相同尺寸的标签数组不会打断动画。这里仅接入切换动效，不增加拖动选择手势。

`SegmentedMotion.test.ets` 覆盖双向拉伸、跨项切换、准确落位、快速反向连续性、轨道边界，以及同项/空几何稳定性。
