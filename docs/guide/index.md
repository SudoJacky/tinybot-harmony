## 界面地图

聊天页只有四个可操作区域，指南中的位置描述都以此为准：

| 区域 | 内容 |
| --- | --- |
| 标题栏 | 左侧打开会话列表；中间显示项目名、会话名、服务商图标与模型，点击切换模型；右侧是更多菜单与新建对话 |
| 会话列表 | 项目分组与“普通聊天”、搜索框、“对话 / 已归档”切换、新建项目、新建对话、底部设置入口 |
| 消息区 | 每轮的工作流状态线、正文、工具回执、“本轮修改”、预览与文件卡片、消息操作栏 |
| 输入区 | 加号（附件与工作区等）、上下文圆环、推理强度、待发送徽标、麦克风、发送或停止 |

更多菜单里的入口按会话生效：工具范围、工作区文件、应用内浏览器、分支关系、创建分支、分享对话、导出为 Markdown，最后是设置。

## 三类文档的分工

| 层次 | 回答的问题 | 典型内容 | 入口 |
| --- | --- | --- | --- |
| 指南 | 这个功能是什么、在哪点、有什么限制 | 操作步骤、界面行为、边界与默认值 | 本页 |
| 架构 | 内部由谁实现、数据怎么流动 | 模块职责、生命周期、持久化与协议 | [架构总览](/internals/overview) |
| 参考 | 精确的清单、字段与取值 | 工具参数、回执错误码、设置项、磁盘布局、词条 | [工具参考](/reference/tools) |

指南只描述你观察得到的行为，不解释内部实现；需要追代码时从架构页末尾的“代码入口”表或[代码地图](/internals/code-map)进入。参考页用于查具体字段与错误码，遇到报错先看[回执与错误](/reference/receipts)。

## 术语约定

| 术语 | 在本站的含义 |
| --- | --- |
| 会话（Session） | 一条聊天记录及其草稿、附件、引用、模型选择、队列和工作区归属 |
| 项目（Project） | 一组共享工作区与项目说明的会话容器 |
| 工作区（Workspace） | 会话可读写的沙箱目录；项目内会话共用同一个目录 |
| 分支（Branch） | 从某条消息复制的会话副本，保留原会话不变 |
| 引用（Reference） | 把其他会话或文件选段的文字快照带进当前消息 |
| 待发送输入 | 运行中追加的指令或排队的后续任务，按会话保存 |
| 审阅基线（Baseline） | 文件首次被修改前保存的原文，用于差异与恢复 |
| 记忆（Memory） | 跨轮次保留的背景资料，分全局与当前会话两种范围 |
| 模型服务（Provider） | 一份包含协议、地址、密钥、模型列表与启停状态的配置 |
| 回执（Receipt） | 工具调用保存下来的参数、结果、差异与错误记录 |

## 本版范围

文档对应 1.0.3 / 1000003，目标设备为 HarmonyOS API 26 手机。当前明确不包含：

- Shell、跨应用控制或任意外部目录访问；文件工具只能读写当前绑定的工作区。
- 跨项目移动会话、Agent Graph 与工作流编排、常驻后台 Agent、对话实时云同步。
- 密钥导出：备份与导出都不含模型服务与 MCP 凭据。
- 内置免费模型额度；模型可用性与费用由你配置的服务决定。

## 限制与默认值写在哪

指南只重复与操作直接相关的限制，完整取值集中在参考部分的几页：

- 工具参数、分页、截断与错误码：[工具参考](/reference/tools)、[回执与错误](/reference/receipts)。
- 开关默认值、字段含义与可调范围：[设置项](/reference/settings)。
- 磁盘目录、备份内容与导出范围：[磁盘布局](/reference/storage)。

数字类限制（附件大小、队列条数、上下文预算、备份体积等）以代码为准；指南写下的数值与当前版本一致，改动后会同步更新。
