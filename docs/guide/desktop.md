# PC 与 2in1

这页说明 Tinybot 在 HarmonyOS 2in1（PC、二合一）设备上的窗口约束、分栏断点、键鼠操作与布局恢复方式；手机与平板的布局规则见[文件与工作区](/guide/files#平板与窗口布局)。

## 设备识别与窗口

| 项目 | 行为 | 依据 |
| --- | --- | --- |
| 设备判定 | `deviceInfo.deviceType` 为 `2in1` 时启用桌面布局；`phone`、`tablet` 沿用原有布局，连接键盘或鼠标不会改变判断 | `common/DeviceForm.ets` |
| 最小窗口 | 360 × 420 vp；API 22 及以上直接按 vp 设置，更低版本换算为 px 后设置 | `entryability/EntryAbility.ets` |
| 布局切换 | 以窗口宽度为准，不按设备或屏幕尺寸固定；小于 720 vp 时使用单栏 | `model/WorkbenchLayout.ets` |
| 对话框宽度 | 窗口达到 600 vp 时取窗口宽度的 70%，限制在 440–800 vp；更窄的窗口沿用系统默认宽度 | `WorkbenchLayout.dialogWidth()` |

平台拒绝最小窗口限制时只在诊断日志中记录，不阻止继续使用；窗口小于限制时布局仍按实际宽度降级。

## 工作表布局

720 vp 及以上进入工作表布局，会话栏、对话与侧栏按可用宽度重新分配：

| 窗口宽度 | 布局 |
| --- | --- |
| 小于 720 vp | 单栏，会话列表以覆盖式抽屉打开；文件、预览与浏览器占满内容区 |
| 720–795 vp | 会话栏 224–360 vp（默认 252），可收起为 56 vp 图标栏；对话至少保留 440；侧栏不并排，占满内容区 |
| 796 vp 及以上 | 侧栏可与对话并排；会话栏按剩余空间展开或收起为图标栏，对话仍至少保留 440 |

- 窗口变窄时，会话栏先收缩到 224 vp 下限，再收起为图标栏；侧栏在宽度不足时改为占满内容区，而不是继续挤压对话。
- 侧栏并排时，标签栏右侧提供“最大化侧栏 / 恢复并排显示”；最大化后侧栏占满内容区，对话隐藏，标签栏继续提供恢复按钮。
- 窗口不足 796 vp、侧栏占满内容区时，标签栏改为紧凑形式：显示当前面板名与下拉切换，只关闭当前标签，另提供添加入口。
- 标题栏固定 48 vp：窗口不足 720 vp、没有常驻会话栏时，左侧显示会话列表与新建对话；中间是项目名与会话名，右侧是搜索、展开输入、更多操作与侧栏开关。

## 拖动与布局记忆

| 操作 | 行为 |
| --- | --- |
| 悬停分隔线 | 显示左右调整光标 |
| 拖动分隔线 | 在会话栏 224–360 vp 与侧栏 300 vp–窗口 70% 的范围内调整；始终为对话保留至少 440 vp |
| 双击分隔线 | 恢复该栏默认宽度；聚焦分隔线后按 Enter 同样生效 |
| 窗口变窄 | 当前布局按新宽度收缩，不覆盖已保存的宽度 |
| 重启或重新打开窗口 | 恢复上次的宽度与收起状态 |

布局写入 `tinybot-ui` 偏好库，与会话和模型服务分开：

| 键 | 含义 |
| --- | --- |
| `pc.historyCollapsed` | 会话栏是否收起为图标栏 |
| `pc.historyWidth` | 会话栏宽度，0 表示使用默认值 |
| `pc.detailWidth` | 侧栏宽度，0 表示使用默认值 |

写入失败不会改变当前界面，只在诊断日志中记录。

## 命令面板

在 2in1 上按 **Ctrl+K** 打开命令面板，替代手机与平板上展开会话搜索的行为。窗口聚焦、数据就绪且没有其他弹层时可用。

| 输入 | 结果 |
| --- | --- |
| 直接输入 | 命令与会话混合列表；先列命令，再列标题匹配与消息正文匹配，最多 24 项；未输入时只列命令 |
| 以 `>` 开头 | 只看命令 |
| ↑ / ↓ | 移动选中项；鼠标悬停也会改变选中项 |
| Enter | 打开选中项 |
| Esc | 关闭面板 |

命令包括：新建对话（在项目内时建在当前项目）、新建普通对话（仅在项目内出现）、搜索对话、工作区文件、应用内浏览器、打开或关闭侧栏、记忆与工具、技能、生活看板、设置、键盘快捷键。打开会话时若命中消息正文，会定位到该消息并高亮。

侧栏占满内容区时，聊天快捷键暂停，只有 Ctrl+K 仍可打开命令面板。

## 鼠标与右键

- 会话行、消息，以及记忆、MCP 服务与工作区文件列表支持右键打开操作菜单；可滑动的行同时显示“更多操作”按钮。
- 会话行悬停时显示浅色底；没有编辑权限的会话不显示菜单，也不会响应悬停高亮。
- 消息正文仍支持系统文字菜单；右键与长按打开的是同一份消息操作。
- 消息区与列表在 2in1 上显示滚动条，回弹效果关闭；对话左右留白固定为 24 vp。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| Ctrl+N | 新建对话 |
| Ctrl+K | 搜索对话或命令 |
| Ctrl+B | 展开或收起会话列表 |
| Ctrl+, | 设置 |
| Ctrl+Shift+F | 工作区文件 |
| Ctrl+Shift+L | 聚焦消息输入框 |
| Ctrl+O | 添加文件附件 |
| Ctrl+Shift+E | 展开输入 |
| Ctrl+Shift+J | 查看最新消息 |
| Ctrl+Shift+S | 停止生成 |
| F1 | 键盘快捷键说明 |
| Ctrl+Enter / Alt+Enter | 在输入框中换行 / 发送 |

快捷键说明按对话、导航、输入分组，可输入功能名或键位搜索；2in1 上 Ctrl+K 的说明写作“搜索对话或命令”。

## 窗口、后台与通知

- 最小化会隐藏窗口。窗口不可见时，正在进行的长回答继续传输；完成通知按后台规则发送，与手机熄屏一致。
- 窗口隐藏时立即触发一次草稿保存，不等 800 ms 防抖；保存失败仍以输入区上方的错误条提示。
- 退出应用与手机相同：已保存的会话、草稿与工作区保留，待发送队列在下次启动时保持暂停。

## 与手机平板的差异

| 项目 | 2in1 | 手机与平板 |
| --- | --- | --- |
| 工作表断点 | 720 vp | 840 vp |
| 会话栏范围 | 224–360 vp，默认 252 | 264–420 vp，默认 280 |
| 侧栏并排 | 窗口至少 796 vp | 窗口至少 840 vp |
| 搜索快捷键 | Ctrl+K 打开命令面板 | 展开会话搜索 |
| 列表密度 | 行高与按钮更紧凑，悬停高亮 | 长按打开菜单，滑动行 |
| 拍照 | 依次选择可用的后置、前置或第一个摄像头 | 固定使用后置摄像头 |
