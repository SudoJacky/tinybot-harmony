# 大屏工作台（平板与 2in1）

平板与 2in1 共用同一套大屏工作台：会话栏、对话与侧栏按窗口宽度重新分配，命令面板、会话详情与旁聊只在这样的设备上提供；手机仍使用单栏与覆盖式抽屉。这页说明窗口约束、分栏断点、拖动与布局记忆、命令面板、会话详情和键鼠差异；手机与平板共用的文件布局见[文件与工作区](/guide/files#大屏与窗口布局)。

## 设备判定与窗口

| 项目 | 平板与 2in1 | 手机 |
| --- | --- | --- |
| 设备判定 | `deviceInfo.deviceType` 为 `tablet` 或 `2in1` 时启用大屏工作台，与窗口宽度无关 | 其余设备使用手机布局 |
| 最小窗口 | 仅 2in1 设置 360 × 420 vp；API 22 及以上按 vp，更低版本换算为 px | 由系统管理 |
| 布局切换 | 平板 840 vp 起进入工作表；2in1 从 720 vp 起进入工作表 | 单栏，会话列表以抽屉打开 |
| 对话框宽度 | 任一设备窗口达到 600 vp 时取窗口宽度的 70%，限制在 440–800 vp | 沿用系统默认宽度 |

2in1 上平台拒绝最小窗口限制时只在诊断日志中记录，不阻止继续使用；窗口小于限制时布局仍按实际宽度降级。

## 分栏与侧栏

| 项目 | 平板 | 2in1 |
| --- | --- | --- |
| 工作表断点 | 840 vp | 720 vp |
| 会话栏范围 | 264–420 vp，默认 280 | 224–360 vp，默认 252 |
| 侧栏并排 | 窗口至少 840 vp | 窗口至少 796 vp |
| 图标栏宽度 | 56 vp | 56 vp |
| 分栏记忆 | 仅本次运行 | 写入 `tinybot-ui`，重启恢复 |

两种设备都遵守同一组下限：对话至少保留 440 vp，侧栏至少 300 vp、最多为窗口宽度的 70%，默认占 40%。

- 窗口变窄时，会话栏先收缩到下限，再收起为只显示新建对话、搜索与设置的图标栏；侧栏在宽度不足时改为占满内容区，而不是继续挤压对话。
- 标题栏左侧的会话栏按钮在展开、图标栏与覆盖式抽屉之间切换；图标栏本身不再提供展开、文件与工具按钮，文件与浏览器从更多菜单或命令面板进入，记忆与工具从命令面板或设置进入。
- 会话列表的搜索结果在大屏上显示消息摘要；筛选菜单的“已归档”带有条目数。设置入口固定在会话栏底部。
- 侧栏并排时，标签栏右侧提供“最大化侧栏 / 恢复并排显示”；窗口至少 840 vp 时可用。最大化后侧栏占满内容区，对话隐藏，标签栏继续提供恢复按钮。
- 窗口不足 840 vp 且侧栏占满内容区时，标签栏改为紧凑形式：显示当前面板名与下拉切换，只关闭当前标签，另提供添加入口。
- 窗口至少 1240 vp 且打开“会话详情”或没有任何侧栏标签时，侧栏以 320 vp 浮动卡片显示，避免遮住输入区。

## 拖动、自动收起与布局记忆

| 操作 | 行为 |
| --- | --- |
| 悬停分隔线 | 2in1 显示左右调整光标 |
| 拖动分隔线 | 在会话栏与侧栏各自范围内调整；始终为对话保留至少 440 vp |
| 拖到最窄再超出 | 会话栏越过下限约 32 vp 后松手，收起为图标栏；侧栏越过下限约 32 vp 后松手，关闭侧栏。接近收起时分隔线加粗提示 |
| 拖动中取消 | 恢复拖动前的宽度，不收起 |
| 双击分隔线 | 2in1 上双击，或聚焦分隔线后按 Enter，恢复该栏默认宽度 |
| 窗口变窄 | 当前布局按新宽度收缩，不覆盖已保存的宽度 |
| 重启 | 2in1 恢复上次的宽度与收起状态；平板回到默认宽度 |

2in1 的布局写入 `tinybot-ui` 偏好库，与会话和模型服务分开：

| 键 | 含义 |
| --- | --- |
| `pc.historyCollapsed` | 会话栏是否收起为图标栏 |
| `pc.historyWidth` | 会话栏宽度，0 表示使用默认值 |
| `pc.detailWidth` | 侧栏宽度，0 表示使用默认值 |

写入失败不会改变当前界面，只在诊断日志中记录。平板不写这些键。

## 命令面板

在平板与 2in1 上按 **Ctrl+K**，或点标题栏的搜索按钮，打开命令面板；手机上仍是展开会话搜索。窗口聚焦、数据就绪且没有其他弹层时可用。

| 输入 | 结果 |
| --- | --- |
| 直接输入 | 命令与会话混合列表；先列命令，再列标题匹配与消息正文匹配，最多 24 项；未输入时只列命令 |
| 以 `>` 开头 | 只看命令 |
| ↑ / ↓ | 移动选中项；鼠标悬停也会改变选中项 |
| Enter | 打开选中项 |
| Esc | 关闭面板 |

命令包括：新建对话（在项目内时建在当前项目）、新建普通对话（仅在项目内出现）、搜索对话、工作区文件、应用内浏览器、打开或关闭侧栏、记忆与工具、技能、生活看板、设置、键盘快捷键，以及满足条件时的“新建旁聊”。打开会话时若命中消息正文，会定位到该消息并高亮。

侧栏占满内容区时，聊天快捷键暂停，只有 Ctrl+K 仍可打开命令面板。

## 会话详情与旁聊

大屏的“更多操作 → 会话详情”打开侧栏的详情页：提供工作区文件、应用内浏览器、新建旁聊入口，并列出当前会话的旁聊与最近产物。最近产物取最近 12 条消息中的文件交付与生成图片，按路径去重后最多 4 项。

- 旁聊从当前主会话拆出，沿用主会话的工作区与模型，但工作区只读，只提供读取文件与会话引用的工具。
- 旁聊有独立的消息、草稿与停止状态，不等同于主会话的分支，也不会出现在会话列表、搜索、命令面板或引用候选中。
- 入口包括侧栏“新建旁聊”、标签栏的“+”菜单与命令面板；需要主会话至少有一条消息且未归档。
- 完整回答可以“带回主会话”，作为会话引用进入主会话；删除旁聊会二次确认，删除主会话会一并删除它的旁聊。

具体规则、持久化与限制见[对话与消息](/guide/chat#旁聊)。

## 输入框补全与快捷键

平板与 2in1 上，输入 `$`、`@`、`/team` 或 `/compact` 出现建议列表时，可用 ↑ / ↓ 选择、Enter 确认、Esc 关闭；这些键只在没有 Ctrl、Alt、Shift 或输入法组合时接管。

| 快捷键 | 作用 |
| --- | --- |
| Ctrl+N | 新建对话 |
| Ctrl+K | 搜索对话或命令 |
| Ctrl+B | 展开或收起会话列表 |
| Ctrl+, | 设置 |
| Ctrl+Shift+F | 工作区文件 |
| Ctrl+Shift+L | 聚焦消息输入框 |
| Ctrl+O | 添加文件附件 |
| Ctrl+Shift+E | 展开输入 |
| Ctrl+Shift+J | 查看最新消息 |
| Ctrl+Shift+S | 停止生成 |
| F1 | 键盘快捷键说明 |
| Ctrl+Enter / Alt+Enter | 在输入框中换行 / 发送 |

快捷键说明按对话、导航、输入分组，可输入功能名或键位搜索；大屏上 Ctrl+K 的说明写作“搜索对话或命令”。

## 鼠标、右键与窗口

- 2in1 上会话行、消息，以及记忆、MCP 服务与工作区文件列表支持右键打开操作菜单；可滑动的行同时显示“更多操作”按钮。平板仍以长按和滑动为主。
- 2in1 的会话行悬停时显示浅色底；没有编辑权限的会话不显示菜单，也不会响应悬停高亮。
- 消息区与列表在 2in1 上显示滚动条，回弹效果关闭；对话左右留白固定为 24 vp。平板使用触控尺寸的标签与按钮。
- 2in1 最小化会隐藏窗口。窗口不可见时，正在进行的长回答继续传输；完成通知按后台规则发送。窗口隐藏时立即触发一次草稿保存，不等 800 ms 防抖。
- 退出应用与手机相同：已保存的会话、草稿、旁聊与工作区保留，待发送队列在下次启动时保持暂停。

## 与手机的差异

| 项目 | 平板与 2in1 | 手机 |
| --- | --- | --- |
| 工作表 | 平板 840 vp、2in1 720 vp 起 | 无 |
| 侧栏并排 | 平板 840 vp、2in1 796 vp 起 | 不并排，占满内容区 |
| 搜索快捷键 | Ctrl+K 打开命令面板 | 展开会话搜索 |
| 会话详情与旁聊 | 提供 | 不提供 |
| 拖动自动收起 | 提供 | 不提供 |
| 右键菜单 | 仅 2in1 | 长按菜单 |
| 分栏记忆 | 仅 2in1 写入偏好库 | 不适用 |
| 拍照 | 依次选择可用的后置、前置或第一个摄像头（2in1 无摄像头时明确报错） | 固定使用后置摄像头 |
