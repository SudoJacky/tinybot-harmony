# 常见问题

按“现象 → 原因 → 处理”组织，先按界面上的原话找到对应条目，再按处理步骤排查。这里只写能由代码或现有文档确认的行为，不猜测服务端状态。

覆盖的十条：网络与代理、鉴权失败、模型不支持工具调用、流式中断与重试、保存失败与重试、工作区目录丢失、文件权限被拒、预览空白、账号状态不一致、备份恢复失败。

## 网络与代理

**现象**：一直停在“等待模型响应”；提示“网络请求失败（2300005 等错误码），请检查连接和服务地址。”、“模型服务连续 120 秒未返回数据，请检查网络或稍后重试。”或“无法创建网络请求，请检查模型配置。”。

**原因**：手机访问不到填写的地址；地址里的 `127.0.0.1` 指向手机自身；Ollama 服务没有监听局域网；基础地址与所选协议不匹配（例如自建服务缺少 `/v1` 前缀）；所处网络需要代理而系统层没有配置；DNS 或 TLS 拦截。连接超时为 15 秒，响应流连续 120 秒没有数据也会判定超时。

**处理**：

1. 用手机浏览器访问同一地址，确认网络可达。
2. 本地模型填手机能访问的局域网地址与端口，例如 `http://192.168.1.100:11434/v1`，不要用 `127.0.0.1`。
3. 在服务编辑页核对协议（Chat Completions / OpenAI Responses / Anthropic Messages）与基础地址是否匹配。
4. 需要代理时在系统网络层配置，应用没有独立代理设置。
5. 明确的临时传输错误与流式空闲超时会自动重试最多 2 次（间隔 1 秒、2 秒），界面上显示重试状态；鉴权失败、额度错误与解析失败不重试，需手动重新生成。

## 鉴权失败

**现象**：提示“模型服务返回 HTTP 401，请检查地址、API Key、模型名称和额度。”；“请填写 API Key；更换服务基础地址时需要重新填写，其他服务的密钥不会被复用。”；“请先登录华为账号，再使用 AI 生成功能。”；或“华为账号配置校验失败（…），请检查 Client ID 和应用签名指纹。”。

**原因**：密钥错误、失效或额度用尽；更换了域名、端口、协议或服务基础路径，旧密钥不会跨凭据范围复用；服务被停用，或模型被移出该服务的模型列表；华为账号未登录，或平台侧 Client ID 与签名指纹不匹配。

**处理**：

1. 在服务编辑页重新填写 API Key，注意首尾空格；密钥保存在系统安全存储，不写入会话与备份。
2. 确认该服务处于启用状态，且所选模型仍在服务的模型列表中。
3. 在“设置 → 华为账号”重新登录；登录前先阅读并同意协议。
4. 提示“配置校验失败”属于平台配置问题：核对 AGC 中的包名 `com.sudojacky.tinybot`、Client ID 与当前签名证书的 SHA-256 指纹，配置生效时间以平台提示为准。

## 模型不支持工具调用

**现象**：回答只有文字，工具一步都没有执行；或服务返回 HTTP 400 且本轮没有任何工具记录；或工具参数解析失败导致本轮终止。

**原因**：所选模型或服务不支持当前协议的流式工具调用；协议选错（例如对只兼容 Anthropic Messages 的服务用了 Chat Completions 地址）；模型来自“模型发现”，只说明 `/models` 返回了它，不代表它支持工具。

**处理**：

1. 换用确认支持工具调用的模型，或在服务配置中改用正确的协议。
2. 先用一个不需要工具的问题确认同一服务能正常返回，再把任务换成需要工具的步骤，区分“服务不通”和“模型不支持工具”。
3. 工具参数解析失败会作为本轮错误结束，不会把半截工具调用发出去；此时重试通常无效，应换模型或简化任务。

## 流式中断与重试

**现象**：回答停在半句，状态线显示“已停止”或“未完成”；重启后这条回答仍标记为已停止。

**原因**：手动停止；网络中断或 120 秒无数据；鉴权、额度、协议解析失败；保存检查点失败；进程被系统结束。

**处理**：

1. 点“重新生成（保留原回答）”从该回答的上一条用户消息新建分支重发；也可以“改写”回到用户消息再改。
2. 只有明确可重试的错误会自动重试，且只重发尚未提交的模型请求，不重放已完成的工具。
3. 中断的回答正文不进入下一轮上下文，已完成的工具结果保留；已经写入的文件不会因为停止而回滚。
4. 若是保存失败导致的终止，先处理保存错误再继续。

## 保存失败与重试

**现象**：聊天页出现错误条与“重试保存”，会话列表出现错误条与“重试”；发送按钮不可用；切换会话、改设置被拒绝。

**原因**：本地写入、`fsync` 或重命名索引失败；存储空间不足；写入过程中进程被中断，留下待补写的改动。

**处理**：

1. 点“重试保存”补写未落盘改动；重试不会自动继续已暂停的队列。
2. 错误清除前，发送、切换会话、改设置都不被接受，这属于保护而不是卡死。
3. 强制结束进程可能丢失本轮尚未落盘的增量文字，但已保存的历史不会被改写成“已完成”。
4. 反复失败时先清理设备存储，再重启应用重试。

## 工作区目录丢失

**现象**：启动停在“打开本地会话或工作区失败：项目工作区不存在，请从备份恢复。”；或打开某个项目会话时报同样的错误。

**原因**：项目共享目录被手动删除、迁移或外部清理。普通会话目录缺失会在启动时自动补建，项目目录不会——它使用“必须存在”的检查，缺失即报错。

**处理**：

1. 优先从备份恢复（本地导入或华为云空间），恢复会按 `workspaceId` 带回文件。
2. 确实要重建时，用开发者工具在应用沙箱内新建同名目录 `workspace/project-<项目ID>`，再点“重试读取”。
3. 不要把项目目录改成符号链接或普通文件，路径检查会拒绝。

## 文件权限被拒

**现象**：“工作区工具不允许访问符号链接。”；“工作区路径中的父目录不存在或不是目录。”；“只能写入普通文件，不能覆盖目录或符号链接。”；“请选择普通文件。”；“文件超出读取上限。”；“文件自上次读取后已变化，请重新读取再修改。”。

**原因**：路径中含符号链接；父级不是目录；路径越出当前工作区；覆盖已有文件前本轮没有成功读取；读取后文件被外部改动；导出或分享时源文件超过 20 MB 读取上限。

**处理**：

1. 重新读取该文件再修改，版本校验会要求使用最新内容。
2. 把符号链接替换为真实文件或目录；不要在工作区里放指向外部的链接。
3. 只操作当前会话或当前项目的工作区；外部文件通过系统选择器导入，不要尝试绝对路径。
4. 导出、分享前确认文件是普通文件且不超过 20 MB。

## 预览空白

**现象**：卡片长时间显示“正在加载交互内容…”或空白；提示“交互内容启动超时，请重试。”、“交互内容渲染进程已退出，请重试。”；截图位置显示“预览截图加载失败”。

**原因**：卡片不在可见区域——滚动停止约 200 毫秒后才开始加载；页面启动超过 20 秒；渲染进程退出；Three.js 场景需要设备支持 WebGL2；发布的是旧格式内容。

**处理**：

1. 点“重新加载”或先“展开预览”，让卡片进入可见区域并停在原位。
2. Three.js 场景需要设备支持 WebGL2，示例代码缺少 WebGL2 时会直接抛错；发布时的设备启动检查或截图失败也会阻止发布，此时改用普通 HTML/SVG 或 2D 画布。
3. 发布失败会返回 `PREVIEW_INVALID` 与诊断信息，按提示修复源文件后重新发布，而不是反复重试同一份内容。
4. 旧 `.jsonl` 界面不再执行，会明确显示不支持格式，需要改写成 `.js`/`.html`/`.svg`。

## 账号状态不一致

**现象**：“华为账号已退出或发生变化，请重新登录。”；“无法检查华为账号状态，请重试或重新登录。”；“无法恢复华为账号登录状态，请重新登录。”。

**原因**：设备华为账号退出、切换或状态异常。应用在重启、前台恢复以及每次模型请求前都会检查当前设备账号，检查失败会拒绝请求而不是带着旧身份继续。

**处理**：

1. 进入“设置 → 华为账号”重新登录，再重试刚才的操作。
2. 退出 Tinybot 登录不会退出设备账号，也不会删除会话、文件或模型配置。
3. 设备换了账号时，必须用当前设备账号重新登录；本机登录记录不会随会话备份导出。

## 备份恢复失败

**现象**：“备份文件无效。”；“备份最多 20 MB、1000 个文件。”；“华为云空间尚不可用，请登录华为账号，并在系统云空间中开启 Tinybot。”；“备份下载超时，请检查网络后重试。”；“另一项云备份操作正在进行，请稍后再试。”。

**原因**：快照超过 20 MiB 或工作区文件超过 1000 个；文件被改写、不是普通文件或被识别为符号链接；华为云空间未开启、网络/电量/本机或云端空间不足；同时发起多个云操作。

**处理**：

1. 先在系统“设置 → 云空间”登录并开启 Tinybot，再点“刷新备份列表”；只有位置为云端或本机及云端才显示“已上传云端”。
2. 恢复为独立副本，不覆盖现有会话；已有项目的名称、说明与文件以本机为准。
3. 模型与 MCP 凭据不导出：恢复后若服务无法匹配，会导入为停用副本，需要重新填写密钥。
4. 删除备份会同步到云端与其他设备，删除前确认；同步失败时会明确提示“云端删除尚待同步”。
