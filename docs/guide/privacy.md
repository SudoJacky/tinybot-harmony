# 隐私与用户协议

Tinybot 把对话、文件与设置保存在本机，只有调用模型或联网能力时才会把对应内容发出去。这页说明本机存了什么、华为账号的 OpenID 用在哪里、日志与导出包含什么，以及应用内协议的阅读边界。

## 本机数据

应用数据位于应用的私有目录，卸载应用会一并移除：

```text
<databaseDir>/tinybot.db     加密数据库：会话、全局配置、用量、生活看板与卡片
<filesDir>/sessions-v2/      旧版会话索引与单会话文件（升级后保留）
<filesDir>/attachments/      图片附件（.jpg）；文本与文档原件随消息存入工作区
<filesDir>/usage-records/    旧版用量分页账本（升级后保留）
<filesDir>/performance-current.jsonl / performance-previous.jsonl   诊断日志（仅在开启采集时写入）
工作区目录/                     每段会话或每个项目的文件，按 ID 隔离
  ├─ attachments/<附件ID>/<文件名>   文本与文档原件
  ├─ generated-images/        图片工具生成的结果
  └─ mini-apps/<appId>/       旧版小程序页面与数据（升级保留）
```

界面外观与语言保存在 `preferences` 的 `tinybot-ui` 库，开发者开关保存在 `tinybot-developer` 库，这些是设备偏好，不属于任何会话。

会话与配置写入本机加密数据库，索引、会话记录、用量与看板在同一批事务中提交；旧版文件在首次升级时导入并保留为升级前副本，不会因迁移失败而删除。旁聊作为会话记录保存在同一数据库中，与主会话共用工作区，不建立独立目录。

## 华为账号与 OpenID

- 登录使用华为账号（Account Kit），不需要注册 Tinybot 账号，不获取姓名、手机号或身份证号。
- 应用只保存 OpenID，写入系统安全存储（AssetStore）的 `tinybot.huawei.account.v1` 别名下；授权码、ID Token 与 UnionID 既不使用也不保存。
- 登录响应会校验 `state`，再用 OpenID 向系统查询当前设备账号状态；两步都通过才写入本机记录。
- 自动/手动备份与恢复模型 API Key 时，使用已验证账号的 OpenID 派生加密密钥，实现同账号跨设备恢复；OpenID 本身不写入备份。自动任务只使用现有登录，不主动弹出账号登录框。
- 登录记录仅保存在本机系统安全存储，不随会话、备份或云空间备份导出。重启与每次模型请求前都会检查当前设备账号；系统账号退出或变化后需要重新登录。
- 退出 Tinybot 登录只清除本机登录记录，不退出设备华为账号，也不删除会话、文件或模型配置。
- 未登录可以查看历史、配置服务和准备草稿；聊天、标题、摘要、团队与记忆提炼等模型调用需要登录。
- 登录失败只显示错误码与固定文案，不回显系统原始错误信息，因为其中可能包含账号标识。

普通账号登录不等同于真实身份核验。

## 什么内容会离开设备

| 场景 | 发送内容 | 接收方 |
| --- | --- | --- |
| 对话与工具步骤 | 消息正文、附件（含图片）、系统指令、工具定义与工具结果 | 当前会话选择的模型服务 |
| 图片生成与编辑 | 图片提示词、参考图（工作区的 PNG/JPEG/WebP 或本次对话的照片），以及生成结果 | 配置的图片服务；图片服务可复用聊天服务的地址与密钥 |
| 标题、记忆提取、上下文压缩 | 对应范围的对话文本与摘要请求 | 同一模型服务，或指定的专用模型 |
| 团队执行 | 团队目标、成员职责、任务与依赖结果 | 同一模型服务 |
| 联网搜索 | 搜索词 | 配置的搜索服务（内置必应、DeepSeek 官方搜索、Tavily 或 SearXNG 实例） |
| 网页读取 | 目标 URL 与固定 User-Agent | 目标网站；请求不携带模型密钥、Cookie 或自定义认证头 |
| 应用内浏览器 | 页面操作、快照、等待条件与截图；可检查已发布的预览快照 | 目标网站或本地预览快照；登录态属于本次浏览器会话 |
| 云备份 | 对话与文件、服务配置，以及经华为账号信息加密的模型 API Key | 个人华为云空间 |
| 评分和评论 | 跳转应用市场写评论页，应用不收集评论内容或诊断资料 | 华为应用市场 |
| 反馈与建议 | 用户填写的类型、内容、可选联系方式、主动选择的图片与勾选后整理的日志，以及反馈身份凭证 | Tinybot 开发者运营的 `https://sudotinybot.cn` 反馈服务 |
| 打开外部链接 | 固定网址 | 系统浏览器 |

Markdown 导出与诊断导出不携带 API 密钥；模型密钥也不会出现在工具结果、日志或搜索配置里。备份只携带经华为账号信息加密的模型 API Key；对话与文件不加密，MCP 与搜索密钥不导出。

## 密钥与凭据

- API Key 与搜索密钥写入 Asset Store Kit，属性为设备解锁后可读、禁止跨设备同步。
- 在聊天服务下附加的图片模型复用该服务的密钥；单独添加的图片服务使用自己的凭据别名。删除服务或关闭图片模型不会删除另一个服务的密钥。
- 日常配置只保存密钥别名。备份时模型 API Key 单独加密，用户登录同一华为账号后可在另一台设备恢复到系统安全存储；已有本机密钥保留。备份不包含 OpenID。
- 更换服务基础地址后必须重新填写密钥；删除服务会同时删除这份密钥。
- 网页与工具请求不复用模型密钥或浏览器登录状态，避免把凭据带到目标站点。

## 反馈身份与内容

首次主动提交反馈时创建匿名身份，不采集硬件标识或华为账号。凭证写入 AssetStore 的 `tinybot.feedback.identity.v1` 别名，设备解锁后可读、禁止跨设备同步；只放在 HTTPS 请求的 Authorization 头，不放入 URL 或日志，也不随聊天备份导出。401 或网络失败会保留原凭证。

反馈类型、内容与可选联系方式会发送给开发者保存，开发者可以查看并回复。图片仅经主动选择后上传；服务端转换为静态 WebP 并移除原始 EXIF/GPS 元数据。日志默认不附加；用户勾选后，客户端自动整理本次运行最近 15 分钟、最多 1,000 条已通过白名单脱敏的应用运行日志及应用版本，无需手动选文件。普通模式仅保留已有警告和错误，缓冲只在内存中，不落盘，退出进程即消失；不会因勾选而开启开发者性能采样。日志不含聊天正文、密钥、账号凭证、任意错误文本、URL 或文件路径。勾选后直接生成 `.log` 附件，随用户点击提交反馈时上传，不显示日志检查页；取消勾选即移除待上传日志，不会单独或自动后台上传。反馈及其附件、联系方式与回复并非端到端加密。

本机 `tinybot-feedback` Preferences 保存回复已读时间、待提交内容及附件任务元数据；图片副本、脱敏后的日志和下载预览保存在私有 `filesDir/feedback-files/`，不进入聊天工作区或备份。任务完成或用户结束任务后清理本机上传副本，关闭预览后清理下载副本。列表和回复按用户操作查询，无后台轮询或推送。卸载、清除数据或丢失凭证后无法找回访问权限；清除本机数据不会自动删除已经提交到服务端的反馈，可在详情中确认删除自己的附件。

## 日志与诊断

- 默认关闭性能采集。未开启时，warn 与 error 级别仍会写入经脱敏的 HiLog。
- 开启开发者模式后，诊断日志按级别、模块、事件与字段记录；名称与字符串值走白名单，任意错误文本、请求体、URL 与文件路径不会写入。
- 诊断文件按 4 MiB 轮转，最多保留两份；性能环形缓冲保留最近 12000 个事件，运行日志保留最近 1000 条。
- 导出诊断时生成一份 JSON 到缓存目录，由系统分享；其中包含应用版本、平台、指标快照、事件与两份日志文本。系统事件只导出事件名与数值，不包含系统堆栈。
- 采集不会在进程重启后自动开始。

## 导出与分享

| 操作 | 内容 | 不含 |
| --- | --- | --- |
| 导出对话为 Markdown | 对话标题、每条消息的角色与正文、附件文件名 | 附件二进制、模型服务密钥 |
| 云端备份 | 项目、对话（含旁聊）、附件、工作区文件、生活看板、小程序、Skills、模板、记忆、用户文档、设置与用量，以及账号加密的模型、搜索、MCP、邮箱、卡片和反馈连接凭据 | 系统授权、华为账号登录凭据、设备安全存储别名、缓存和诊断日志 |
| 接收系统分享 | 系统授予的 URI 对应的文本、链接、图片或文档，进入新对话草稿 | 不申请整个图库或外部文件夹权限 |
| 导出 CSV（数据视图） | 当前表格内容 | 会话与密钥 |

分享内容进入新对话草稿，仍需要用户审阅后发送；应用就绪且没有保存错误时即可接收，正在生成的其他会话不受影响。一次最多 10 项，文本最多 24000 字符。

小程序入口已在 v1.3.1 下线，已有页面与数据继续保存在本机工作区，并随完整备份上传到个人华为云空间。自动备份保持开启，仅在已同意隐私政策、已登录应用内华为账号并开启 Tinybot 云空间时执行，与手动备份更新同一份文件，见[云备份](/guide/cloud-backup)。

## 第三方服务

| 服务 | 何时使用 | 说明 |
| --- | --- | --- |
| 模型服务商 | 每次模型调用 | 由用户自行选择并配置，密钥与用量由该服务商处理 |
| 图片服务 | 每次调用 `image_gen` | 提示词与参考图发送给配置的图片服务；生成结果下载后保存在工作区 |
| DeepSeek 搜索 | 启用联网搜索且选择 DeepSeek 时 | 复用官方 DeepSeek 模型服务的密钥 |
| Tavily | 启用联网搜索且选择 Tavily 时 | 独立的地址与密钥 |
| 目标网站 | 网页读取或应用内浏览器 | 内容作为不可信资料交给模型 |
| 华为账号（Account Kit） | 登录与账号状态检查 | 仅使用 OpenID |
| 华为云空间 | 自动或手动创建、刷新、恢复、删除云备份 | 快照保存在用户的云空间 |
| 华为应用市场 | 用户主动点击评分和评论 | 应用市场页面处理评分与评论表单 |
| MCP 服务器 | 用户配置并启用后 | 远程工具由该服务器执行，调用前需要确认 |

仓库中的内嵌链接与开源许可入口使用系统浏览器打开，例如 GitHub 仓库与 Apache 2.0 许可证。

## 系统隐私托管与本地用户协议

- 隐私政策使用华为应用市场标准化隐私声明托管。应用不再携带 `privacy-policy.md` 或自建隐私声明阅读页，也不重复显示隐私同意弹窗。
- `HostedPrivacy` 在启动时查询 AppGallery Kit 的托管信息与当前版本签署状态，并订阅 `usual.event.PRIVACY_STATE_CHANGED`；事件只用于触发重新查询，不直接信任事件中的同意标记。应用不再在本机缓存同意记录，状态以系统接口的当前返回为准。
- 查询结果分三类：已同意时初始化账号、会话、ArkWeb、诊断以及分享/快捷入口业务；隐私政策版本更新且需要重新签署时，由 AppGallery 展示系统标准弹窗，等待页提供“继续授权”和退出入口；系统明确返回已拒绝时停止业务并退出应用。
- 系统接口暂时失败或尚未就绪时（例如首次安装后托管信息还没同步），若上一次已知状态不需要用户操作，应用照常进入，并在前台恢复、隐私状态变化与每次模型请求前重新检查；若已知状态明确是“已拒绝”或“待重新签署”，则保持业务关闭，显示错误码与重试、退出入口，不会静默放行。
- 查询失败且系统返回 `1006700003` 时，应用在后台按 500 ms、1 s、2 s、4 s 重试，不阻塞首屏；重试期间界面仍按上一条规则决定是否可用。
- 系统弹窗未出现时，“继续授权”可主动请求同一个系统弹窗。已有有效同意时直接进入，不再叠加第二次请求。
- “设置 → 关于 Tinybot / 华为账号 → 隐私政策”先显示“查看 / 拒绝”选择。选择查看后，通过 `getAppPrivacyMgmtInfo()` 获取系统托管地址并交给系统浏览器，不使用硬编码地址作为运行时降级。
- 选择“拒绝”后，再次提示撤回授权会退出应用；只有点击“拒绝并退出”才调用系统 `disableService()` 撤销同意记录，立即停止当前对话并退出。取消确认不会撤回授权，本机也没有需要额外清理的同意缓存。已有会话、文件和设置保留；下次打开并重新通过系统弹窗同意后可继续使用。撤回失败会显示错误码，不宣称撤回成功。
- 用户协议没有托管，仍随包保存在 `entry/src/main/resources/rawfile/user-agreement.md`，使用原生 Markdown 组件离线全文阅读。引导和登录页面的勾选框仅表示同意用户协议，不代表同意系统隐私政策。
- 用户协议版本日期为 2026年10月26日，随包正文见 `entry/src/main/resources/rawfile/user-agreement.md`。当前没有 Tinybot 账号、会员订阅或应用内购买；争议处理采用法定管辖。

调试包在 entry 的 `module.json5` 预置 `appgallery_privacy_hosted` 和隐私政策 HTTPS 地址，使用官方 debug 模拟接入方式。正式分发的托管配置以应用市场为准，用户协议不设置托管 metadata。真机必须能正常访问应用市场；首次安装后托管信息可能尚未就绪，查询失败不放行业务。此能力不支持模拟器。

模拟器使用独立的本地调试同意流程：仅当构建生成的 `DEBUG` 为 `true`、`BUILD_MODE_NAME` 为 `debug`，且系统 `deviceInfo.productModel` 为 `emulator` 时启用。启动页展示调试隐私说明和政策查看入口，明确点击“同意并进入调试”才初始化业务；退出则不进入。该同意只在本次运行内有效，冷启动需重新确认，撤回会关闭业务并退出；不保存到磁盘，也不读写 AppGallery 签署记录。模拟器查看政策使用包内 metadata 的 HTTPS 地址。

真机 Debug 包及所有 Release 包继续使用系统托管流程，接口失败时不会自动放行。模拟器 Debug 同意不代表完成了系统隐私授权，完整托管流程仍须在真机或云真机验证；在线调试请使用测试数据。

官方说明：[隐私管理服务](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/store-privacy)。

## 用户可以控制的范围

| 想做的事 | 操作 | 边界 |
| --- | --- | --- |
| 停止发送对话内容给模型 | 不发送消息；退出登录后模型调用会被拒绝 | 已发出的请求无法撤回 |
| 移除某份服务的凭据 | 删除该模型服务 | 会同时删除这份配置，使用它的会话需要重新选择模型 |
| 关闭联网能力 | 关闭“允许网页读取与搜索” | 网页与搜索工具不再提供给模型 |
| 停止图片生成 | 在“模型分工与能力 → 生成图片”选择“关闭图片生成” | `image_gen` 不再提供；已生成的图片仍保存在工作区 |
| 关闭应用内浏览器 | 在设置中关闭（默认开启） | 助手不会再次请求启用 |
| 移除云端快照 | 在备份列表删除对应备份 | 同步到云端与其他设备，无法在应用内撤销 |
| 清除本机登录记录 | 退出华为账号 | 不删除对话、文件与模型配置 |
| 清除全部本机数据 | 系统层面的卸载或清除应用数据 | 应用内不提供单独入口 |

完整的行为与实现边界见 [模型服务与上下文](/guide/models)、[网页、搜索与 Skills](/guide/web-and-skills)、[云备份](/guide/cloud-backup)。
