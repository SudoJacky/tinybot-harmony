# 文件与工作区

这页说明会话绑定的工作区（Workspace）在什么位置、如何浏览与编辑文本、怎样导入材料并导出到系统文件夹，以及文件的后台备份与主动恢复。

## 平板与窗口布局

应用按当前窗口可用宽度切换布局，单位为 vp：

- 小于 840：保留手机单栏与会话抽屉，打开文件时覆盖聊天区。
- 840 及以上且未打开侧区：常驻项目与会话列表。
- 打开文件、预览或浏览器后：对话与侧栏并排，侧栏顶部用标签列出已打开的面板（工作区文件、预览、应用内浏览器），可以切换或逐个关闭；点标签栏的“+”可再打开文件或浏览器。只有当会话栏、对话（至少 440）与侧栏（至少 300）仍能同时放下时，会话栏才保持展开，否则收起为 56 宽的图标栏。
- 无论宽度如何，会话栏都可以手动收起；图标栏提供展开、新建对话、搜索、文件、工具与设置入口。展开时若空间不足，会改用覆盖式抽屉，避免挤坏对话或侧区。

平板侧栏集中显示新建对话、文件与工具入口以及项目树；搜索、归档和多选位于“工作区”标题旁，收起按钮位于侧栏顶部右侧。新会话时，欢迎语、项目/模式选择和多行输入区居中显示；开始对话、调出软键盘或窗口高度不足时，输入区回到底部。项目、模式、模型与工具范围均可在输入区附近切换。

会话栏右侧与对话、对话与侧区之间各有一条可拖动的分隔线：会话栏限制在 264 至 420，侧区限制在 300 至窗口宽度的 70%，且始终为对话保留至少 440。拖动结果在窗口旋转或分屏调整后保留，并会在空间不足时自动收缩，不会被裁掉。

宽屏标题栏右侧的侧栏按钮打开或收起侧栏；侧栏没有面板时提供“工作区文件”和“应用内浏览器”两个入口。生成结果卡片的“在侧区打开”会把预览加入同一组标签。展开或收起时，侧栏从右侧滑入/滑出，对话与分隔位置同步让出或收回宽度，不会先跳变再播放面板动画。收起侧栏不会关闭标签，再次打开仍回到原来的标签和编辑/浏览位置；关闭预览标签后，聊天中的预览恢复为可操作。聊天正文和输入区限制最大行宽，避免大屏上的长行。

导航页面沿用系统的进入和返回过渡；文件、交互预览与浏览器标签使用短距离位移和淡入淡出。退出动画结束后才释放页面，暂时被其他标签遮住的编辑器和浏览器仍保留状态。动画遵循系统动画缩放设置。

旋转屏幕、分屏或调整窗口大小只改变布局，不清空聊天草稿、文件编辑内容或运行中的任务。文件区显示打开时所属项目，切换会话后仍保留该文件区；重新打开其他工作区或关闭文件标签前，未保存的编辑需要明确确认。文件引用只允许加入同一工作区的对话，避免把不同项目的内容混入草稿。

## 工作区在哪里

每个会话绑定一个目录，路径在运行时推导，不写死在配置里：

```text
<应用级 filesDir>/workspace/
├── <会话ID>/                普通会话各自的目录
│   ├── 笔记-1007-1530.md
│   └── .tinybot-review/     审阅基线（隐藏目录）
└── project-<项目ID>/        项目共享目录，项目内所有会话共用
```

| 会话类型 | 目录 | 共享范围 |
| --- | --- | --- |
| 普通会话 | `workspace/<会话ID>` | 只有这一条会话 |
| 项目会话 | `workspace/project-<项目ID>` | 该项目内所有会话 |

- 目录位于应用沙箱内，不需要存储授权，也不出现在系统文件管理器的公共目录里。
- 普通会话启动时会补建自己的目录；项目目录缺失时明确报错“项目工作区不存在，请从备份恢复。”，不会静默创建空目录。
- 路径会逐级检查，拒绝越界路径与符号链接；目录里的符号链接条目在列表里显示为“链接 · 不支持打开”。

## 从哪里打开

| 入口 | 打开的内容 |
| --- | --- |
| 输入区“+ → 工作区” | 当前会话的工作区根目录 |
| 更多菜单 →“工作区文件” | 同上 |
| 项目分组菜单 →“项目文件” | 项目共享目录，标题为“项目文件 · 项目名”；项目没有可用会话时会先新建一条 |
| 回答里的文件卡片 | 直接打开对应文件 |
| 文件交付卡片 | 预览、分享、导出当前文件 |

“项目文件”打开的是该项目最近更新的未归档会话；项目内会话看到的都是同一份文件。

## 浏览

- 顶部是面包屑，点任意一级返回该层；系统返回键先返回上一级目录，再离开页面。
- 下拉刷新重新读取目录；文件夹排在文件前，各自按名称排序。
- 单层最多加载 200 项，超出的部分提示“仅显示前 200 项”。
- 图片文件直接以图片预览；Markdown 渲染排版；CSV/TSV 显示为表格；其余文本按等宽字体显示，可长按选择。
- 读取失败时页面内显示错误条，可关闭后重试。

## 新建、编辑与删除

| 操作 | 行为 |
| --- | --- |
| 新建笔记 | 在当前位置创建空 `.md`，命名 `笔记-MMDD-HHmm.md`，重名自动加 ` (2)`，随后直接进入编辑 |
| 编辑 | 文本在编辑器中最多 32000 字符；编辑中标题显示“编辑中”或“编辑中 · 未保存” |
| 保存 | 覆盖写入后重新读取基线，提示“已保存” |
| 放弃 | 有未保存修改时返回会询问“放弃未保存的修改？”，可继续编辑或放弃 |
| 删除 | 二次确认“删除后无法恢复”，删除后关闭预览并刷新列表 |

图片文件只能预览，没有编辑入口。文件行左滑提供分享、导出、删除；预览页底部提供分享、导出与删除，文本文件另有引用。

## 导入材料

“导入文件”使用系统文件选择器，一次最多 5 个，可选后缀为 `.txt`、`.md`、`.csv`、`.tsv`、`.json`、`.log`、`.pdf`、`.docx`、`.xlsx`、`.pptx`。

- 文本文件按 UTF-8 完整读入；非 UTF-8 或包含空字符的文件会拒绝导入，并给出明确错误。
- PDF 与 Office 文档提取文字后以 `.txt` 形式保存，PDF 最多 100 页、原文件最多 8 MB；不保留排版，也不做扫描件 OCR。
- HarmonyOS 6（API 20）未提供系统 PDFKit 模块，导入 PDF 会在读取前提示“此系统的 PDF 组件未提供文字提取”，不会生成空白文本；可把页面截图作为图片发送，或改用 Office、文本文件。
- 文件名会去掉路径分隔符等非法字符，重名自动加序号，不会覆盖已有文件。
- 导入结束提示“已导入 N 个文件”。导入是复制一份到工作区，原文件位置不受影响。

## 保存到系统文件夹与分享

- **导出**：打开系统保存选择器，你选好位置后才写入；取消选择不会产生文件。源文件读取上限 20 MB。
- **分享**：先复制一份到应用缓存并清洗文件名，再交给系统分享面板，因此分享后再修改工作区文件不会改变已分享内容。
- 两者都对当前文件生效，不改变工作区里的原件。

导出含助手回答的对话 Markdown，以及有助手成功写入/编辑记录的工作区 `.md`、`.markdown`、`.html`、`.htm` 文件时，副本会加入 `AIGC` 隐式来源标识，包含 Tinybot 和随机内容编号，不包含用户、账号或设备信息。Markdown 使用独立 HTML 注释并保留已有 front matter 的首行位置；HTML 完整文档写入 `<head>` 的 `<meta>`，片段使用 HTML 注释。查看源码可读到标识，普通渲染不显示；重新导入 Markdown 后，应用预览也会忽略这条标识。

分享、工作区内的生成与编辑、共享目录直接写入均不新增标识。单纯导入的用户原文、备份、诊断以及其他文件格式不添加 AI 来源标识。来源依据是所在工作区保留的成功工具记录；缺少历史记录时不推断作者身份。

## CSV / TSV 表格预览

扩展名为 `.csv` 时按逗号分列，`.tsv` 时按制表符分列，第一行作为表头，其余作为数据行，表格最高 4000 vp 后内部滚动。预览是只读的：需要改数据时点“编辑”修改原文，保存后重新打开即可看到新表格。表格上选中的文字同样可以引用到草稿。

## 自动备份与恢复

文件写入后立即生效，无需再次确认保留。打开文件只展示当前内容，不显示差异审阅或“助手修改了这个文件”卡片，也不要求选择删除或保留。

修改前备份仍自动保存在工作区的 `.tinybot-review/` 中，首次保存的原始内容不会被后续写入覆盖。有已有文件备份时，预览页右上角“更多操作”菜单提供：

- **导出修改前备份**：将备份内容保存到你选择的位置；即使当前文件无法预览，也能导出备份。
- **恢复原版**：主动选择后才弹出恢复确认，核对当前内容未变化后写回备份。恢复失败时备份保留。项目内文件的恢复确认会说明影响范围。

新建文件没有旧内容，不提供备份恢复或作为撤销操作的删除选择；需要删除时使用文件本身的普通删除入口。

## 本轮修改

每条回答结束后，如果本轮真的改过文件，末尾展示“本轮修改”：

- 按路径比较“本轮首次成功修改前”与“最后一次写入后”的内容，包含工具编排里的子调用。
- 改回原文的文件不计入净变化；新建的空文件仍会列出。
- 可展开文件清单与分页差异；这份快照随回执一起保存，重启后不依赖当前文件，也不会进入模型上下文。
- 旧回执没有本轮快照时不推算汇总；用户审阅用的基线与之独立。

## 写入规则

项目授权的共享文件夹以 `shared/<名称>/` 访问，可以新建和修改 UTF-8 文本文件。修改会直接反映到原文件所在的系统目录。

| 规则 | 表现 |
| --- | --- |
| 私有工作区原子替换 | 先写同目录临时文件、`fsync`，再重命名覆盖目标；失败时清理临时文件 |
| 共享目录直接写入 | 写前在应用私有工作区保存备份，再直接写入目标；保存中断可能留下部分内容，不保证原子性 |
| 文本约束 | 只处理 UTF-8 文本，拒绝空字符；不能写目录或符号链接 |
| 覆盖前必须读取 | 本轮没有成功读取过的已有文件，只能创建新文件；直接覆盖返回 `FS_NOT_OBSERVED` |
| 版本校验 | 读取时记录 SHA-256，写入时比对；期间文件被改动则返回 `FS_STALE_VERSION`，要求重新读取 |
| 串行写入 | 同一路径的写入排队执行，不同文件可并行 |

文本约束对所有写入生效；覆盖前必须读取、版本校验与串行队列约束助手的工具调用。界面保存也按文件位置采用上述写入方式。

共享文件的后台备份保留首次修改前的内容，连续写入不会覆盖。恢复和导出由你在“更多操作”菜单主动发起，恢复采用直接写入，失败时备份会继续保留。完整的错误码与恢复建议见[回执与错误](/reference/receipts)。

## 边界

- 文件工具只能访问当前会话绑定的工作区和项目明确授权的共享文件夹，看不到其他会话目录、模型配置或密钥。
- 没有 Shell、跨应用控制或任意外部目录访问；外部文件只能通过系统选择器，以你选中的 URI 为范围。
- 列目录每次最多 200 项，内容搜索每次最多扫描 200 个文件并返回 100 处匹配，读取每次最多 2000 行或 50 KiB，可继续读取。

项目共享的归属规则见[项目与共享工作区](/guide/projects)，备份如何带走文件见[云备份](/guide/cloud-backup)。
