# 云备份

「设置 → 备份与恢复」可将快照自动或手动保存到华为云空间，也可通过 WebDAV 手动备份，在重装或换机时选择历史版本合并恢复。这页说明备份包含什么、状态文字的含义、恢复时会改写哪些引用，以及失败时应该看哪条提示。

## 自动云备份

自动云备份默认开启，与手动云备份共用本机的版本保留规则。仅在已同意系统隐私政策、已登录应用内华为账号并开启 Tinybot 云空间时执行。自动任务不会弹出账号登录框，账号或云空间未就绪时等待，失败会在本页显示原因并记录脱敏诊断日志。

自动备份不使用定时器，不在启动、前台停留或每次编辑后创建快照。应用退到后台时，若对话、配置或本机工作区文件有变化，申请一次系统短时任务，异步打包并请求云端同步；没有新变化且已经上传时不重复备份。已有完整快照等待上传时只重试同步。失败等下一次退后台再试，也可手动备份。

短时任务在 `UIAbility.onBackground()` 内同步申请，完成、失败或即将超时时主动释放；到期会取消后续打包与等待，不把未完成的文件当成备份。它受系统配额约束，申请失败时显示原因，不悄悄切回高频备份。新安装等待备份发现/恢复选择或完成新手设置后才开始，不用空白数据覆盖旧备份。

华为云空间和 WebDAV 按设备分别保存最近 3 个备份版本。恢复时可查看设备和时间。自动备份只使用华为云空间，WebDAV 通过同页入口手动创建和恢复快照。

生命周期回调仅申请短时任务并启动异步流程，不同步等待备份。任务只延迟后台挂起，不能拦截划掉任务、崩溃、系统回收、升级或一键清理等直接终止进程的情况，也不会为等待上传而阻止用户关闭应用。恢复范围以最后一份实际上传完成的快照为准，尚未备份的最新改动可能丢失。

本页区分“已上传”与“等待上传”。卸载前请确认备份已上传；“已发起同步”或“已在本机生成文件”不代表重装后可恢复。自动备份沿用下述范围与加密规则。

变化检测同时覆盖对话、工作区、凭据、用量和界面偏好。仅修改邮箱/API 连接、语言、外观或已读状态，也会在下一次符合条件的后台备份时更新快照；没有变化且已上传时不重复打包。

## 前置条件

1. 在系统「设置 → 云空间」登录华为账号，并开启 Tinybot 的云空间开关。
2. 回到应用进入「设置 → 备份与恢复」，点击“备份”或“恢复备份”。

华为云空间使用 Core File Kit 的端云文件协同。使用 WebDAV 时，在备份页添加自己的连接，再选择“备份”或“恢复备份”。两种方式均使用应用内华为账号保护备份中的连接凭据。

## 备份范围

每次备份是一份 `.tinybot` 二进制快照，格式为 `tinybot-harmony.backup.v4`，继续沿用 `TINYBOT3` 分块容器。附件与工作区文件保存原始字节，以 256 KiB 分块读写，不经过 Base64；兼容导入 v3 归档和 v1/v2 JSON 备份。旧版应用不能读取 v4 快照。

完整备份兼容旧版小程序清单，保留版本历史、正式数据、迁移前数据和试用文件，包括原会话已删除后保留的小程序工作区。这些文件作为工作区原件保留。已有工作区仍以本机数据为准。

| 包含 | 不包含 |
| --- | --- |
| 项目、对话、历史消息、草稿及交互状态 | 隐私同意、系统权限与共享文件夹授权 |
| 附件原件（图片、文本与文档） | OpenID 与华为账号登录凭据 |
| 模型服务配置、API Key、独立余额查询凭据与所选模型 | 设备安全存储别名（恢复时重新生成） |
| 工作区文件（含 `generated-images/`）、旧版小程序页面与数据，包括失去原会话的工作区 | 应用缓存、文件修改审阅基线、诊断日志与性能记录 |
| 生活看板布局、挂载状态、卡片定义、数据、输入和运行记录 | 外部共享文件夹的文件内容 |
| Skills 及参考文件、长期记忆、USER.md 和助手选项 | 未完成的反馈提交、附件上传与后台操作 |
| 搜索、MCP、邮箱和 API 卡片的配置及加密连接凭据，含已保存的 OAuth Token | 浏览器临时会话与系统管理的第三方登录状态 |
| 外观、语言、用量账本、评分及公告已读状态、反馈身份和回复已读状态 | 安装标识、新手/启动恢复标记、云端备份副本 |

| 限制 | 值 |
| --- | --- |
| 备份容量、索引与文件数量 | 不设应用固定上限，实际受设备内存、本机存储与云空间约束；旧 JSON 导入也无固定容量上限 |
| 符号链接 | 不支持，遇到即失败 |
| 项目共享工作区 | 按 `workspaceId` 只打包一次；没有会话的项目也会包含文件 |

创建和恢复含模型配置或连接凭据的备份时，应用检查华为账号登录状态，尚未登录则由用户完成系统登录。沿用现有加密方案：以同一应用下的 OpenID 经 PBKDF2-SHA256 派生密钥，通过 AES-256-GCM 加密凭据，不需要设置备份密码；换设备必须登录同一账号。OpenID 不写入备份。对话、服务地址、模型列表和文件不加密。无加密凭据区的备份可直接导入。

导出复制输入，不改动运行中的配置。公开配置清空凭据别名，需要凭据的服务在公开部分停用；原始配置与凭据一起认证加密，恢复时校验服务地址，防止重定向密钥。邮箱配置与授权码、卡片 API Key/Bearer/OAuth、反馈身份也只进入加密区域。读取已保存凭据失败会停止备份并报错。

项目共享文件夹只备份 URI 引用，不包含外部文件内容或系统授权。换设备或授权失效后，需要在项目设置中重新选择文件夹；恢复到已有项目时，以本地共享文件夹配置为准。

## 新安装时发现备份

同意隐私政策后，新安装且尚未配置的应用会查询云空间备份，优先提示恢复“最新备份”。用户明确选择恢复后才下载和导入；选择“暂不”后不会反复提示。云空间未就绪或网络失败会记录诊断日志，可稍后启动时重试，或从设置手动恢复。

升级不会仅因“没有 API 配置”触发弹窗：首次引入此功能时，在会话存储初始化之前同时检查系统安装/更新时间、现有 v2 会话清单、旧 v1 文件和引导完成记录。已有安装判定结果只保存在本机 Preferences，不随备份迁移。检测期间已开始配置、输入草稿、接收分享或打开服务编辑页时，不再打断当前操作；隐私同意撤销、离开前台后也不弹出。

## 备份

点击“备份”，或在符合自动备份条件时退到后台，会创建独立的华为云空间版本。应用先写完私有临时快照，再将完整文件放入云目录。WebDAV 也以独立文件保存版本。

只有原生文件位置明确为“云端”或“本机及云端”时，才显示“备份已上传到云端”。同步完成回调本身不能证明已经上传。没有上传成功时保留上一份恢复副本；页面显示等待上传，自动备份下次只重试同步，不重复打包没有变化的数据。

上传成功后，清理本机超过保留数量的旧版本。清理仅处理当前设备生成的版本，其他设备和旧格式的备份仍可选择。

打开备份页可查看状态，手动备份由“备份”按钮触发。

## 恢复

在另一台设备登录同一华为账号后，按所用服务开启 Tinybot 云空间或配置同一 WebDAV 目录。点击“恢复备份”，选择设备和版本。应用下载并校验快照，显示将新增、跳过和另存副本的会话数量，确认后合并。

- 云端文件会先下载：等待对应 URI 的下载完成回调，连续 60 秒没有新增下载字节才超时；失败或超时会停止该下载并移除监听，不导入不完整文件。
- 合并导入时跳过相同会话版本。同一会话存在不同版本时另存为备份副本，原会话和文件保留。工作区逐文件补齐缺失内容，已有文件、卡片数据和看板布局以本机为准。
- 恢复前校验文件名、大小、格式、附件、引用与工作区路径。新格式先解包到私有缓存目录，并核对整包唯一的 SHA-256 校验值；校验失败不写入工作区，正常完成或失败后清理临时目录。
- 对话与附件内容保留原文；附件获得新的本机文件 ID，新项目的物理工作区也使用新目录，在会话索引提交前不替换任何本地项目。
- v1 备份没有项目归属，恢复为普通会话。
- 恢复会保留项目与会话身份。已有项目的名称、指令与文件以本地为准；新增项目准备新目录后再提交归属。

模型与工具引用按下面的规则对齐本机配置：

| 对象 | 匹配规则 | 匹配不到时 |
| --- | --- | --- |
| 模型服务 | 协议 + 完整服务地址（忽略末尾斜杠），优先使用原服务 ID；否则只在唯一匹配时复用 | 有加密密钥时恢复原服务配置并写入新的安全存储别名；旧备份导入停用副本，提示配置密钥 |
| MCP 服务 | 完整 URL，优先使用原 ID | v4 恢复启用状态与加密凭据；旧备份导入停用副本 |
| 会话所选模型 | 指向匹配后的服务 ID | 本机模型列表未被覆盖，需重新选择模型 |

恢复前先解密并认证密钥，账号不匹配时不解包文件。恢复会保留匹配到的本机服务与密钥；只为新增服务写入系统安全存储，配置提交失败会清理本次新增的密钥。恢复成功后立即注册新增模型服务，无需重启或重新保存设置。全新且未配置的应用恢复所选模型后可以直接使用；已有应用的当前模型不变。

v4 的新增 MCP 服务恢复原认证方式和启用状态，无认证的 MCP 也保留启用状态。模型服务与邮箱连接合并导致 ID 改变时，会同步改写新导入卡片的余额服务、邮箱来源和模型路由引用。API 卡片按新设备的工作区重新建立安全存储关联，已有本机连接凭据优先。OAuth 或邮箱授权码被服务端撤销时仍需重新连接。

单项设置保留本机非默认值，以备份补齐缺失或出厂默认的助手选项；外观、语言等设备偏好只在本机尚未保存时恢复。定制过的内置 Skill 和模板可替换新安装的出厂版本，已定制或停用的本机 Skill 不覆盖。用量记录按请求 ID 合并，本机已有记录优先；公告已读记录合并。恢复不会迁移隐私同意与系统授权，也不会自动重放待执行消息或未完成的外部操作。

设置提交失败时回滚本次新增凭据、邮箱连接和新增文件；文件回滚检查内容版本，不删除期间被修改的文件。设置已提交但用量或偏好恢复失败时会明确提示“主要数据已导入，附加数据恢复未完成”，再次导入可继续补齐。

## 历史兼容

没有新格式共享备份时，也能自动发现并恢复旧时间戳备份或旧的独立自动备份；只选择已经在云端的最新副本，跳过尚未上传的本地副本。云端同步失败或未完成时停止恢复，不用缓存列表冒充最新云端结果。云端没有备份时，会明确提示先在原设备完成备份。

旧版应用仍可能创建独立文件。全部设备更新到新版后，下一次共享备份成功上传会清理旧文件，恢复入口始终自动选择最新可恢复内容。

## 失败处理

| 提示或错误码 | 含义 |
| --- | --- |
| 华为云空间尚不可用（22400001 / 801） | 未登录华为账号，或系统云空间未开启 Tinybot |
| 无法写入华为云空间（13900012） | 云目录不可写，需在系统云空间开启 Tinybot 后重试 |
| 网络不可用（22400002） | 无网络，联网后刷新 |
| 电量过低（22400003） | 电量不足，充电后刷新 |
| 本机存储空间不足（13900025） | 清理本机空间后重试 |
| 华为云空间已满 | 释放云空间后刷新 |
| 设备温度过高 | 稍后刷新 |
| 备份下载超时 | 连续 60 秒没有新增下载字节，检查网络与本机空间后重试 |
| 备份格式无效 / 备份文件无效 | 文件名、格式、大小或结构不符合要求，快照不会被导入 |

原生同步与下载操作全局串行，页面重开也不会重复并发调用；已有操作进行时提示“另一项云备份操作正在进行，请稍后再试。”

恢复期间需要同时容纳备份文件、临时解包文件与新增数据，请预留足够本机空间。文件不会额外压缩；对话和文件不加密。整包 SHA-256 用于发现内容损坏，不提供身份认证；凭据区域单独通过 AES-256-GCM 认证加密。

## 与本地数据的关系

- 备份页提供华为云空间和 WebDAV 两种入口。恢复兼容旧 JSON 和归档格式。
- 云备份不修改当前数据，只有“恢复”才会合并导入。
- 模型 API Key 只以密文进入快照；本机已有的密钥与服务设置不会被快照覆盖。
- v4 包含语言偏好与请求用量账本；合并后保留本机已有请求，不重复计数。
- 系统 `BackupExtensionAbility` 是另一项能力，本次不启用，应用不会主动触发系统整机备份。
- 自动与手动备份覆盖相同数据，并按设备维护各自生成的历史版本。

## 验证边界

自动化测试覆盖快照脱敏与不变性、账号不匹配与密钥篡改拒绝、随机盐和 nonce、密钥提交失败回滚、本机密钥保留、新安装与升级识别、上传状态、配额失败保留快照、写入失败清理、等待下载完成、错误 URI 隔离、合并恢复、非法路径拒绝、超时与并发锁释放；删除测试覆盖三种文件位置、只移除选中快照、失败保留文件与同步失败重试。

完整迁移夹具还覆盖模型、搜索、MCP、邮箱、API/OAuth 卡片及反馈身份的加密恢复，模型与邮箱 ID 重映射，普通孤立工作区、看板挂载状态、定制内置 Skill 和模板、界面偏好与用量账本。它使用独立临时目录模拟空白设备与已有数据的设备，验证重复导入、本机数据优先、提交失败后清理与重试、附加数据失败后的明确提示与补齐，以及合并超过现有服务数量限制时保留原数据。

真实上云与跨设备恢复需要两部支持端云协同的设备、同一华为账号，并已开启 Tinybot 的同步开关；原生适配测试不能代替这项验证。官方适配要求 HarmonyOS 6.0.0.115 及以上、云空间 6.0.0.300 及以上。
