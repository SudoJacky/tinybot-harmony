# 云备份

「设置 → 备份与恢复」用个人华为账号的云空间保存手动快照，并在另一台设备上恢复成独立副本。这页说明备份包含什么、状态文字的含义、恢复时会改写哪些引用，以及失败时应该看哪条提示。

## 前置条件

1. 在系统「设置 → 云空间」登录华为账号，并开启 Tinybot 的云空间开关。
2. 回到应用进入「设置 → 备份与恢复」，页面提供“打开华为云空间”入口；无法跳转时按提示手动前往系统设置。

应用使用 Core File Kit 的端云文件协同，不需要 Tinybot 账号、自建服务器或 WebDAV 配置。云目录不可用时直接报错，不会在本机伪造一个“云目录”替代。

## 备份范围

每次备份是一份 `.tinybot` 二进制快照，格式为 `tinybot-harmony.backup.v3`。附件与工作区文件保存原始字节，以 256 KiB 分块读写，不经过 Base64；继续兼容导入 v1/v2 的 JSON 备份。旧版应用不能读取新的 `.tinybot` 文件。

完整备份兼容 v1/v2 小程序清单，保留版本历史、正式数据、迁移前数据和试用文件，包括原会话已删除后保留的小程序工作区。恢复后按清单中的正式数据文件继续读取；已有工作区仍以本机数据为准。

| 包含 | 不包含 |
| --- | --- |
| 项目、对话与历史消息 | MCP / 搜索 Token、设备凭据别名 |
| 附件（文本与图片） | 助手选项（用户文档除外） |
| 模型服务配置、经账号信息加密的 API Key 与所选模型 | OpenID 与账号登录凭据 |
| 各工作区文件 | 语言偏好（界面语言） |
| Skills、提示词模板、长期记忆 | 请求用量账本 |
| 用户文档（USER.md） | 应用缓存、诊断日志与性能记录 |

| 限制 | 值 |
| --- | --- |
| 备份容量、索引与文件数量 | 不设应用固定上限，实际受设备内存、本机存储与云空间约束；旧 JSON 导入也无固定容量上限 |
| 符号链接 | 不支持，遇到即失败 |
| 项目共享工作区 | 按 `workspaceId` 只打包一次；没有会话的项目也会包含文件 |

创建和恢复含模型配置的备份时，应用检查华为账号登录状态，尚未登录则由用户完成系统登录。新备份使用同一应用下的 OpenID 派生密钥，不需要额外设置备份密码；换设备必须登录同一账号。OpenID 不写入备份。只加密模型 API Key 区域；对话、服务地址、模型列表和文件不加密。无加密密钥区的备份直接导入。

导出复制输入，不改动运行中的配置：公开服务条目清空凭据别名并标为停用，另将模型服务的原始配置与 API Key 一起认证加密，防止修改公开地址后把密钥恢复到其他服务。MCP 与搜索密钥不导出。

项目共享文件夹只备份 URI 引用，不包含外部文件内容或系统授权。换设备或授权失效后，需要在项目设置中重新选择文件夹；恢复到已有项目时，以本地共享文件夹配置为准。

## 新安装时发现备份

同意隐私政策后，新安装且尚未配置的应用会查询云空间备份，优先提示恢复“最新备份”。用户明确选择恢复后才下载和导入；选择“暂不”后不会反复提示。云空间未就绪或网络失败会记录诊断日志，可稍后启动时重试，或从设置手动恢复。

升级不会仅因“没有 API 配置”触发弹窗：首次引入此功能时，在会话存储初始化之前同时检查系统安装/更新时间、现有 v2 会话清单、旧 v1 文件和引导完成记录。已有安装判定结果只保存在本机 Preferences，不随备份迁移。检测期间已开始配置、输入草稿、接收分享或打开服务编辑页时，不再打断当前操作；隐私同意撤销、离开前台后也不弹出。

## 创建与查看

点“备份到华为云空间”会更新固定的 `tinybot-latest.tinybot`，重复备份覆盖这一份最新备份，不再追加历史快照。先在同目录写入唯一临时文件，完整复制并同步到磁盘后，通过重命名替换旧文件；复制、落盘或替换失败时保留上一份完整备份。上传失败时保留已完成的新备份供重试，并显示真实同步状态。

打开页面不会自动备份。所有设备共享这份最新云备份，后续备份会替换此前的内容；旧版本已生成的时间戳备份仍可恢复或手动删除，不会自动清理。最新备份的日期来自文件修改时间。

```text
当前数据
  └─ 复制快照（API Key 账号加密；公开配置清空凭据别名）
       ├─ 写入索引、逐文件复制原始字节与整包校验值 → 临时快照文件
       ├─ 完整写入后重命名 → tinybot-latest.tinybot（替换上一份）
       └─ 请求端云同步
            ├─ 30 秒内收到完成 → 显示“已上传云端”
            └─ 超时或排队 → 显示“仅保存在本机，等待上传”，系统稍后继续
```

| 列表文字 | 含义 |
| --- | --- |
| 已上传云端 · 大小 · 点按恢复 | 文件位置为云端，或本机及云端 |
| 仅保存在本机，等待上传 · 大小 | 尚未上传，还不构成云端备份 |
| 云端状态未知，请刷新确认 | 位置信息不可判定，需要刷新 |

同步请求只表示“已发起”。应用等待完成回调最多 30 秒，超时后按文件真实位置显示状态，系统仍可继续上传。点“刷新备份列表”会重试待上传的快照并获取其他设备的备份元数据。

列表通过 `lstat()` 排除符号链接与非普通文件，再查询文件位置。真机系统文件库读取 `lstat()` 结果的位置会触发原生崩溃，因此位置来自随后的 `stat()`。

## 恢复

在另一台设备登录同一华为账号、安装 Tinybot 并开启云空间开关后，点“刷新备份列表”，选择一份备份并确认。恢复规则：

- 云端文件会先下载：等待对应 URI 的下载完成回调，连续 60 秒没有新增下载字节才超时；失败或超时会停止该下载并移除监听，不导入不完整文件。
- 恢复为独立副本：已有会话按 ID 跳过，不覆盖本机对话；当前对话与设置保持原样。
- 恢复前校验文件名、大小、格式、附件、引用与工作区路径。新格式先解包到私有缓存目录，并核对整包唯一的 SHA-256 校验值；校验失败不写入工作区，正常完成或失败后清理临时目录。
- 对话与附件内容保留原文；附件获得新的本机文件 ID，新项目的物理工作区也使用新目录，在会话索引提交前不替换任何本地项目。
- v1 备份没有项目归属，恢复为普通会话。
- 恢复会保留项目与会话身份。已有项目的名称、指令与文件以本地为准；新增项目准备新目录后再提交归属。

模型与工具引用按下面的规则对齐本机配置：

| 对象 | 匹配规则 | 匹配不到时 |
| --- | --- | --- |
| 模型服务 | 协议 + 完整服务地址（忽略末尾斜杠），优先使用原服务 ID；否则只在唯一匹配时复用 | 有加密密钥时恢复原服务配置并写入新的安全存储别名；旧备份导入停用副本，提示配置密钥 |
| MCP 服务 | 完整 URL，优先使用原 ID | 导入为停用副本 |
| 会话所选模型 | 指向匹配后的服务 ID | 本机模型列表未被覆盖，需重新选择模型 |

恢复前先解密并认证密钥，账号不匹配时不解包文件。恢复会保留匹配到的本机服务与密钥；只为新增服务写入系统安全存储，配置提交失败会清理本次新增的密钥。全新且未配置的应用恢复所选模型后可以直接使用；已有应用的当前模型不变。

## 删除

每份备份右侧有删除按钮，确认框显示备份日期。删除会校验文件名与文件类型后只移除该快照，再请求同步，不下载云端文件，也不删除工作区、对话或其他备份。

- 删除会同步到云端与其他设备，无法在 Tinybot 内撤销。
- 不影响当前对话与设置。
- 文件删除成功但同步失败时，提示“备份已从本机列表移除，云端删除尚待同步”，可稍后刷新重试。

## 失败处理

| 提示或错误码 | 含义 |
| --- | --- |
| 华为云空间尚不可用（22400001 / 801） | 未登录华为账号，或系统云空间未开启 Tinybot |
| 无法写入华为云空间（13900012） | 云目录不可写，需在系统云空间开启 Tinybot 后重试 |
| 网络不可用（22400002） | 无网络，联网后刷新 |
| 电量过低（22400003） | 电量不足，充电后刷新 |
| 本机存储空间不足（13900025） | 清理本机空间后重试 |
| 华为云空间已满 | 释放云空间后刷新 |
| 设备温度过高 | 稍后刷新 |
| 备份下载超时 | 连续 60 秒没有新增下载字节，检查网络与本机空间后重试 |
| 备份格式无效 / 备份文件无效 | 文件名、格式、大小或结构不符合要求，快照不会被导入 |

原生同步与下载操作全局串行，页面重开也不会重复并发调用；已有操作进行时提示“另一项云备份操作正在进行，请稍后再试。”

恢复期间需要同时容纳备份文件、临时解包文件与新增数据，请预留足够本机空间。文件不会额外压缩；对话和文件不加密。整包 SHA-256 用于发现内容损坏，不提供身份认证；API Key 区域单独通过 AES-256-GCM 认证加密。

## 与本地数据的关系

- 本地导出与导入仍可独立使用：「导出备份」写出同一份快照并由系统分享，接收方可保存到本机或发送到其他设备；「从备份导入」只恢复缺少的内容，保留本机已有对话。
- 云备份不修改当前数据，只有“恢复”才会导入，且以独立副本形式追加。
- 模型 API Key 只以密文进入快照；本机已有的密钥与服务设置不会被快照覆盖。
- 语言偏好与请求用量账本不在备份范围内；用量账本随本机账本更新，不汇总其他设备。
- 系统 `BackupExtensionAbility` 是另一项能力，本次不启用，应用不会主动触发系统整机备份。
- 没有定时备份或实时数据合并；密钥只随手动备份与恢复迁移。云端重复备份替换最新备份。本地导出默认使用同一文件名，由系统保存窗口决定目标位置与覆盖行为。

## 验证边界

自动化测试覆盖快照脱敏与不变性、账号不匹配与密钥篡改拒绝、随机盐和 nonce、密钥提交失败回滚、本机密钥保留、新安装与升级识别、上传状态、配额失败保留快照、写入失败清理、等待下载完成、错误 URI 隔离、恢复为独立副本、非法路径拒绝、超时与并发锁释放；删除测试覆盖三种文件位置、只移除选中快照、失败保留文件与同步失败重试。

真实上云与跨设备恢复需要两部支持端云协同的设备、同一华为账号，并已开启 Tinybot 的同步开关；原生适配测试不能代替这项验证。官方适配要求 HarmonyOS 6.0.0.115 及以上、云空间 6.0.0.300 及以上。
