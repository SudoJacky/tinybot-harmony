# 设置、外观与用量

设置页集中管理账号、模型服务、助手偏好、工具权限、外观语言、数据与关于信息。这页说明每个分组负责什么、哪些改动立即生效、Token 用量账本怎么统计，以及开发者诊断入口在哪里。

## 设置分组

侧栏与聊天“更多”菜单都通往同一个设置首页，分组顺序固定：

| 分组 | 内容 |
| --- | --- |
| 账号 | 华为账号状态（已登录 / 未登录） |
| 模型与服务 | 每份服务配置、添加模型服务、模型分工与能力 |
| 助手偏好 | 称呼与回答偏好（用户文档）、提示词模板、自动保存任务结果 |
| 记忆与上下文 | 自动提取长期记忆、管理长期记忆、自动压缩历史 |
| 工具与权限 | 只读模式、允许网页读取与搜索、搜索服务、应用内浏览器、Skills、MCP 服务 |
| 界面与语言 | 界面与外观、语言 |
| 数据与用量 | Token 用量、存储空间、备份与恢复 |
| 帮助与关于 | 使用帮助、评分和评论、关于 Tinybot，以及解锁后出现的开发者模式 |

大部分条目从右侧进入独立页面。开关类设置点按即保存；服务、记忆、模板、MCP 的编辑留在各自页面，模型列表修改先进入服务草稿，保存服务后才生效。

## 华为账号

未登录的华为账号页沿用新人引导的 Tiny 吉祥物、登录说明、协议勾选和底部登录按钮，保留顶部返回与“华为账号”标题，不提供“跳过引导”或“稍后登录”。用户协议与隐私政策从勾选说明中的链接打开；同意协议且账号状态已就绪后才能登录，有任务执行或登录处理中仍会禁用按钮。已登录时保留退出登录入口。

## 保存与锁定

- 有回复、压缩或团队任务正在执行时，页面顶部显示“有任务正在进行，完成后可修改设置。”，编辑类入口同时置灰；只是短暂保存不会锁页。
- 保存失败时顶部横幅显示具体原因；单个开关失败会恢复显示已保存的值，并弹出提示，不会把失败状态留在界面上。
- 自动提取长期记忆的说明里写明“每 10 轮后台整理，会额外调用模型”，这类后台请求会计入账本。
- “自动保存任务结果”会把成功的回答归档到工作区的“任务结果”目录。
- “只读模式”对所有对话生效，阻止修改文件与调用远程工具；“允许网页读取与搜索”只控制网页与搜索工具，不影响模型服务与浏览器权限。
- 应用内浏览器默认开启；关闭后助手不会再次请求启用。内置必应搜索依赖应用内浏览器，禁用浏览器会同时停用内置搜索。

## 搜索服务

进入 **设置 → 工具与权限 → 搜索服务**，列表展示 DeepSeek、Tavily 和必应的配置状态。点整行或右侧勾选区域只切换草稿中的提供方；“配置”进入 DeepSeek / Tavily 详情，“详情”查看必应权限与验证接管说明。列表顶部只保留搜索开关，前置的网页读取与搜索权限关闭时显示提示。

详情页“完成”把编辑结果带回列表，返回键放弃本次详情编辑。列表有改动时显示“有未保存的更改”；底部“保存”统一校验并写入，失败时保留草稿。搜索页的开关也遵循这一保存规则。配置状态表示本地配置是否齐备，不代表已验证服务余额或网络可用性。

切换到其他提供方不会删除 Tavily 密钥，切回相同地址可以复用。更换地址需要重新填写密钥；“清除已保存的密钥”也要在列表保存后才生效。当前版本不认识的提供方仍保留选中行与只读说明，可显式选择受支持的服务。

## 外观

**设置 → 界面与语言 → 界面与外观** 提供以下选项，改动立即应用并写入本机设备偏好：

| 选项 | 取值 |
| --- | --- |
| 明暗模式 | 跟随系统、浅色、深色 |
| 主题色 | 绿、蓝、紫、琥珀、玫瑰、自定义颜色 |
| 字号缩放 | 0.9、1、1.15、1.3 |
| 光感效果 | 自动、关闭、轻柔、标准、生动 |
| 字体 | 可选字体族，留空使用系统字体 |

外观偏好保存在 `preferences` 的 `tinybot-ui` 库（键 `appearance`），与对话、模型服务分开。应用启动时在创建第一帧之前应用模式与字号缩放，避免首帧闪烁；修改失败会回滚到上一个值并提示。

手机和平板共用中性的浅色／深色背景、文字、分隔线和选中态。主题色用于主操作、开关与重点状态；次要按钮使用中性底色。平板的聊天、文件与预览面板使用相同的圆角和间距。

关闭光感效果后，动效改为静态反馈；开启时按钮与卡片使用系统沉浸光感材质。胶囊、分段选择等装饰性动效另有独立的设计说明。

沉浸光感同时要求 API 26 和设备支持；仅升级系统并不代表设备支持该材质。不支持的设备使用普通配色和系统菜单背景，光感选项显示为关闭且不可选择。

“自动”按系统提供的设备材质能力选择档位，手动选择则使用对应档位。小按钮保持所选效果，展开菜单、弹出层和对话框使用更轻柔一档的材质，减少大面积透底对文字阅读的干扰；已经处于轻柔档时不再下调。长文本面板继续使用较厚的着色底层，关闭效果仍统一生效。

## 语言

**设置 → 界面与语言 → 语言** 提供“跟随系统 / 简体中文 / English”，选中项显示对勾，返回设置或重启后保留。

- 中文系统使用简体中文，其余系统语言回退到英文。
- 选择后立即生效；语言偏好同样保存在 `tinybot-ui` 库（键 `language`）。
- 聊天、团队卡片、设置、文件操作与常见提示已接入双语词条；用户消息、模型回复、自定义提示词与已有文件内容保持原文。
- 语言偏好独立保存在本机，不随会话备份覆盖；云备份也不包含它。

## 用量账本

Token 用量页把服务实际返回的用量汇总成本机账本，不估算、不推算账单。

### 数据与统计口径

| 项目 | 口径 |
| --- | --- |
| 总量 | 输入 + 输出 |
| 缓存读取、缓存写入 | 计入输入，不重复相加 |
| 推理 Token | 计入输出，不重复相加 |
| 未报告 | 服务没有返回该字段时显示“未报告”，与 0 区分 |
| 部分上报 | 只有部分请求报告时标注“（部分）” |
| 失败与取消 | 已报告的 Token 仍计入总量，并单独统计次数 |
| 日期归组 | 按本地日期与自然周（周一起算） |
| 会话归属 | 按请求记录的会话 ID；无法确定时归为“未归属” |
| 分支复制 | 不会重复累计 |

用途字段把请求分为对话、团队规划、团队执行、上下文压缩、标题生成、记忆提取、联网搜索与未分类；同一轮里的多次调用分别记录。工具活动记录名称、状态、耗时与 MCP 工具名，Skill 按使用轮次计数；活动次数不折算成 Token，旧记录不补造活动数据。

账本保存在应用目录的 `usage-records` 下：`index.json` 记录版本与页数，每页 256 条，写入走临时文件后重命名。旧的单文件账本会在首次启动时迁移，迁移完成前保留原文件作为恢复副本。写入失败会保留待写页并在下次重试，界面提示“用量保存失败：原因”。

### 页面结构

入口为 **设置 → 数据与用量 → Token 用量**。顶部筛选为今天、近 7 天、近 30 天、全部，另可按服务、模型、会话过滤；默认选择“全部”：总量包含全部历史，贡献热力图及活跃天数、最长连续天数展示近 365 天。其他时间范围下，热力图与统计遵循相同筛选；空白补位日期不可选。热力图按本地日期、周一至周日排列，可横向查看历史，点击日期查看当天 Token 与请求数。颜色深浅代表已报告 Token，圆点标记含未报告请求的日期；当天有请求即计为活跃，不把未报告当成零用量。

| 标签页 | 内容 |
| --- | --- |
| 总览 | 总 Token、输入、输出、请求数与贡献热力图；活跃天数、最长连续天数；已报告、未报告、失败/取消/进行中；可展开的 Token 明细（缓存读取/写入、推理）；按用途统计；模型分布；按周统计 |
| 会话 | 会话用量排行，可展开到轮次与每次模型调用，显示 Token 占比 |
| 活动 | 工具调用次数、失败次数与累计耗时；Skill 使用轮次 |
| 请求 | 请求明细，每条可展开用途、会话、调用序号、团队成员、任务、尝试次数、耗时、首字耗时与输出速度；分页每页 30 条 |

- 页面随本机账本更新，不汇总其他设备，也不读取服务商账户余额。
- 请求状态显示为完成、失败、已取消或“进行中 / 结果不确定”；进行中的记录不显示耗时。
- 旧账本只有在请求 ID 能唯一对应会话时才补上会话归属。
- 展开明细只读本地记录，不会重新发起模型请求。

## 存储空间

入口为 **设置 → 数据与用量 → 存储空间**。页面合并统计两处私有目录：Ability 目录中的会话、用量和反馈副本，以及 Application 目录中的工作区、附件和 CPU 日志；不读取项目授权的共享文件夹，也不汇总其他应用。

### 总览与分类

- 顶部显示 Tinybot 数据总量；设备容量与可用空间来自系统存储统计，读取失败时隐藏容量条。
- “占用明细”固定分为八类：会话记录、工作区文件、附件、修改备份、用量账本、诊断与性能日志、缓存与临时文件、反馈附件。
- 工作区文件与隐藏的 `.tinybot-review/` 修改备份分开统计，避免把审阅基线当成用户文件。
- 点按分类进入明细，按占用从大到小排列，最多显示 300 项。
- 有目录读取失败时，页面顶部提示“部分目录无法读取，统计结果可能不完整”，数字只代表成功读取的部分。

### 建议清理

“建议清理”只汇总可安全删除的部分，并在确认框中给出总量：

| 项目 | 规则 |
| --- | --- |
| 缓存 | `cacheDir` 中生成超过 10 分钟的文件 |
| 临时文件 | 工作区内超过 1 小时的 `.tinybot-*.tmp` |
| 未使用的附件 | 没有被任何会话、待发送输入、工具截图或分支引用的附件 |
| 残留工作区 | 会话已删除、目录仍保留，且其中没有 `.tinybot-review/` 修改备份的 `workspace/<会话 ID>` |

清理逐项执行并统计成功与失败数量，完成后重新统计；目录部分删除时按实际删除的文件累计释放量，读取失败的目录会让清理结果标注“可能不完整”。以下数据不会被自动清理：

- 会话记录、工作区文件和被引用的附件；删除会话仍沿用“保留工作区”的既有行为。
- 修改备份：分类页可以单项删除，但删除后对应文件将无法恢复修改前内容。包含修改备份的残留工作区不会整目录自动清理，需先处理备份。
- 诊断与性能日志：仍由开发者模式的“清除诊断数据”管理。
- 用量账本与反馈附件：分别在 Token 用量和反馈页面管理。

有回复、压缩或团队任务执行时，清理按钮不可用，避免与文件写入并发。当前版本不提供自动清理或定时策略；系统仍可能自行回收 `cacheDir`，缓存不能当作持久存储。

## 关于与帮助

聊天输入框下方常驻 12 fp 的“AI生成内容可能有误，请仔细鉴别。”，使用系统明暗主题的次要文字颜色，不随消息滚动；英文模式使用对应英文，允许自动换行。

| 入口 | 行为 |
| --- | --- |
| 使用帮助 | 打开分类帮助文章（模型配置、附件与语音、个人偏好与记忆、文件备份、连接问题），可重看首次使用指引 |
| 评分和评论 | 通过官方 Deep Linking 打开应用市场中 Tinybot 的写评论页；调用期间阻止重复打开，跳转失败显示错误信息 |
| 关于 Tinybot | 图标、名称、实际安装包的版本名称与版本号，更新说明、公告、评分入口、首次使用指引、用户协议、隐私政策、GitHub 仓库、反馈与建议、Apache 2.0 与第三方开源许可 |

- 更新说明随应用打包。远程公告从 `https://sudotinybot.cn/api/announcement` 获取，每次应用进程启动在隐私同意后检查一次，展示接口指定的当前公告；客户端不按 ID 排序。点击“知道了”后按 ID 保存已读状态，同一 ID 的内容修改不会再次提醒，新 ID 会重新提醒；接口返回 `announcement: null` 时不展示。加载失败不会阻止使用，下一次启动再试。
- 公告标题居中，左侧显示图标和“公告”小标签。弹窗按实际内容高度伸缩，期望最小高度为 240vp，上限为可用高度的 80%（小窗口优先遵守上限）。长正文独立滚动，“知道了”按钮固定在弹窗底部。
- 首次使用指引可随时重看，目前不在启动时自动弹出。
- 版本号来自 `bundleManager` 读取的实际安装包，不是写死的字符串。
- 用户协议与隐私政策在应用内全文阅读，支持滚动、复制与系统明暗主题；阅读不产生同意记录，边界见 [隐私与用户协议](/guide/privacy)。
- 系统评价弹窗的返回值不代表评论已发布，因此不显示“已评价”状态，也不保存已评价标记。

## 反馈与建议

从“关于 Tinybot → 反馈与建议”选择功能异常、产品建议或其他，填写内容（最多 5,000 个 UTF-16 单元），联系方式可选（最多 200 个 UTF-16 单元）。页面按类型、正文、图片、联系方式和可选日志分区，顶部时钟按钮打开“我的反馈”。内容作为纯文本发送到 `https://sudotinybot.cn/api/feedback`，不会自动附带聊天、日志或设备标识。

首次主动提交时创建匿名身份，先保存凭证到仅本机可用的 AssetStore，再提交反馈。后续复用凭证；401 或网络失败不会覆盖凭证。打开页面或查看空历史不会创建新身份，不依赖华为账号登录。

“我的反馈”支持状态与类型组合筛选，按接收顺序倒序分页，每页最多 20 条；翻页保留两种筛选，状态计数覆盖当前身份的全部类型。历史未分类记录保持“其他”。点开记录查看全文、附件和开发者当前回复，刷新可更新状态。“已处理”与是否回复、是否已读分别展示；对比本机已查看的回复时间显示“有新回复”，没有推送通知。

可选最多 3 张图片，每张原文件与编码后的 JPEG 均不超过 5 MiB、最多 2,400 万像素。服务端进一步转换为静态 WebP 并移除原始元数据。当前不支持视频。

日志默认不附加。勾选后自动整理本次运行最近 15 分钟、最多 1,000 条已脱敏的应用诊断日志，不需要用户查找文件。普通模式仅包含已有的警告与错误；开启开发者采集时可包含已启用的其他日志级别，但勾选不会开启开发者模式或性能采样。

本机内存缓冲不落盘，退出进程后消失，不包含聊天正文、请求体、URL、文件路径、密钥或账号凭证。勾选时直接整理为接口支持的 UTF-8 `.log`（JSON Lines 纯文本，不是压缩包），生成本机附件，点击提交反馈时一起上传；不弹出文件选择或日志检查确认页，取消勾选会移除待上传日志。没有近期记录时只附带应用版本和记录数为 0 的说明；不声称能补回上次进程退出或崩溃前的日志。文件超出本机预算时保留最新记录并标明省略数量，大小不超过接口的 2 MiB 上限。

先保存反馈正文，再逐个发送附件的原始二进制，分别显示结果。附件失败不会再次提交正文；本机保存待完成任务，重启可继续。上传超时先读取服务端附件核对；只有查询后明确确认未保存，才允许重试。详情支持带凭证下载后预览、保存副本及确认后删除自己的附件，凭证不会进入图片 URL。日志预览显示前 80,000 字符，保存副本可查看完整文件。

提交结果不确定时保留内容并阻止直接重试，重新启动也会恢复提示；先刷新近期记录并核对，明确确认后才能再次提交。限流按 `Retry-After` 等待，不自动重试。凭证和已读状态不随聊天备份导出，卸载或清除数据后无法找回旧反馈的访问权限。

## 开发者诊断入口

开发者模式是本地功能开关，不是安全边界：

1. 打开 **关于 Tinybot**，在 2 秒内连续点击版本号 7 次，弹出开发者密码输入框。
2. 输入开发者密码后开启；密码错误提示“密码不正确”，连续输错后显示冷却剩余秒数。
3. 开启后设置底部出现“开发者模式”，副标题为“性能统计、慢操作与诊断日志”。

开发者页面提供性能采样开关、帧回调、慢操作记录、CPU Profile 与诊断日志导出；导出文件写入缓存目录并由系统分享，采集内容不含任意错误文本、请求体、URL 与文件路径。实现细节见 [运行诊断与性能](/internals/diagnostics)。

## 代码入口

| 职责 | 位置 |
