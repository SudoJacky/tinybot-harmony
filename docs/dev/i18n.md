# 词条维护

应用自有文案全部来自双语词条：`locales/zh-CN.json` 与 `locales/en.json`。消息 ID 使用原始中文文本（gettext 风格），改译文不需要改调用点；两个文件的消息 ID 必须完全一致。

## 调用方式

```ts
import { t } from '../model/I18n';
t('保存');
t('展开全部 {0} 行', [lineCount]);
```

- 值或语序会变化时，使用带编号占位符的整句，`{0}`、`{1}` 在各语言中保持一致，译者可以调整顺序。
- `{{input}}` 属于提示词模板，按字面保留。
- 传参而不是拼接消息 ID。
- 不翻译用户消息、模型回答、自定义提示词、文件名和已保存内容。

## 生成与检查

修改词条后依次运行：

```powershell
node scripts/build-locales.cjs
node scripts/build-locales.cjs --check
node scripts/test-i18n-native.cjs
```

生成器检查键一致性、占位符和代码中每一处字面量 `t()` 引用，并产出 `model/LocaleCatalog.ets` 供同步查表；不要直接编辑生成文件。`build-locales.cjs --check` 已纳入 `scripts/test.ps1`，词条与代码不同步会直接失败。

## 语言选择

设置提供**跟随系统**、**简体中文**和**English**。中文系统变体使用简体中文，其他语言回退英文。设备偏好保存在 `tinybot-ui` Preferences 中，与聊天备份和凭据相互独立。`EntryAbility` 在配置变化和前台进入时刷新。

生效语言变化会重建视图树，但保留会话 ViewModel、导航栈和已保存草稿；模型请求和用户内容不会被改写。

## 工程约定

- 模块级标签集合必须是惰性函数，否则会冻结启动时的语言。
- 自动生成的会话默认标题按当前语言显示；手动改名和历史消息保留原文。
- 已保存的历史错误与工具记录保持原语言，新错误使用当前语言。
- 原生系统选择器跟随设备语言；系统可见的 Ability 描述使用原生 `base` 与 `zh` 资源。

## 验证范围

测试覆盖语言回退、显式覆盖、参数替换、特殊字符、词条对齐、初始化后持久化与保存失败回滚。英文界面还需在设备上检查换行，较长标签可能溢出。

## 代码入口

| 路径 | 职责 |
| --- | --- |
| `locales/zh-CN.json`、`locales/en.json` | 词条源文件 |
| `scripts/build-locales.cjs` | 生成 `LocaleCatalog.ets` 并校验 |
| `entry/src/main/ets/model/I18n.ets` | `t()` 查表与参数替换 |
| `entry/src/main/ets/model/LocaleCatalog.ets` | 生成的同步目录，不手改 |
| `scripts/test-i18n-native.cjs` | 原生语言偏好与持久化验证 |
