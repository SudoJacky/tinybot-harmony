# 使用指南

[文档索引](README.md) · [项目首页](../README.md)

## 华为账号登录

首次使用引导的第一步会引导验证华为账号，也可从聊天底部的“去登录”或“设置 → 华为账号”进入；阅读用户协议和隐私政策、勾选同意后点击“华为账号登录”。无需另行注册 Tinybot 账号，不获取姓名、手机号或身份证号。未登录可查看历史、配置服务和准备草稿；聊天、标题、摘要、团队及记忆提炼等模型调用需要登录。普通账号登录不等同于真实身份核验。

登录记录仅保存在本机系统安全存储，不随会话备份或云空间备份导出。重启和每次模型请求前会检查当前设备账号；系统账号退出或变化后需重新登录。退出 Tinybot 登录不会退出设备华为账号，也不会删除会话、文件或模型配置。登录失败会显示具体错误码；签名校验失败时需检查平台的 Client ID 和签名指纹。

## 聊天与界面

首次使用时，吉祥物 Tiny 会陪你经历六幕引导：验证华为账号、轻点唤醒、拖动认识、连接模型、能力小剧场和第一条消息。账号步骤可稍后登录，未登录仍可配置模型和准备草稿；可随时跳过；已配置服务、有聊天或草稿的用户不会自动进入。完成或跳过后不会在重启时再次弹出，可从“设置 → 使用帮助”或“关于 Tinybot → 首次使用指引”重新体验。动效在后台、不可见或被其他页面覆盖时暂停，关闭外观效果后使用静态反馈；唤醒途中被打断后，需要轻点“继续”，不会在后台自动翻页。

模型页按顺序提供 DeepSeek、Z.ai、Ollama，也可添加其他服务。切换选项保持单选；云服务的“填写 API Key”和 Ollama 的“连接模型”进入现有的服务配置页，密钥仍由系统安全存储保管；取消会返回引导，保存后根据当前模型配置更新状态。没有 Key 时可先逛逛。按钮与卡片跟随应用主题，继续按钮、服务商卡片、建议按钮和返回按钮使用系统沉浸光感，随外观效果设置调整或关闭；选中与禁用状态保持清晰。Tiny 的橙色圆点保留品牌配色。同一个 Tiny 贯穿六幕，随内容平滑移动、缩放，并呈现困倦、惊喜、好奇、专注与开心等表情；前进和返回使用方向一致的内容过渡，关闭外观效果后直接切换。能力小剧场可以左右滑动，轻点 Tiny 查看聊天、资料与草图、Skills 的本地示例，不调用模型或操作实际文件。最后可选择建议或编辑第一条消息，“带进聊天”只准备独立草稿，仍需自己发送；跳过不改动已有草稿。聊天与工作区保存在本机，调用模型时会向所选服务商发送消息和附件。

- 原生聊天、会话列表、新建与确认删除；界面跟随系统明暗主题。
- 点击菜单、长按菜单和推理强度弹框显示时，以跟随明暗主题的半透明遮罩淡化背景；点击遮罩关闭，原生确认框与底部面板保留系统遮罩。
- 增量文本显示、停止生成、失败后重新编辑发送；明确区分完整、停止和失败状态。
- 每轮回答共用一条工作流状态线，跟随真实事件显示等待模型、思考、执行工具、生成回答及完成/停止/失败。最外层状态线展开后，按时间顺序列出思考和工具调用；两类条目均默认收起，分别点击查看内容，不再嵌套中间的“已思考”分组。较长思考可继续加载，工具参数和结果按需查看。新记录轻柔进入；完成后平滑收束为耗时摘要和回答，手动展开的过程保留，失败次数及已发布预览仍可见。运行中也可折叠过程，重试原因单独保留。
- 思考、整轮状态和运行中的工具条目统一使用轻微呼吸图标、文字扫光；工具完成后显示对勾，失败保留红色提示，状态改变时短暂淡化、微移并交叉渐变到新文案。过程箭头平滑旋转，展开内容轻微渐入；历史记录静态显示，离屏、后台、关闭外观效果或完成后停止循环动画，用户手动展开的内容不会被动效强制收起。网页读取完成后保留站点图标。
- **交互预览**：助手直接编写 JS、HTML 或 SVG，通过 `publish_preview` 在聊天中展示交互页面、动画和 Three.js 场景，与独立浏览器会话分开。发布成功的内容快照可在重启后恢复；页面内的临时输入状态会在视图释放后重置。旧 JSONL 界面不再支持，会明确显示错误。详见[交互预览与验证](interactive-ui.md)。
- 输入框中的 **麦克风胶囊**使用鸿蒙 Core Speech Kit 离线识别中文（包括中文语境下的英文），首次使用申请麦克风权限。点按开始、再次点按停止；按住说话、松手结束，左滑或点“取消”撤销本次听写。胶囊展开显示计时与语音活动动效，文字实时写入 composer，原草稿保留，仍需手动发送；切到后台或离开聊天停止录音并保留已输入文字。每次最长 10 分钟，不保存录音、不调用模型服务。依赖设备的系统识别引擎；拒绝授权或引擎失败会明确提示。接入与验证见[语音输入](speech-input.md)。
- 消息下方使用紧凑的纯图标操作栏，每项只出现一次并保留无障碍名称。助手回答提供复制、选择文本、朗读、重新生成、分支和提炼记忆；朗读时图标切换为停止。用户消息提供复制、选择文本和改写，**改写** 将该消息恢复为新分支草稿。按钮区域为 36×44，窄屏自动换行；正文长按仍可打开文字菜单。**选择文本** 在独立面板中提供系统选词、复制和引用，关闭后返回对话。
- 输入框空白且未聚焦时收为单行胶囊，提示文字与添加、语音按钮垂直居中；点击输入后平滑展开，上下文用量与推理强度等工具渐显。有文字、附件或引用时才渐显发送按钮，并平滑移开语音入口；草稿、附件、语音输入、运行中任务或待发送队列会保持展开。收起键盘且清空内容后平滑恢复紧凑状态。
- 消息发送并进入列表后自动收起键盘；发送前校验未通过时保留输入焦点。新消息气泡从输入区轻快上浮并落入消息列表，文字、附件和引用一起移动；历史消息不会重播。超长消息使用短距离渐显，避免大块内容飞过整个屏幕。动画不延迟模型请求。
- 会话顶部完整显示会话名、服务商图标和模型；向下阅读时，中间信息与模糊背景随滚动上移淡出，接近顶部再逐渐恢复。左侧会话列表、右侧更多与新会话按钮始终固定，并保留各自的光感材质。
- 输入框获得焦点并弹起键盘时跟随最新消息，键盘显示期间隐藏底部免责声明。记忆编辑和文本选择面板的底部操作区避让系统手势条；服务删除收纳到编辑页的 **更多操作** 中，仍需二次确认。
- **会话分支树**展示父子关系，可返回来源消息；会话搜索显示匹配摘要，打开后定位消息并突出显示。

“设置 → 语言”使用与其他设置一致的独立页面，从右侧进入。选择“跟随系统 / 简体中文 / English”后立即生效，选中项显示对勾，返回设置或重启后保留。中文系统使用简体中文，其余系统语言回退到英文。聊天、Team 卡片、设置、文件操作及常见提示已接入双语词条；用户消息、模型回复、自定义提示词和已有文件内容保持原文。语言偏好独立保存在本机，不随会话备份覆盖。

## 项目与文件

左侧栏按“项目 → 会话”显示，可展开、收起项目；未归属项目的会话集中在“普通聊天”。项目右侧的加号在该项目内新建会话，顶部“新对话”创建普通聊天；空项目仍保留标题和新建入口。项目菜单可编辑项目、打开项目文件。搜索会自动展开匹配分组，置顶会话在各自分组内优先显示。项目内会话共享文件与项目说明，保留各自的聊天历史。详细规则见[项目、会话与共享工作区](projects-and-workspaces.md)。

从搜索或“已归档”页面新建项目成功后，会清除搜索并回到“对话”列表，展开新项目；编辑已有项目保留当前筛选条件。

## 附件、引用与分支

- **+ → 画板**：使用 HarmonyOS Pen Kit 系统画布和工具栏，支持手指绘制、圆珠笔、钢笔、铅笔、马克笔、荧光笔、颜色与粗细、橡皮擦、套索及撤销重做；隐藏马赛克和激光笔以精简工具栏。画板采用紧凑顶栏和圆角白色画布，顶部关闭和添加按钮使用系统沉浸光感材质，跟随应用外观设置。点击右上角“添加”将笔迹区域导出为白底图片并加入当前草稿，可预览、移除或补充文字后发送，也可单独发送；不会自动请求模型。手绘图片与其他附件共用每条消息 4 个的上限，需要支持视觉输入的模型。关闭未添加的绘画会提示确认；未添加的画稿不跨应用重启保留。设备需支持系统手写能力，否则明确提示不可用。工具栏由系统控制，收起后变成单支浮动笔，点击可展开。
- 输入 `@` 搜索其他会话标题，或从 **+ → 引用其他会话** 进入。每条消息最多引用 4 个会话，可预览、移除；发送时携带选择时的文字快照，原会话之后修改或删除不影响已保存的引用。每份预览最多 8000 字符，超长时保留完整文字快照供模型按需补读；仅引用完整轮次的正文，不包含思考、附件和工具记录。引用暂不支持任务排队。
- 聊天框 **+**：添加图片或文档附件；右上角更多菜单提供文件、分支、导出和统一设置入口。每条消息最多 4 个附件；UTF-8 文本不再限制 64 KiB / 32000 字符，完整保存；不超过 50 KiB 且不超过 2000 行的文本直接进入消息，大文本由 read_attachment 按需分段读取，每次最多 2000 行或 50 KiB，未读完时返回续读位置；图片原文件限 20 MB，最长边缩小至 1600 px 并转 JPEG，结果限 4 MB。需要选择支持视觉输入的模型。附件消息可单独发送；任务队列目前仍只接受文本。
- PDF、DOCX、XLSX、PPTX 附件支持提取文字，原文件最多 8 MB。PDF 最多 100 页、Office 受解压大小限制，文字超过 31000 字符明确截断；保留页码、工作表和单元格等可用位置。当前不做扫描件 OCR、不保留 Office 排版；保存的是提取的文本副本。附件预览中可选择文本引用。
- **长会话引用补读**：`@` 引用的预览仍最多 8000 字符；超过时同时保存选择当时的完整用户/助手文字快照，`read_reference` 按消息 ID 和源会话 ID 分页补读。之后源会话变化不影响快照，也不能读取未引用的会话。老数据没有全文时明确标记仅预览。

文件读取策略参考 pi 的工具输出分页；文本附件采用完整保存、按需读取的方式，与 pi CLI 的 `@文件` 全文注入有所不同。当前文本仍会完整解码到内存并保存在会话数据中，实际容量受设备资源影响；上下文预算和 20 MiB 备份总量限制仍生效。

会话分支与重新生成的文件行为见[项目与工作区](projects-and-workspaces.md#会话分支与重新生成)。

## 压缩、追加指令与任务排队

- 输入 `/compact` 并发送，或从 `/` 命令建议中选择，即可调用当前模型压缩较早上下文；完整记录保留，不新增聊天消息。失败时命令留在草稿中，压缩期间新输入的内容不会被清空。

聊天输入框在执行期间保持可用：

- **追加指令**：沿用 Pi Agent 的 steering 语义。等待当前模型响应和整批工具调用完成，在下一次模型请求前按顺序接收一条追加指令；不打断或回滚正在执行的工具。即使模型本来准备结束回答，有待接收指令时也会继续响应。
- **加入队列**：当前任务成功结束并保存后，自动依次启动后续任务。每项任务是独立的用户/助手轮次，保留各自的 200 次模型调用上限和上下文预算；追加指令优先于后续任务。
- 待发送列表可展开、收起、**撤回编辑**或**移除**。撤回时若已有草稿会提示先处理草稿；队列执行不会清空另行输入的草稿。空闲时也可以先添加多个任务，再点击**继续队列**。
- **停止**会终止当前执行并暂停后续任务；模型或保存错误也会停止自动续跑。未开始的指令保留，重启后始终暂停，点击**继续队列**才恢复。手动发送新消息不会恢复已有的暂停队列。
- 队列按会话分别保存，最多 20 条，每条最多 24000 字符；沿用当前会话选择的模型。运行时不能切换会话或模型。追加指令记录在它进入模型上下文的位置，参与历史回放、搜索和上下文压缩；消费指令与记录历史在同一次检查点保存。
- 当前运行固定工具和 Skills。运行中用 `/skill:名称` 切换 Skill 时，请使用**加入队列**，在下一项任务开始时加载。已有待办暂停时，新一轮也保持该队列暂停，可继续加入待办。

输入区的模式菜单可选择“完整版”或“自定义”。添加菜单中的“自定义工具”也可打开 12 项能力开关：基础文件读取、检索和编辑始终保留，浏览器、预览与图表、团队协作和 MCP 远程工具分别统一开关。开启数量和“全部开启/全部关闭”在同一行。记忆工具与后台提取统一使用设置中的“自动提取长期记忆”开关；Skills 使用专门管理页面的单项开关，自定义工具不再重复提供这些设置。旧会话中的记忆和 Skills 禁用记录会清除，其他只关闭部分配套工具的能力保持整组关闭。关闭的能力不会提供给 Agent、编排代码或团队员工；模型/服务配置及原有授权仍然生效。完整版保留自定义设置，切换回来可继续使用。选择随下一条有效消息保存，分支继承当前选择；运行时不能修改。

团队并行工作见[聊天中的团队协作](teams.md)。

## 记忆、偏好与模板

- **设置 → 管理长期记忆**：新增、修改、删除背景资料；范围为所有对话或当前对话。消息的更多或长按菜单中，提炼为记忆先调用记忆模型（未指定则使用当前模型）提炼最多 5 条、每条最多 200 字符的候选；可以逐条编辑、勾选或手动补充，确认后才保存，默认仅用于当前对话。长消息只提炼前 12000 字符；助手回复结合前一条用户消息判别依据，不直接作为用户事实。没有新信息、取消或提炼失败都不保存原文。确认时再次去重并记录来源；旧记忆不自动修改。设置首页可独立开启“自动提取长期记忆”，开关立即保存：成功任务后额外调用指定模型，仅从本轮用户消息提取事实，过滤已存在的相同条目，并保存来源会话与消息；不覆盖手动记忆。按最近更新时间在 16000 字符预算内注入；超出时提示模型未加载全部条目。自动提取默认开启，当前去重为规范化文本匹配。
- **设置 → 提示词模板**：管理常用提示词，使用 `{{input}}` 插入当前草稿；套用后返回输入框供编辑，不自动发送。
- **设置 → 用户文档（USER.md）**：编辑全局 Markdown 偏好文档，填写称呼、背景与回答偏好；保存后从下一轮起附加到所有对话及团队执行的上下文，清空即可停用。系统提示词固定由应用维护，用户文档不能覆盖系统规则或工具权限。旧版自定义系统提示词会原样迁移到此文档，旧版内置默认值不迁移。当前文档内容随本机会话配置原子保存并纳入备份，不在各会话工作区重复创建同名文件。导入备份时，仅在本机用户文档为空时恢复备份中的偏好，保留本机已有的非空文档。
- 固定任务规则支持只读工具限制、写入前基线、成功回答归档到“任务结果”目录；自动提取长期记忆默认开启，模型路由和归档默认关闭，可分别调整。

系统指令的组装方式见[系统提示词](system-prompt.md)。

## 模型、工具与设置

- 通过注册表选择 DeepSeek、DashScope、OpenAI、Z.ai、Ollama 或自定义兼容服务；提供与桌面 Tinybot 对齐的模型预设，仍可手动填写模型名称和地址。添加服务与已添加服务列表显示对应品牌 Logo，单色标志适配明暗主题，自定义服务使用通用图标；资源随应用打包，无需联网加载。支持 Chat Completions、OpenAI Responses 和 Anthropic Messages 三种流式协议。
- **统一设置**：集中提供模型服务、长期记忆、助手行为、工具与扩展、数据与用量、隐私和语言设置。常用开关立即保存；语言、外观选项、添加模型服务、模型管理与发现，以及记忆、模板、MCP 编辑均从右侧进入独立页面。模型列表修改保留在服务草稿中，保存服务后生效；用量筛选和开发者模式验证保留临时弹层。
- **统一设置 → 模型分工与能力**：配置模型的视觉支持、上下文窗口、推理强度和流式用量请求；模型服务编辑页可从服务的 `/models` 接口发现模型，仍可手动录入。推理强度适用于兼容 Chat Completions/Responses 的服务，Anthropic 当前使用服务默认。自动路由可指定快速、深度、视觉模型，按图片、问题长度和分析关键词选择；每轮记录实际模型，不更改会话的手动选择。

模型地址、预设和限制见[模型与上下文](models-and-context.md)；网页、搜索及 Skills 见[使用说明](web-and-skills.md)，MCP 见[远程 MCP](tools-and-permissions.md#远程-mcp)。

## 用量统计

- 用量账本保存服务实际返回的输入/输出、缓存和推理 Token，以及耗时、首字时间和速度。未报告的指标显示未知，不用估算冒充账单；异常结束仍保留请求记录。
- **Token 用量统计**：从「设置 → Token 用量」打开；侧栏和聊天更多菜单均通往同一设置首页。支持今天、近 7 天、近 30 天、全部时间及服务/模型筛选，展示总量、输入/输出、缓存读取/写入、推理、每日趋势、模型分布和分页请求明细。按本地日期归组，全部时间的趋势图仅展示近 30 天；失败/取消请求中已报告的 Token 仍计入总量，缓存与推理不重复相加，未报告与零明确区分。页面随本机账本更新，不汇总其他设备或服务商账户余额。
- **会话与调用归属**：用量页分为总览、会话、活动、请求；可按会话筛选，并从会话排行展开到轮次和每次 LLM 调用。同一轮的多次调用、标题生成、记忆提取、上下文压缩和团队执行分别记录，按用途及自然周汇总 Token；团队调用保留成员、任务和尝试次数。旧账本仅在请求 ID 能唯一对应会话时补充归属，分支复制不会重复累计，无法确定的记录显示为未归属。新增工具活动记录名称、状态、耗时和 MCP 工具名，Skill 按使用轮次计数，活动次数不折算成 Token，旧记录不补造活动数据。

## 备份、分享与帮助

- 备份 v2 包括项目、会话、附件、工作区、Skills、模板和记忆，最多 20 MB；共享工作区只打包一次，无会话的项目也保留文件。兼容 v1 备份并恢复为普通会话。导入保留项目与会话 ID，跳过已有会话；已有项目沿用本地名称、指令和文件，新项目文件准备到独立目录后才提交归属，现有数据和助手选项不覆盖，模型及 MCP 凭据不导出。恢复保留本机已有 Key、Token 和服务设置，复用能明确匹配的服务；新增或匹配不明确的服务作为停用副本导入，需要配置凭据。
- 系统分享面板可选择 Tinybot 接收文本、链接和图片。内容进入新对话草稿，用户审阅后发送；运行中的任务结束后再接收。仅使用系统授予的 URI，不申请整个图库或外部文件夹权限。
- **关于与帮助**：设置底部提供使用帮助、评分和评论、关于 Tinybot；展示实际安装版本、本地更新说明、公告和可重看的首次使用指引。评分和评论入口直接打开华为系统评价弹窗，支持星级评分与撰写评论。用户协议与隐私政策分别打开应用内全文页面，可离线阅读和复制。聊天输入框下方常驻“AI可能会犯错，请仔细鉴别。”，支持中英文和系统明暗主题。接入与验证边界见[关于与帮助](about-and-help.md)。

支持在「设置 → 备份与恢复」手动备份到个人**华为云空间**、刷新列表、恢复为独立副本，以及确认后删除指定备份。删除同步到云端及其他设备，不影响当前对话和设置。需先在系统云空间开启 Tinybot；仅保存在本机的快照会明确显示待上传，配置中的密钥不导出。功能与验证边界见[云备份说明](cloud-backup.md)。
