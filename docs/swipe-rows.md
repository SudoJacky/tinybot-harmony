# 滑动操作行

记忆、模板、MCP 服务及工作区文件共用 `common/SwipeRow.ets`，依据 SwipeRow 视觉参考
独立实现 ArkUI 手势、抽屉及弹性动画，没有复制 React 组件源码或引入网页依赖。

- 左滑跟手展开删除区，超过 80 vp 后带阻尼；松手按距离和方向停靠或收回。
- 松手后的回弹由原生 animator 的物理弹簧驱动，卡片和删除区连续运动；再次拖拽时从当前显示位置接续。取消旧动画的终点回调不再改写位置。
- 深滑展开区达到行宽的 52%（至少 120 vp）时，垃圾桶盖抬起，松手调用现有删除确认；退回阈值内桶盖合上，快速反向拖回不提交。阈值按带阻尼的展开距离计算，正常短滑仍只露出删除按钮。
- 点击删除也进入相同确认流程。取消或保存失败不会提前从列表移除数据。
- 每个面板只展开一行。切换页签、离开可见区域、变为忙碌状态时收回；组件退出时取消动画。
- 记忆与工具通过顶部标签切页，列表中的横向手势专用于行操作，避免与 Tabs 自带滑动抢占。
- 操作区适配行高；浅色和深色主题均使用可读的危险色文字。
- 长按提供删除入口；工作区文件还保留分享和导出。文件夹与链接保持原有交互。

`SwipeRowMotion.ets` 只处理距离、阻尼、触发阈值和停靠判断。
`SwipeRow.test.ets` 验证短滑、深滑、快速回滑、窄行保护及拖动边界。
回弹中间帧及动画中途再次拖拽需在设备上验证；物理弹簧不能通过 `ICurve.interpolate()` 取归一化时间的插值。
