# 安装与首次启动

这页说明 Tinybot 在什么设备上可安装、安装包从哪里获取、第一次打开时应用写了哪些数据，以及卸载、清除数据和升级各自会影响什么。

## 设备与系统要求

| 项目 | 要求 | 依据 |
| --- | --- | --- |
| 设备形态 | 手机（`phone`），不声明平板或 PC | `entry/src/main/module.json5` 的 `deviceTypes` |
| 最低系统 | HarmonyOS API 26，`compatibleSdkVersion` 为 `26.0.0` | `build-profile.json5` |
| 目标系统 | `targetSdkVersion` 为 `26.0.0` | `build-profile.json5` |
| 发布包架构 | 仅 `arm64-v8a` | `docs/distribution/START-HERE.txt` |
| 模拟器 | 使用单独构建的调试包（含 `x86_64`），不随正式包分发 | `docs/distribution/START-HERE.txt` |

当前版本为 1.0.3 / 1000003，包名 `com.sudojacky.tinybot`。应用不内置模型额度，也不在手机内运行大模型；模型能力、费用与可用性由你配置的模型服务（Provider）决定。

## 安装包从哪里来

| 来源 | 产物 | 前置条件 |
| --- | --- | --- |
| 华为应用市场 | 已签名的发布包 | 应用已上架且对该设备可见；上架状态、年龄分级与发布地区以市场页面为准 |
| 交付目录 | `packages/Tinybot-1.0.3-1000003-release-UNSIGNED.app` 与同名 `.hap` | 需完成正式签名后才能安装或提交审核 |
| 本地构建 | `entry/build/default/outputs/default/entry-default-unsigned.hap` | 需要 DevEco Studio API 26 SDK 与 DevEco CLI，见[环境、构建与签名](/dev/setup) |

交付目录由准备脚本生成：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\prepare-distribution.ps1 -StudioRoot "C:\Program Files\Huawei\DevEco Studio"
```

脚本先检查 ArkTS，再构建 Release APP，核对版本号、`app.debug=false`、包内容、arm64 沙箱库与符号表 Build ID，最后生成独立目录与 ZIP。`-SkipBuild` 只打包既有产物，仍校验结构与版本，但不能证明包含最新代码。

两点容易踩空：

- 目录里的 `UNSIGNED` 文件不是可安装包。Release 编译不等于发布签名，需要在 DevEco Studio 的 Build > Upload Product 选择 `build\outputs\default\tinybot-harmony-default-unsigned.app`，关联包名 `com.sudojacky.tinybot`，用对应发布证书或云管理签名重签。
- 本地 `devecocli build` 在未配置签名时生成未签名 HAP；真机调试需要先 `devecocli auth login` 与 `devecocli signature generate`，再用 `devecocli run --device <设备>`。

## 首次启动做了什么

启动过程按固定顺序完成，界面在数据就绪前显示“正在打开本地会话…”，失败时显示错误与“重试读取”。

1. `EntryAbility` 在首屏创建前应用外观与语言偏好，然后加载页面。
2. 组装原生会话服务：会话仓库、运行内核、系统安全存储、工作区与附件目录、模型服务注册表。
3. 读取会话仓库：没有 `sessions-v2/index.json` 时尝试旧版 `tinybot-v1.json`，两者都没有则创建空数据并立即保存。
4. 校验项目数据，安装内置 Skills 的本地副本，检查每个项目的工作区是否存在（不自动创建），并为每个普通会话补建目录；已暂停的待发送队列在加载时保持暂停。
5. 选中上次的会话；没有可用会话时新建一条空会话并保存。
6. 数据就绪后再判断是否展示首次使用引导。

### 首次使用引导

引导是一个独立导航页，共五幕：

| 步骤 | 内容 | 交互 |
| --- | --- | --- |
| 华为账号 | 登录或稍后登录 | 同意协议后可登录，也可稍后再配置 |
| 第一次见面 | 轻点叫醒 Tiny | 轻点唤醒；唤醒途中被打断需手动继续，不在后台自动翻页 |
| 认识 Tiny | 台词与三页作品示例 | 报告、行程、摘要可点击侧页、页码点或左右滑动切换；第二句台词期间展示一轮后停在报告页，手动切换会停止自动展示 |
| 连接模型 | 选择 DeepSeek、Z.ai、Ollama 或添加其他服务 | 云服务进入“填写 API Key”，Ollama 进入“连接模型”；可取消返回引导 |
| 第一个任务 | 选择建议或编辑首条消息 | “带进聊天”只准备独立草稿，仍需自己发送 |

作品均为本地演示，不调用模型、不读取真实资料或创建文件。翻页时 Tiny 会短暂低头看作品；关闭动效时只显示当前静态纸页，仍可滑动或用页码点切换。内容区高度小于 520vp 时隐藏两侧纸页；切到后台或离开介绍页会停止播放。

连接模型时，点入服务地址或 API Key 后会暂时隐藏服务商卡片；页面保持原高度，键盘覆盖底部备注和操作，只让当前输入框避开键盘。Tiny 在填写服务地址时保持正常表情，仅在输入 API Key 时捂眼并短暂偷看。收起键盘后恢复服务商卡片和底部操作，不会自动保存配置。

Tiny 从登录页开始休息，叫醒后会在本次引导中保持清醒，返回上一页无需重新叫醒。打招呼是一次短动作；示例轮播时持续看向作品，结束后抬头。填写密钥会让 Tiny 重新捂紧眼睛，停下约一秒再偷看。保存时专注，成功时庆祝、点亮小球，失败时摇头；带进聊天前会先做告别动作。减弱动效时省略这些运动和告别等待，后台或离页会取消未完成的动作。

是否自动弹出由两个条件共同决定：偏好库中没有 `onboardingComplete`，且当前数据仍是“新用户形态”——未配置模型、没有模型服务记录、没有项目、至多一条会话，且该会话没有消息、草稿、附件、引用、待发送输入、置顶、改名、归档或分支归属。已完成配置、已有聊天或草稿的用户不会自动进入。

跳过会写入完成标记并返回原聊天，不改动已有草稿；完成会写入标记，并按需要新建一条独立会话、把所选文字放进草稿。两种结果都不会在重启后再次自动弹出。重看入口是“设置 → 使用帮助 → 首次使用指引”或“关于 Tinybot → 首次使用指引”，进入的是同一个页面。

### 还没有配置模型或没有登录时

- 未配置模型时，空会话欢迎页显示“先连接一个模型服务”，按钮“连接你的模型”直接进入设置。
- 未登录华为账号时，聊天底部提示条提供“去登录”；未登录仍可查看本地历史、配置服务、准备草稿和附件，发送时才要求登录。
- 标题、摘要、团队执行与记忆提炼等模型调用同样需要登录。

## 网络与权限

应用只声明两项权限：

| 权限 | 用途 | 申请方式 |
| --- | --- | --- |
| `ohos.permission.INTERNET` | 访问你配置的模型服务、网页读取、搜索、MCP 与云备份 | 安装时授予，无运行时弹窗 |
| `ohos.permission.MICROPHONE` | 语音输入，使用系统语音识别服务（支持中文离线识别） | 首次开始录音时由系统弹窗询问，场景为使用时（`inuse`） |

其余外部文件访问都通过系统选择器返回的 URI 完成，不申请图库或整个外部文件夹权限：

- 添加图片走系统图片选择器，添加文档走系统文件选择器。
- 导出文件走系统保存选择器，分享走系统分享面板。
- 应用内浏览器需要先确认启用；联网工具默认开启，可在设置中关闭“允许联网”，关闭后网页读取与搜索都不再提供给模型。
- 华为云空间备份要先在系统“设置 → 云空间”登录华为账号并开启 Tinybot。

应用不提供独立的代理设置，网络请求走系统网络栈；需要代理的网络请在系统层配置。

## 数据存放位置

会话与工作区都位于应用沙箱（Sandbox）内，路径由系统分配，应用不改用公共目录。会话使用 UIAbility 的 `filesDir`，工作区与附件使用应用级 `ApplicationContext.filesDir`，下面的 `<filesDir>` 按数据类别分别指这两处：

```text
<filesDir>/sessions-v2/index.json        会话索引（v2 清单）
<filesDir>/sessions-v2/<uuid>.json       单个会话的全部消息与回执
<filesDir>/tinybot-v1.json               旧版单体会话文件（迁移后保留）
<filesDir>/usage-records/index.json      用量账本清单
<filesDir>/usage-records/<页>.json       用量账本分块
<filesDir>/usage-ledger.json             旧版账本（迁移后保留）
<filesDir>/workspace/<工作区ID>/         会话或项目工作区
<filesDir>/workspace/<工作区ID>/.tinybot-review/   文件审阅基线
<filesDir>/attachments/<uuid>.jpg|.txt   附件副本
```

另有三类数据不在上述目录：

| 数据 | 位置 | 进入备份 |
| --- | --- | --- |
| 首次使用记录、界面偏好 | 偏好库 `tinybot-ui`（由系统管理） | 否 |
| 模型与 MCP 凭据 | 系统安全存储 | 否，备份与导出都不含密钥 |
| 云备份快照 | 系统云目录 `tinybot-backups` | 本身就是备份产物 |

具体目录职责与字段见[磁盘布局](/reference/storage)。

## 卸载、清除数据与升级

**卸载应用或清除应用数据**都会删除沙箱内的全部内容：会话、工作区文件、审阅基线、附件、用量账本、偏好与首次使用记录，模型密钥也需要重新填写。华为云空间中的快照不受影响，重装后可在“设置 → 备份与恢复”刷新列表并恢复为独立副本；恢复保留会话与项目 ID，已有会话不会被覆盖，本机已有密钥和服务设置优先。

**升级**的约束：

- 必须使用相同签名覆盖安装，不卸载、不清空数据；只在干净环境验证全新安装。
- 版本号需要递增，否则平台会拒绝同一 `versionCode` 的再次上传。
- 首次加载旧数据时会把 v1 单体会话迁移为 v2 索引与独立会话文件，原 `tinybot-v1.json` 保留；只重写变化的会话，先写内容再原子切换索引。
- 内置 Skills 以本地副本安装，升级不覆盖同名用户 Skill，也不恢复被停用或删除的条目。
- 旧版工具禁用记录在加载时清理；1.0.1 移除了图片生成设置、开关与执行接口，但保留图片附件输入、模型图片理解和历史图片查看。
- 本地备份与云备份都兼容 v1 格式，v1 备份恢复为无项目归属的普通会话。

升级后的回归重点是会话、模型配置、草稿与工作区是否完整，可参考[发布清单](/dev/release)。
