# 第一次对话

这页带你从空会话走到第一条完整回答：新建会话、选模型、发消息、看流式输出、停止、附加文件、打开交互预览，并说明回答最终存在哪里。

## 新建一条会话

首次使用引导包含六幕：验证华为账号、轻点唤醒 Tiny、拖动认识、连接模型、能力小剧场和第一条消息。首步阅读用户协议与隐私政策并勾选同意后，可调用系统华为账号登录；登录成功后显示已确认状态，也可选择“稍后登录”继续配置模型和准备草稿。未登录仍不能调用模型。

引导可随时跳过，也可从“设置 → 使用帮助”或“关于 Tinybot → 首次使用指引”重看。最后的“带进聊天”只准备独立草稿，由用户发送；跳过不改动已有草稿。后台或覆盖页暂停动效，唤醒中断后由用户点击继续。

三个入口，落到同一件事上：

| 入口 | 位置 | 归属 |
| --- | --- | --- |
| 新建对话 | 聊天页标题栏右侧 | 沿用当前会话的归属：在项目内创建项目会话，在普通聊天里创建普通聊天 |
| 新对话 | 侧栏顶部按钮 | 不归属任何项目（普通聊天） |
| 加号 | 侧栏某个项目分组标题右侧 | 该分组对应的项目 |

侧栏的“新对话”固定创建普通聊天；标题栏的“新建对话”沿用当前归属；只有项目分组标题旁的加号明确把新会话放进该项目。

新建会话会立即保存并切换到它。当前会话未被编辑（没有消息、草稿、附件、引用、待发送输入，也没改名、置顶或分支归属）且归属相同时，重复点击“新建对话”会复用当前会话，不重复创建会话或目录。

## 选择模型服务

标题栏中间显示当前会话的“服务商图标 · 模型名”。点击它进入“选择模型”：

- 已添加的服务与模型按服务分组列出，可按服务名或模型 ID 搜索；选择后写入当前会话，不改动其他会话；当前用于新对话的模型带“新对话默认”标记。
- 尚未添加任何服务时，标题副行显示“选择模型”，空会话欢迎页出现“先连接一个模型服务 / 连接你的模型”卡片；当前模型不可用时，副行显示模型名并附带“· 不可用”。
- 空会话更换模型会同时更新新会话的默认模型；已有消息的会话只改自身。
- 服务被删除、停用或模型被移出列表后，该会话显示不可用，需要重新选择，应用不会自动切换到其他服务。

服务地址、协议、预设模型与上下文预算见[模型服务与上下文](/guide/models)，凭据与请求细节见[模型服务与凭据](/internals/providers)。

## 发一条消息

输入框在空白且未聚焦时收成单行胶囊，点击后展开。以下任一条件成立时出现发送按钮：有文字、有附件、有会话引用。发送前会检查：

1. 已登录华为账号，未登录时先打开“华为账号”页。
2. 会话未归档、当前没有进行中的任务、没有未处理的保存错误。
3. 输入非空（文字、附件、引用至少一项）。

除登录跳转会打开账号页外，发送被拒绝时输入框保持内容与焦点，不会静默清空。发送成功后键盘自动收起，消息进入列表，回答开始流式生成。

## 流式回答与停止

助手回答上方有一条工作流状态线，按真实事件切换文案：

| 阶段 | 显示 |
| --- | --- |
| 等待首个数据 | 等待模型响应 |
| 收到推理内容 | 正在思考 |
| 执行工具 | 正在执行具体工具 |
| 输出正文 | 正在生成回答 |
| 临时错误重试 | 正在重试 |
| 结束 | 用时摘要，可展开查看过程 |

正文按增量淡入，思考与工具条目默认收起，点开可看参数与结果。生成期间输入框仍可用：有草稿时可选择“追加”或“排队”，右侧固定为停止按钮。

点击停止会取消当前网络请求、阻止后续工具执行，并把这条回答标记为“已停止”；已生成正文、已完成的工具结果和本轮文件修改都保留。停止不会回滚已经写入的文件。

## 附件、图片与画板

输入框左侧的加号提供图片、文本文件与画板。每条消息最多 4 个附件：

| 类型 | 限制 | 处理方式 |
| --- | --- | --- |
| 图片 | 原文件 20 MB、不超过 8000 万像素 | 最长边缩至 1600 px，转 JPEG（质量 85），结果不超过 4 MB；需要模型支持视觉输入 |
| 文本 | 无 64 KiB 上限，完整保存 | 小文本直接进入消息；大文本由 `read_attachment` 按需分段读取，每次最多 2000 行或 50 KiB |
| PDF / DOCX / XLSX / PPTX | 原文件 8 MB | 提取文字保存为文本副本；PDF 最多 100 页，超过 31000 字符明确截断；不做扫描件 OCR。HarmonyOS 6（API 20）没有系统 PDFKit，导入 PDF 时会明确提示并建议改用截图或 Office/文本文件 |
| 画板 | 依赖设备系统手写能力 | 导出为白底 JPEG 加入草稿，与其他附件共用 4 个上限 |

附件消息可以只发附件不写文字。图片与文档内容会随消息发送给你选择的模型服务。

## 交互预览

助手可以在工作区写入 `.js`、`.html` 或 `.svg`，再调用 `publish_preview` 准备快照，最后在回复中引用。任务成功结束后，预览直接出现在说明文字之间，没有额外的标题和白色边框；工具执行过程中不会反复弹出。旧消息保留原有可展开、收起的卡片。要点：

- 发布时保存的是不可变内容快照与一张截图，之后修改或删除源文件不影响已发布版本。
- 卡片在滚动停止后才会加载 Web 内容；离屏、后台或只读时暂停。
- 页面内的临时输入状态在视图释放后重置，重启后恢复的是发布时的快照。
- 旧版 `.jsonl` 界面不再执行，会明确显示不支持格式的错误。

完整规则与失败处理见[交互预览与 Web UI](/internals/preview)。

## 回答保存在哪里

- 消息在发送前与生成结束时各保存一次。会话以 v2 布局写入 `sessions-v2/`：索引 `index.json` 加每个会话一个独立文件。
- 附件二进制单独存放在 `attachments/`，不写进会话 JSON。
- 强制结束进程可能丢失本轮尚未落盘的增量文字，但已保存的历史不会被改写成“已完成”。
- 中断的生成在重启后标记为已停止；未完成的回答正文不进入下一轮上下文，已完成的工具结果保留。
- “分享对话”和“导出为 Markdown”生成的是文字记录，不含附件二进制与模型密钥。

文件布局见[磁盘布局](/reference/storage)，保存链路见[会话与持久化](/internals/session)。

## 发送之后，界面上还发生了什么

- 首条消息发出后，后台用本轮实际模型生成一个简短标题：与输入语言一致，最多 28 字符，不携带历史与工具，不阻塞回答。失败时保留首句摘要；你手动改名后，晚到的标题结果不会覆盖。
- 输入框左侧的圆环显示当前上下文占用百分比，点击打开上下文面板：预计占用、剩余容量、分类估算（系统指令、工具定义、历史、附件等），以及“压缩较早对话”。压缩只改变发送给模型的内容，完整记录仍保留在本机。
- 模型支持推理强度时，输入区出现推理强度胶囊；点击可在当前会话内切换档位，规则见[推理强度](/ui/reasoning-effort)。
- 每条回答结束时，末尾会显示“本轮修改”（本轮真的写过文件时才有），列出文件清单与差异，见[文件与工作区](/guide/files)。

## 一条回答的三种结局

| 状态 | 含义 | 界面表现 |
| --- | --- | --- |
| 完整 | 模型正常结束，没有要求继续调用工具 | 显示耗时摘要，过程可展开 |
| 已停止 | 你点了停止，或执行被取消 | 保留已生成正文与工具结果，状态线写“已停止” |
| 未完成 | 网络、鉴权、额度、解析或保存失败 | 状态线写“未完成”，保留失败次数、工具记录与已准备的预览快照；新预览不会提前挂载，可重新生成或改写后重发 |

失败不会把半截回答伪装成完整答案。临时传输错误与流式空闲超时最多自动重试 2 次，重试会丢弃本次未完成的正文与工具参数，用相同的已提交历史重新请求；鉴权失败、额度错误和解析失败直接展示。详见[轮次、流式与重试](/internals/agent-loop)。

## 回答下方能做什么

助手回答的操作栏提供复制、选择文本、朗读回答、重新生成、分支与“提炼为记忆”；用户消息提供复制、选择文本与改写。每项只出现一次，窄屏会自动换行。各操作的确切语义见[对话与消息](/guide/chat)。

## 输入区的其他入口

| 入口 | 作用 |
| --- | --- |
| 加号 | 图片、文本文件、画板、工作区、记忆、Agent 团队、引用其他会话、提示词模板 |
| 麦克风 | 切换到语音输入，使用系统语音识别（支持中文离线识别），最长 10 分钟 |
| 上下文圆环 | 查看占用分类并按需压缩较早对话 |
| 推理强度胶囊 | 切换当前会话的推理档位（模型支持时） |
| 队列徽标 | 有待发送输入时显示“待发送 N”或“已暂停 N”，点击展开列表 |
