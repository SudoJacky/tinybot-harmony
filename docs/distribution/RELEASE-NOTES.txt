# Tinybot v1.3.1 更新说明

准备日期：2026-11-13
版本：1.3.1 / 1003001
系统要求：HarmonyOS 6.0.0（API 20）及以上，手机与平板，目标 API 26

## 本机存储与备份

- 会话、模型配置、用量和生活看板迁入本机加密数据库。首次升级自动迁移并校验，原始文件保留为升级前副本。
- 本机数据库密钥无法读取时，可从启动页选择升级前副本或云备份，恢复到新的加密库。
- 华为云空间和 WebDAV 按设备保留最近 3 个备份版本。恢复前可选择版本并核对新增、跳过和另存副本的会话数量。坚果云 WebDAV 保存新备份时使用独立文件，避免覆盖冲突。
- 修复系统隐私授权状态读取失败时的恢复流程。

## 对话、文件与界面

- 手机优化键盘和语音输入。空会话中，输入框上下的留白都可以向右滑动打开会话栏。
- 平板空会话可直接切换工作区。快捷键按对话、导航、输入分组，可按功能名或键位搜索。
- 设置支持左右滑动切换分类。修复动效图标缩放，首页 Tinybot 标志使用原来的米白色外环和橙点。
- 文件预览支持 Office、HTML 和批注。图表可离线预览，生成的 PowerPoint 图表可在办公软件中继续编辑。
- 开启自动更新记忆后，助手可在当前对话中主动维护长期记忆。聊天中的上下文用量可展开查看。
- 本地小程序和提示词模板入口已移除。已有会话、历史预览和工作区原件保留。

## 升级

- 同签名覆盖升级可保留会话、草稿、附件和工作区。华为云空间恢复加密连接凭据时需登录同一华为账号。
- 沉浸光感材质需要 API 26 及设备支持。API 20 保留 PDF 原件，读取时会提示缺少文字提取能力。

# Tinybot v1.3.0 更新说明

准备日期：2026-11-08
版本：1.3.0 / 1003000
系统要求：HarmonyOS 6.0.0（API 20）及以上，手机与平板；目标 API 26

## 生活看板与余额

- 看板升级为持久化的 12 列网格，支持交互 HTML 卡片、长按拖动、调整大小和明确摆放；同一卡片在不同看板中保留各自的界面状态。
- 打开生活看板即可使用默认日常卡片，无需手动添加；顶部提供可切换吉祥物、星环与跃迁场景的离线 ASCII 动画。
- 卡片按实际占用区域自动向上靠齐，拖动、缩小或移除后收起空行，保留左右位置、尺寸与内部状态；淡色右下角提示标明实际缩放边界。
- 改善整块看板与卡片内部的上下滑动配合，修复长按编辑时无法上下拖动及误触下拉刷新；整理标题栏、菜单和卡片详情。
- 新增已适配模型服务的余额查询与余额看板，支持账户切换、查询状态和服务图标；卡片和看板仅在助手明确引用时出现在回答中，避免重复追加。
- 邮箱卡片支持点击读取绑定邮箱的纯文本正文，无需调用模型；读取沿用账号与文件夹权限，不将正文保存为卡片数据。
- 内置 Widget、Widget Design 和 Canvas Skills，将创建、数据源与视觉规范按需提供给助手，减少工具描述中的重复说明。

## 手机、平板与对话

- 优化手机和平板的设置、侧栏、弹层、输入框与内容布局；修复平板设置切换类别不刷新、返回对话后部分输入按钮异常放大的问题。
- 语音输入切换到“按住说话”时，保持左右按钮与中间输入区域的尺寸一致。
- 附件菜单支持拍照添加图片；改进消息底部的 Token 用量与生成速度信息，打开已有会话时定位到最近内容。
- 数学公式使用随包资源离线渲染，减少对外部资源加载的依赖。
- 修复邮箱 IMAP TLS 监听时序，改善邮箱连接与看板数据源的稳定性。

## 完整备份与换机恢复

- 备份纳入对话、草稿、待发送指令、附件、工作区文件、生活看板、小程序、Skills、记忆、模板、设置和用量记录。
- 模型 API Key、独立余额凭据，以及搜索、MCP、邮箱、卡片 API/OAuth 和反馈连接凭据，沿用华为账号加密方案迁移；换机需使用同一华为账号。
- 自动与手动备份更新同一份云端文件，页面只保留“备份”和“恢复备份”。恢复时自动同步、下载并合并，保留本机已有数据和密钥，补齐缺少内容。
- 新备份确认上传后才清理旧副本；失败时保留可恢复数据并明确提示。兼容旧版 v1/v2 JSON 与 v3 归档，旧备份未保存的内容需要重新备份后才能迁移。

## 使用与升级

- 使用相同签名覆盖升级，保留已有数据。旧版应用不能读取新的 v4 备份，换机时两端均应使用支持该格式的版本。
- 多设备共用一份备份，后备份的设备会替换此前的云端内容；这不是设备间实时同步。自动备份受系统后台时限与网络、云空间状态约束，卸载前需确认备份已上传。
- 隐私同意、系统权限、华为账号登录和共享文件夹授权需在新设备完成；被服务端撤销的 OAuth 或邮箱授权仍需重连。对话和文件不加密。
- 沉浸光感需要 API 26 及设备支持；API 20 缺少系统 PDFKit 时，仍保留 PDF 原件，读取时提示不支持文字提取；扫描件不提供 OCR。
- 本版实际验证与正式签名、平台测试待办分别见 CLOUD-TEST.txt、RELEASE-GAPS.txt。

# Tinybot v1.2.3 更新说明

准备日期：2026-11-05
版本：1.2.3 / 1002003
系统要求：HarmonyOS 6.0.0（API 20）及以上，手机与平板；目标 API 26

## 新增与修复

- 新增生活看板：支持指标、清单、趋势卡片与多个看板，接入工作区文件、API、邮箱或助手更新任务；同一卡片可固定到多个看板，分别调整尺寸和顺序。
- 整理生活看板操作栏，支持下拉刷新、选中标签自动定位、按内容调整卡片高度、两行左对齐标题和尺寸菜单；小尺寸清单显示完成摘要，详情展示数据源、连接状态和最近运行。
- 修复卡片正文截获列表滑动、刷新后数据与勾选状态未及时更新、弹层入口互相干扰；明确显示暂停状态、初始数据来源、手动与自动触发记录，并统一中文错误与时间格式。
- 邮箱设置增加字段标签和具体校验提示，错误在表单顶部可见；整理看板与连接面板的顶部布局，改善关闭状态开关的辨识度。
- 同轮多个卡片与看板回执合并为摘要入口，隐藏不可操作的预览刷新按钮，保留聊天顶栏渐变背景并区分菜单图标。
- 新增退到后台时自动云备份：已登录应用内华为账号并开启 Tinybot 云空间时默认启用，可在“备份与恢复”关闭。对话与本机工作区有变更时备份，自动快照与手动备份分开保存，并显示实际上传状态。
- 隐私授权等待页增加“继续授权”和退出入口；系统弹窗未出现时可手动请求授权，接口失败时保留错误和重试入口。
- 修复聊天输入框、滚动和 Markdown 的渲染回调时序，避免页面渲染期间修改状态；切换会话后丢弃旧输入框的迟到回调，保护各自草稿。
- 浏览器与文档提取模块改为按需加载，减少普通聊天启动时的初始化工作；补齐网络状态监听所需权限。
- 修复部分设备因过早查询而误判光感材质不可用的问题，完善标题栏材质与弹层圆角参数。
- 共享文件夹的系统授权失效时，明确提示在项目设置中移除后重新添加，保留已有目录配置。

## 使用与升级

- 自动备份受系统后台运行时限、网络和云空间状态约束；强制结束应用不保证完成备份。卸载前请在“备份与恢复”确认备份已上传。
- 备份中的模型 API Key 需同一华为账号恢复；MCP 与搜索凭据不导出，对话与文件不加密。系统目录授权不能随备份恢复。
- 使用相同签名覆盖升级，保留已有数据。沉浸光感需要 API 26 及设备支持；API 20 缺少系统 PDFKit 时，保留 PDF 原件并在读取时提示能力限制。
- 实际验证与发布待办见 CLOUD-TEST.txt、RELEASE-GAPS.txt。

# Tinybot v1.2.2 更新说明

准备日期：2026-10-29
版本：1.2.2 / 1002002
系统要求：HarmonyOS 6.0.0（API 20）及以上，手机与平板；目标 API 26

## 对话与任务

- 支持多个会话同时执行任务，切换或新建会话时，各自的模型、草稿、队列和停止状态独立保留。
- 网络请求支持后台继续传输，回答成功保存后发送完成通知，点击可回到对应会话。
- 优化工具状态更新、会话保存与文件差异计算，减少界面阻塞；改善大文件、网页和工具结果的读取，不完整内容提供明确提示。

## 小程序与预览

- 在“设置 → 实验室”开启小程序，可收藏交互页面、保存数据，支持更新、恢复上一版页面、导出及移除后恢复；关闭功能保留已有数据。
- 小程序列表支持整卡打开、更多操作菜单、重命名、同名编号、来源与相对时间、分类数量和下拉刷新；有可保存的预览时才显示添加入口。
- 兼容 v1、v2 小程序清单，保留正式数据、版本与采用历史，修复旧预览记录导致会话加载失败的问题。
- 支持全屏预览，切换时保留交互状态；助手可检查实际页面、点击控件、等待状态并采集多帧截图。
- 修复后台预览校验与截图误超时，回到前台后继续同一次发布；改善预览启动和页面观察的稳定性。

## 文件、搜索与备份

- 支持系统分享文档到 Tinybot，以及将图片、文件拖入聊天作为草稿附件；每条消息最多 10 个附件，不会自动发送。
- 文本、PDF 与 Office 附件保留原文件，读取时按需提取内容；普通会话分支保留历史附件原件。
- 默认开启应用内浏览器与内置必应搜索，无需单独配置搜索密钥；优化搜索服务配置，保留各服务的独立设置。
- 模型 API Key 随备份使用华为账号信息加密，同账号换设备可恢复；修复恢复后提示“未注册的模型服务”的问题。
- 改善云备份替换流程，保留可恢复快照；备份和恢复兼容 v2 小程序，保留本机已有数据。
- 新增 QQ 社区入口与任务成功后的评价邀请。

## 平板与稳定性

- 修复从备份恢复含交互预览的旧会话后，继续发送消息时可能闪退的问题。
- 修复进入设置等页面后左侧会话栏空白的问题；键盘展开时收紧侧栏导航，保留搜索结果空间。
- 修复平板聊天标题遮挡内容，以及不支持沉浸光感的设备上菜单背景缺失的问题。
- 改善菜单文字对比度、公告可读性和焦点处理；修复分享、通知与快捷入口进入聊天后被手机文件面板遮挡的问题。
- 加强未知配置字段兼容性；并行会话修改共享文件时检查版本，避免覆盖其他会话的新内容。

## 使用与升级

- 使用相同签名覆盖升级，保留已有会话、模型配置、草稿与工作区。小程序为实验功能，默认关闭。
- 后台网络任务受系统许可与运行时限约束；预览校验和截图需要前台渲染。
- 沉浸光感需要 HarmonyOS 7（API 26）及设备支持；其他设备使用普通界面。HarmonyOS 6 缺少 PDFKit 时保留 PDF 原件，读取时明确提示不支持文字提取；扫描件不提供 OCR。
- 备份中的模型 API Key 需同一华为账号恢复；MCP 与搜索凭据不导出，对话与文件不加密。
- 构建与验证记录见 CLOUD-TEST.txt，正式签名和平台提交事项见 RELEASE-GAPS.txt。

# Tinybot v1.2.0 更新说明

准备日期：2026-10-28
版本：1.2.0 / 1002000
系统要求：HarmonyOS 6.0.0（API 20）及以上，手机与平板；目标 API 26
以下为相对 v1.1.0 的累计更新。

## 新功能

- 并行会话：一个会话生成时，可以切换或新建其他会话继续提问；模型、草稿、队列和停止状态分别保留。
- 本地小程序：将交互页面收藏为小程序，保存数据并在重启后继续使用；支持页面更新、恢复上一版、移除和恢复，原会话删除后仍可保留。
- 文件与系统分享：从系统分享菜单将文档发送到 Tinybot；每条消息最多 10 个附件，文本、PDF、Office 保留原文件，读取时再按需提取内容。
- 后台传输与完成通知：实际网络请求支持后台继续传输；后台回答成功保存后发送完成通知，点击回到对应会话。
- 搜索设置：默认开启应用内浏览器与内置必应搜索，无需搜索 API Key；服务列表与详情分开配置，切换时保留各服务配置，保存后统一生效。已有明确设置保持不变。
- 预览：新增全屏查看，切换时保留页面和交互状态；助手可检查实际页面、点击控件、等待状态并采集多帧截图。
- 新增 QQ 社区入口与任务成功后的评价邀请，可选择暂不或不再提醒。

## 性能与体验

- 优化工具执行状态更新、会话保存和文件差异计算，减少界面阻塞。
- 改善较大文件、网页正文和工具结果的处理，放宽多处固定内容限制，读取预算可调整；不完整内容与失败回执提供明确提示。
- 文档导入不再提前提取或截断正文，PDF 读取不再固定截取前 100 页；普通会话分支保留历史附件原件。

## 问题修复

- 修复后台预览启动校验和截图误超时：回到前台后继续同一次发布，不把后台渲染暂停误报为代码错误。
- 修复外部分享、通知和快捷入口打开聊天后被手机文件面板遮挡的问题，保留编辑草稿；平板并排面板保持原布局。
- 加强配置兼容性，保留当前版本不认识的字段，对不支持的配置明确提示，减少版本切换时配置丢失。
- 并行会话共享文件写入串行处理，修改和删除时检查文件版本，防止覆盖其他会话的新内容。

## 升级与验证说明

- 从 v1.1.0 或 v1.1.1 使用相同签名覆盖升级，保留已有会话、模型配置、草稿与工作区；完整实测范围见 CLOUD-TEST.txt。
- 后台网络任务受系统许可与运行时限约束；预览校验和截图需要前台渲染，后台等待不会被记作校验成功。
- HarmonyOS 6（API 20）使用普通界面；HarmonyOS 7（API 26）支持沉浸光感材质。API 20 缺少 PDFKit 时仍可保留 PDF 原件，读取时明确提示不支持文字提取；扫描件不提供 OCR。
- 发布签名、ACL 授权、API 20 真机、平台云测试与系统评价的待办见 RELEASE-GAPS.txt。UNSIGNED 文件需正式签名后才能安装或发布。

# Tinybot v1.1.1 更新说明

准备日期：2026-10-28
版本：1.1.1 / 1001001
系统要求：HarmonyOS 6.0.0（API 20）及以上，手机与平板；目标 API 26

## 新功能

- 实际网络请求支持后台继续传输，完成后释放系统任务；系统或用户中止时保留明确原因并暂停待发送队列。
- 新增评价邀请，在成功任务后的空闲时机展示，可选择暂不或不再提醒；评分入口使用系统应用内评价流程。
- 预览支持通过原生浏览器检查页面、点击控件、等待状态并采集多帧截图，保留实际观察回执。
- 新增全屏预览，内嵌与全屏之间切换时保留同一个页面及其交互状态。

## 改进与修复
