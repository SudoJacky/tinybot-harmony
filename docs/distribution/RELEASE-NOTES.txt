# Tinybot 0.1.5 测试版更新说明

准备日期：2026-10-07
版本：0.1.5 / 10005
最低系统要求：HarmonyOS API 26，手机

## 主要更新

- 聊天输入框下方新增小字提示“AI可能会犯错，请仔细鉴别。”，支持中英文和系统明暗主题。
- 设置新增“关于”分组，提供使用帮助、评分和评论、关于 Tinybot；可查看实际安装版本、更新说明、公告和首次使用指引。
- 评分和评论直接打开华为系统评价弹窗，可进入“写评论”表单；取消后可重新打开。
- 添加模型服务和已添加服务列表新增 DeepSeek、阿里云百炼、OpenAI、智谱、Ollama、Anthropic 的品牌 Logo；OpenAI Responses 共用 OpenAI 标志，自定义服务保留通用图标。资源离线可用，适配明暗主题。
- 云备份列表支持删除指定快照，操作前确认，显示实际同步结果；同步未完成时保留明确提示，不影响本机对话和设置。
- 恢复备份时保留本机已有密钥和服务配置，复用能明确匹配的模型服务和 MCP，避免重复添加；无法匹配或存在多个候选时导入为停用副本。
- 修复云备份读取文件位置时误用 lstat 元数据的问题，避免原生文件接口崩溃。
- 修复运行中切换明暗主题时状态栏文字颜色滞后，改用系统主题回调中的最新配置。

## 升级与回归重点

- 从 0.1.4 / 10004 覆盖升级，检查对话、模型配置、草稿、模板、记忆及文件保留；签名不一致时卸载重装不能算作升级验证。
- 检查空会话、有消息、键盘展开和收起时的 AI 提示，以及中英文与明暗主题下的可读性。
- 检查设置与关于入口、帮助和指引滚动、版本信息，以及评分弹窗和评论表单的打开、取消、再次打开。
- 检查各服务商 Logo、预设选择和地址/模型预填、自定义服务，以及已有服务配置保留。
- 云备份删除需验证同步成功、失败和超时；恢复需验证已有模型和 MCP 的唯一匹配、歧义导入、历史引用映射及本机凭据保留。
- 用户协议与隐私政策目前仅保留禁用占位，无正文、链接或同意记录；公告暂为空，首次使用指引可手动查看。
- 完整操作步骤与实际验证记录见 CLOUD-TEST.txt。评价表单已验证打开和取消，未提交真实评价；真实云端删除与跨设备恢复仍需真机联调。
