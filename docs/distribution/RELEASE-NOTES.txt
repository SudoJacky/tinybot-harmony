# Tinybot 0.1.6 测试版更新说明

准备日期：2026-10-09
版本：0.1.6 / 10006
最低系统要求：HarmonyOS API 26，手机

## 主要更新

- 新增 orchestrate 工具：通过本机受限 JavaScript 组合已授权的文件、网页、Skills 与 MCP 工具，统一返回任务结果。独立读取可并行，写入等操作保持顺序，沿用现有权限与 MCP 确认。
- 提供 ALL_TOOLS、text、as_settled 和 stream_settled，支持查询工具能力、收集日志、按完成顺序处理成功与失败；日志随最终回执显示。
- 编排回执可展开各子调用的参数、状态与结果，并随会话保存。停止、超时与部分失败保留真实执行记录，后续任务可继续运行。
- 点击输入框旁的上下文圆圈，可查看系统提示、工具定义、用户输入、助手消息、工具结果、压缩摘要、附件与引用、协议开销八类明细，展开到区块、工具或消息来源。
- 上下文分类基于实际保留的请求内容进行本地估算，输入框草稿与附件即时计入。模型返回的最近请求及本轮实际 Token 用量单独展示，区分输入、输出、缓存和推理；缺失字段不当作零。
- 修复上下文详情的滚动范围，长列表下仍可到达压缩会话入口。

## 升级与回归重点

- 从 0.1.5 / 10005 覆盖升级，检查历史对话、模型配置、草稿和文件保留；签名不一致时卸载重装不能算作升级验证。
- 检查编排的正常完成、部分失败、取消、超时恢复，以及重启后的子调用回执。
- 检查上下文分类总和、工具结果预览、压缩摘要、历史引用、草稿与附件变化，以及模型未提供完整 usage 时的提示。
- 本地分类不是模型分词器的精确计数，也不使用相邻请求 total 的差值冒充工具输入量；标题、自动记忆与团队成员等独立请求不计入该对话主执行的汇总。
- 编排不提供 Python、模块加载、直接网络或文件访问；运行预算为 2 秒脚本计算、120 秒总耗时、32 MiB JS 内存、最多 32 次子调用及 4 个同时执行的宿主工具。
- 完整步骤、实际验证与既有未完成项见 CLOUD-TEST.txt 和 RELEASE-GAPS.txt。
