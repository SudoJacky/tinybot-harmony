Tinybot 0.1.3 测试版更新说明
发布日期：2026-10-04（本地测试发布准备）
版本：0.1.3 / 10003
最低系统要求：HarmonyOS API 26，手机

主要更新
• 新增完整 Token 用量页面：按时间、服务、模型和会话筛选，查看每日趋势、周汇总、会话/轮次以及请求明细，并关联工具和 Skill 活动。
• 回答下方展示本轮模型用时、输入/输出与缓存命中情况；区分缺失用量和真实零值。大批量记录使用分页查询与分块存储，迁移旧账本时保留恢复副本。
• 首轮聊天自动生成简短会话标题，保留手动改名；标题请求独立计入用量，失败沿用已有标题。
• 流式 Markdown 新内容渐显，保留已读前缀及过程展开状态；改进推理强度滑块的预览和保存反馈。
• 优化上下文预算与执行中压缩，按模型提供默认窗口；明确配置的模型或服务窗口优先。长时间仍有输出的流式请求不再因固定总时限被中断，连接和空闲超时仍保留。
• 设置页集中长期记忆、模型能力、用量与备份入口，移除底部说明和自动记忆副标题。
• 系统提示词由应用维护；提供可编辑 USER.md 用户文档，从下一轮起加入所有对话上下文。旧自定义提示词自动迁移，备份保留个人偏好。
• 默认开启自动提取长期记忆和 Chat Completions 流式用量请求，保留已有明确关闭的设置。自动记忆会额外调用模型，可在设置中关闭。

升级与回归重点
• 由 0.1.2 / 10002 覆盖升级，检查对话、服务、记忆、文件和自定义偏好；签名不一致时卸载重装不能算作升级验证。
• 检查旧用量账本迁移、分页、缺失字段、取消和失败请求统计；历史请求没有来源时归为历史/未知来源，不补造关联信息。
• 检查 USER.md 保存、返回丢弃、清空停用、切换模型/会话、团队执行及备份恢复；现有非空文档不被导入覆盖。
• 新安装默认开关与已有安装的显式关闭选择分别验证；流式用量参数只用于 Chat Completions。
• 检查自动标题不覆盖手动改名、不阻塞主回复；默认自动记忆只在成功任务后执行。
• 完整操作步骤和本次验证记录见 CLOUD-TEST.txt。
