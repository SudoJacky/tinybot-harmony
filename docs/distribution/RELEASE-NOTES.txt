# Tinybot 0.1.4 测试版更新说明

准备日期：2026-10-05
版本：0.1.4 / 10004
最低系统要求：HarmonyOS API 26，手机

## 主要更新

- 新增系统语音转文字：麦克风展开为计时与语音活动胶囊，识别文字实时写入输入框。支持点按启停、按住说话和左滑取消；保留原草稿，不自动发送。无识别文字时直接收起，不显示空语音错误提示。
- 新增华为云空间手动备份与恢复：保存当前对话、附件、工作区、Skills、模板、记忆和用户文档，显示真实上传状态；恢复为独立副本，配置中的 API Key 和 Token 不导出。
- 修复滑动删除松手后瞬间跳变，恢复连续回弹及重新拖动；略微缩短进入删除状态的距离，垃圾桶盖随触发状态打开、关闭。
- 修复长思考因流式网络数据累计超过 2 MiB 而失败。保留单帧、推理内容和工具参数边界，正常持续输出不再受累计网络字节数限制。
- 修复 Responses 协议只显示“思考中”却没有具体内容的问题；支持服务返回的推理摘要与文本，并避免最终快照重复追加。
- 精简备份与恢复页面的重复说明。

## 升级与回归重点

- 从 0.1.3 / 10003 覆盖升级，检查对话、模型配置、草稿、模板、记忆及文件保留；签名不一致时卸载重装不能算作升级验证。
- 语音输入需设备提供系统识别引擎并授权麦克风；检查拒绝重试、取消回滚、后台停止与实际人声识别质量。
- 云备份需在系统华为云空间开启 Tinybot。待上传快照不等于云端备份；真实上云与同账号跨设备恢复仍需设备验证，不提供实时会话同步。
- 检查长推理、Responses 增量与完成快照、历史重开，以及滑动删除的回弹、开盖和确认流程。
- 完整操作步骤与实际验证记录见 CLOUD-TEST.txt。
