# Tinybot v1.0.4 更新说明

准备日期：2026-10-23
版本：1.0.4 / 1000004
系统要求：HarmonyOS API 26，手机

## 本次调整

- 优化模型请求的稳定前缀复用，提高缓存命中机会；实际命中与节省以模型服务返回的用量为准。
- 接入华为托管隐私政策和系统统一弹窗，首次启动自动展示；同意后启动业务，拒绝后退出，下次启动继续提示。
- 关于 Tinybot 中点击隐私政策可选择查看或拒绝；拒绝需再次确认，撤回授权后停止当前对话并退出，保留已有会话、文件和设置。
- 更新托管隐私政策地址；用户协议继续保留本地阅读与独立同意流程。
- 修复评分入口无弹窗的问题，改为直接打开应用市场写评论页；跳转失败时显示错误提示。

## 升级与验证

- 从 1.0.3 / 1000003 使用相同签名覆盖升级，不卸载或清空数据。
- 本地验证与外部待办见 CLOUD-TEST.txt 和 RELEASE-GAPS.txt。正式签名、权限授权与平台测试仍需完成。

# Tinybot v1.0.2 更新说明

准备日期：2026-10-21
版本：1.0.2 / 1000002
系统要求：HarmonyOS API 26，手机

## 新增与改进

- 新增五步首次使用引导：登录华为账号、叫醒 Tiny、认识 Tiny、连接模型和准备首个任务。三张纸页分别展示调研、行程和摘要示例，支持点按、滑动和减弱动效。
- Tiny 的睡眠、唤醒、打招呼、连接反馈与告别动作衔接更自然。填写服务地址或 API Key 时保持输入框可见，键盘覆盖底部操作；密钥输入时捂眼，停下后短暂偷看。
- 接入华为账号登录及 AI 生成功能授权检查，统一账号登录页面与新人引导体验。
- 项目支持关联共享文件夹，完善共享目录访问边界与文件恢复入口；修复共享工作区备份和恢复中的文件保留问题。
- Markdown 图片可直接显示并打开全屏预览；支持对话图片导出，导出内容与助手回复增加 AI 标识。
- Token 用量总览增加近 365 天贡献热力图、活跃天数和连续使用统计，保留全部历史总量；修复快速切换筛选弹层的问题。
- 上下文详情合并窗口占用、剩余空间与可展开分类，用分段色条展示估算构成，同时保留服务端校准总量。
- 改善流式聊天和交互预览性能，增强中断恢复与网页读取限额；保留完整工具结果并调整 DeepSeek 搜索接入。
- 新增 VitePress 文档站，同步安装、模型、设置及发布文档。

# Tinybot v1.0.0 更新说明

准备日期：2026-10-18
版本：1.0.0 / 1000000
系统要求：HarmonyOS API 26，手机

## 功能

- 原生个人 AI 助手：流式聊天、图片与文档附件、手绘画板、语音输入、会话搜索和分支。
- 项目共享工作区：同一项目中的对话共享文件与项目说明，可查看、编辑、比较和导出文件。
- 精简 Agent 工具：初始仅提供 read_file、write_file、edit_file、orchestrate、tool_search；BM25 检索按需加载其他能力，复杂参数使用原生对象和数组，edit_file 仅暴露 path 与 edits。
- 复用工具编排完成组合任务，提供团队协作、Skills、网页读取与搜索、应用内浏览器、远程 MCP、JS / HTML / SVG / Three.js 预览及图片生成。
- 长期记忆、提示词模板和称呼与回答偏好；支持配置模型分工、思考档位，以及 Chat Completions、Responses、Anthropic Messages 服务。
- 上下文详情展示会话累计实际用量，每轮保留独立统计；可按日期、服务和模型查看用量账本，支持本地导出与华为云空间手动备份。

## 体验与性能

- 流式文字逐段淡入；整轮中间过程统一展开，思考与工具调用各自默认折叠。
- 消息操作集中为紧凑图标，减少重复入口；文件修改卡片和过程列表减少留白与说明。
- 发送消息后自动收起键盘，键盘输入时显示团队模式入口。
- 设置的编辑、管理、语言与外观选择改用右侧进入的独立页面，统一入口和开关行的图标、文字起点及间距。
- 自定义工具合并为 13 项能力，浏览器、预览、团队等配套工具统一开关；记忆与 Skills 由专门设置管理。
- 深色启动页改用柔和 Tinybot 文字；降低弹层光感干扰，改善文字可读性。离屏、后台及关闭动效时停止循环动画。

## 修复

- 修复冷启动进入会话时从左上角展开矩形的过渡问题。
- 改善长回复滚动与预览的加载时机，减少滚动过程中的预览重载。
- 进入模型管理子页时保留服务草稿和待保存密钥，离开服务编辑后清理明文密钥。
- 设置保存失败仍保留草稿并展示错误；MCP 子页保存后的警告可返回列表显示。
- 保留文件访问边界、批量编辑校验、权限和危险操作确认、停止与超时，以及真实工具调用记录。

## 升级说明

- 从 0.1.6 / 10006 使用相同签名覆盖升级，保留本机历史会话、项目、文件、模型配置和设置。卸载重装不属于升级验证。
- 文件访问限于当前对话绑定的工作区；代码沙箱运行受限 JavaScript，通过已授权的宿主工具访问文件，不提供任意系统目录、Shell 或 Python。
- 模型、联网、MCP、语音与云备份的可用性取决于所配置的服务及设备能力。备份不导出模型与 MCP 凭据。
