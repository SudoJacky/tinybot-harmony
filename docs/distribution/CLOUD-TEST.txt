Tinybot 云测试与审核体验说明

软件包与环境
1. 先通过 DevEco Studio Upload Product 使用云管理证书重新签名；本资料包中的 UNSIGNED 文件不能直接作为最终已签名测试包。
2. 选择支持 API 26 或以上的 HarmonyOS 手机；当前仅声明 phone，不包含平板和穿戴设备。
3. 首轮可做安装、启动、退出、再次启动、前后台切换、明暗主题和无网络错误提示测试。
4. AI 功能需要可达的模型服务。云手机中的 localhost / 127.0.0.1 指向云手机，通常无法访问开发机局域网地址。
5. 云测试没有测试模型配置时，自动遍历通常只能覆盖基础界面；不能因此视为模型、工具和 OAuth 已通过完整验证。

模型配置与最小验收
• 首页“连接你的模型”或模型设置中添加服务；按服务真实情况填写协议、地址、模型和审核专用凭据并保存。
• 新建对话发送“请用中文解释什么是番茄工作法，简短回答”。预期流式显示，完成后可复制；停止后不继续自动执行任务。
• 发送“在当前工作区创建 checklist.txt，写入三条读书计划；再读取并核对内容”。预期工具执行回执清晰，文件页能打开文件。
• 让助手修改其中一行；文件页查看修改差异、保留或恢复，恢复新建文件时应明确提示会删除它。
• 发送“先用表单询问我要柱状图还是折线图，提交后展示数据：一月10、二月20、三月15；来源写用户提供的样例数据”。预期表单提交后继续，图表与数据一致。
• 告诉助手“以后请使用简洁中文，代码示例用ArkTS”，再点击回复下的记忆图标。预期先出现候选，可编辑、取消、勾选和确认；没有确认前不新增记忆，默认仅本对话。
• 搜索一条历史消息并定位，创建分支后检查原会话保留，分支有独立空工作区。
• 导入无敏感内容的 UTF-8 / CSV / PDF / Office 测试材料，检查失败、大小超限和不支持格式的提示。
• 导出备份，再导入为新副本。预期原会话保持不变，恢复后的模型服务不携带密钥，需重新配置并启用。

按需测试
• MCP 需要公开可达的 HTTPS Streamable HTTP 服务及其认证配置；应逐次确认调用，拒绝时不发起工具执行。
• OAuth 需要服务支持公共客户端、PKCE 和 tinybot-harmony://oauth/callback 回调；未完成实际服务联调的服务不应对外宣称已兼容。
• 图片生成需要单独配置 OpenAI 兼容图片接口及模型，调用前确认；测试服务需有额度。
• 自动记忆、自动路由和结果归档默认关闭。启用后分别检查额外模型请求、实际选中模型和工作区归档文件。
