Tinybot 0.1.3 云测试与审核体验说明

软件包与环境
1. 先通过 DevEco Studio Upload Product 使用云管理证书重新签名；本资料包中的 UNSIGNED 文件不能直接作为最终已签名测试包。
2. 选择支持 API 26 或以上的 HarmonyOS 手机；当前仅声明 phone，不包含平板和穿戴设备。
3. 首轮可做安装、启动、退出、再次启动、前后台切换、明暗主题和无网络错误提示测试。
4. AI 功能需要可达的模型服务。云手机中的 localhost / 127.0.0.1 指向云手机，通常无法访问开发机局域网地址。
5. 云测试没有测试模型配置时，自动遍历通常只能覆盖基础界面；不能因此视为模型、工具和 OAuth 已通过完整验证。

模型配置与最小验收
• 首页“连接你的模型”或模型设置中添加服务；按服务真实情况填写协议、地址、模型和审核专用凭据并保存。
• 新建对话发送“请用中文解释什么是番茄工作法，简短回答”。预期流式显示，完成后可复制；停止后不继续自动执行任务。
• 发送“在当前工作区创建 checklist.txt，写入三条读书计划；再读取并核对内容”。预期工具执行回执清晰，文件页能打开文件。
• 让助手修改其中一行；文件页查看修改差异、保留或恢复，恢复新建文件时应明确提示会删除它。
• 发送“先用表单询问我要柱状图还是折线图，提交后展示数据：一月10、二月20、三月15；来源写用户提供的样例数据”。预期表单提交后继续，图表与数据一致。
• 先关闭自动提取长期记忆，再告诉助手“以后请使用简洁中文，代码示例用ArkTS”，点击回复下的记忆图标。预期先出现候选，可编辑、取消、勾选和确认；没有确认前不新增记忆，默认仅本对话。
• 搜索一条历史消息并定位，创建分支后检查原会话保留，分支有独立空工作区。
• 导入无敏感内容的 UTF-8 / CSV / PDF / Office 测试材料，检查失败、大小超限和不支持格式的提示。
• 导出备份，再导入为新副本。预期原会话保持不变，恢复后的模型服务不携带密钥，需重新配置并启用。

按需测试
• MCP 需要公开可达的 HTTPS Streamable HTTP 服务及其认证配置；应逐次确认调用，拒绝时不发起工具执行。
• OAuth 需要服务支持公共客户端、PKCE 和 tinybot-harmony://oauth/callback 回调；未完成实际服务联调的服务不应对外宣称已兼容。
• 图片生成需要单独配置 OpenAI 兼容图片接口及模型，调用前确认；测试服务需有额度。
• 自动记忆默认开启，成功任务后检查额外模型请求、事实去重和来源；关闭后不再自动提取。自动路由和结果归档默认关闭，启用后检查实际选中模型和工作区归档文件。已有明确关闭的设置保留。

0.1.3 重点回归（云手机 arm64-v8a）
• 版本与升级：从 0.1.2 / 10002 升级至 0.1.3 / 10003，检查原对话、模板、记忆、服务配置和模型选择保留；另行使用干净环境测试首次启动。遇到签名不一致时不要把卸载重装算作升级通过。
• 沙箱：要求模型只调用 execute_code，依次运行 return {sum: input.values.reduce((a,b)=>a+b,0), host: typeof fetch};（input 为 JSON 字符串 {"values":[2,3,5]}）、while(true){}、return 42;。预期分别得到 sum=10 / host="undefined"、约 2 秒 timeout、42；前一次超时不影响后一次执行。
• 沙箱稳定性：分别执行 console.log("cloud-test"); return 1;、throw new Error("cloud-test");、持续分配数组的循环，检查输出受限、错误/内存限制可恢复；取消执行后再次发送消息，界面可响应，无 ANR、崩溃或持续资源增长。云测试报告需关注原生崩溃，定位时使用随包的 ARM64 符号。
• 思考档位：在实际支持 effort 的模型中切换默认/低档/最高档，重开会话后保持选择；最高档显示绿色粒子，改回默认后停止。切换模型时仅展示其支持档位；默认档继承模型配置，模型未配置强度时不发送自定义 effort。
• 协议：分别配置 OpenAI Chat Completions、Responses 与 Anthropic Messages 测试服务，验证普通流式回复、工具调用后续跑、停止以及错误提示；Anthropic 服务支持时验证 thinking/signature 在工具续跑时保留。只能把有实际服务凭据并完成测试的协议记为通过。
• 会话引用：输入 @ 或通过 + → 引用其他会话选择，预览、移除并发送；最多 4 个引用，验证只包含正文文字快照，不包含原会话思考、附件和工具记录；引用后修改原会话不改变已保存快照。
• 上下文压缩：发送 /compact，检查较早上下文变为摘要、完整历史保留；失败保留命令草稿，压缩期间新输入的内容不会清空。
• 触摸交互：聊天页右滑呼出侧栏，检查纵向滚动不误触；侧栏“对话 / 已归档”、工具页三项和助手页三项连续点击及跨项切换，底块拉伸收拢后准确落位，文字区域保持稳定。
• 滑动与开关：记忆/模板/MCP/工作区文件逐行滑动，检查短滑展开、另一行展开时关闭前一行、深滑仍需确认、取消后内容保留；记忆与工具页通过顶部标签切换。开关点击、拖动、重进页面后状态与实际设置一致。
• 服务编辑：保存后重开，留空密钥保持原凭据；仅改协议不清除同一端点的已有密钥，改变服务基础地址需重新填写；明暗主题下校验表单、错误和保存状态。

• 用户文档：设置 → 用户文档（USER.md），输入称呼与回答偏好，保存后在下一轮、其他会话和团队执行中生效；返回放弃草稿、清空停用、切换语言均正常。旧自定义系统提示迁移后文字不丢失，内置系统提示不可编辑。备份恢复时保留本机已有的非空文档。
• 默认行为：干净环境默认开启自动记忆和流式用量；升级环境保留明确的关闭选择。Chat Completions 请求包含 stream_options.include_usage，手动关闭后移除；Responses / Anthropic 不携带该参数。
• 用量页面：设置 → Token 用量，按日期、服务、模型、会话筛选，展开轮次和请求，查看缓存、推理、工具和 Skill 统计；缺失字段不能显示成真实零值。检查历史账本迁移后重启、分页边界和快速切换筛选，汇总应包含所有匹配记录。
• 标题与流式显示：首轮生成简短标题，手动改名不能被晚到结果覆盖，标题失败保留原题。增量文字渐显，已读前缀和过程展开状态不重置；停止后不继续显示迟到内容。
• 长回复与压缩：持续输出超过三分钟的测试流应保持连接，空闲超过 120 秒应给出错误；自动/手动压缩保留工具调用配对与当前输入。窗口为空时使用模型默认，手动设置优先。
