Tinybot v1.0.1 · 回归与云测试说明
版本：1.0.1 / 1000001；准备日期：2026-10-18

一、安装环境
发布交付包为 arm64、API 26 手机使用的未签名 Release 输入，正式签名后才能用于平台测试。模拟器使用独立调试包；升级检查沿用原签名，不卸载或清空数据。AI 功能需可达的模型服务，云手机的 localhost 不指向开发机。

二、本版重点回归
• 从 1.0.0 / 1000000 同签名覆盖升级至 1.0.1 / 1000001；关于页显示新版本，历史会话、项目、消息、模型选择、草稿、工作区与设置保留。
• 冷启动文字页与明暗主题正常；全新安装在独立环境验证协议阅读与首次使用，完成后进入聊天。
• 新会话开始仅有 read_file、write_file、edit_file、orchestrate、tool_search；按需检索可用工具，关闭的能力不可被检索、编排或团队调用。
• 使用原生对象和数组调用工具；edit_file 用 path + edits 批量修改，工作区边界、只读、旧内容匹配、危险操作确认和停止保护继续有效。
• 让助手在测试工作区创建 checklist.txt，读取、修改一行并核对差异；停止后保留已完成操作和真实回执。不要在用户文件上做破坏性验证。
• 编排验证组合读取、顺序写入、部分失败、取消、超时、内存限额及后续恢复；MCP 仍按现有流程确认。
• 流式长回复的已读前缀稳定，思考与工具行独立折叠，整轮过程只保留一层汇总；离屏、后台、关闭动效时停止循环。
• 发送后收起键盘，输入时显示团队模式；消息动作图标、文件修改卡片与长过程滚动正常。
• 自定义工具按 12 项能力联动；自动记忆和 Skills 使用专门设置，不提供重复开关。
• 设置入口与开关行图标、文字起点一致；语言、外观、模型管理与发现、记忆、模板及 MCP 编辑从右侧进入，系统返回正常。
• 模型子页返回保留待保存密钥和模型草稿；退出服务清理明文密钥，留空密钥保留已有安全凭据。保存失败不关闭页面；MCP 警告回到列表。
• 上下文详情为会话累计实际用量，每轮仍有独立用量；辅助标题、记忆及团队请求不混入主执行汇总。缺失字段与零值区分，缓存与推理不重复计算。
• JS、HTML、SVG、Three.js 预览分别验证；长回复快速滚动、历史重开和前后台切换时检查重载、错误和原生崩溃记录。
• 关于页版本与更新说明正确，用户协议、隐私政策与第三方许可证能离线全文阅读。

三、保留的功能回归
• 三种模型协议、图片/文档附件、画板、语音、会话搜索与分支、项目共享工作区、Skills、团队任务。
• 长期记忆的候选确认、范围、去重、来源与自动整理；USER.md 保存与下轮生效。
• 本地备份导出/恢复保留本机已有凭据；导入包不携带 Key/Token，不覆盖已有非空偏好。
• Token 账本的日期/服务/模型筛选、分页、缓存和推理统计；流式中断、无网络和服务错误可恢复。
• 评分入口仅验证打开和取消，不提交未经用户授权的真实评价。

四、需要外部条件的验证
• ARM64 真机与平台云测试：发布签名安装、首装/升级、长回复、预览滚动、原生沙箱资源上限。
• 华为云空间：真实上传、同账号另一台设备刷新与恢复、删除同步、配额和网络错误。
• 系统语音：实际人声识别质量、权限拒绝与重新授权。
• MCP OAuth 与各模型协议：使用实际目标服务验证；不能将模拟传输通过记为真实服务兼容性通过。
