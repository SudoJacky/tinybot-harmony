简短介绍
原生鸿蒙 AI 助手，连接你的模型服务，整理对话、文件与长期记忆。

完整介绍
Tinybot 是一款使用 ArkTS 与 ArkUI 开发的原生 HarmonyOS 个人 AI 助手。你可以连接自己的兼容模型服务，在手机或平板上完成问答、资料整理、文件处理和多步任务；平板按窗口宽度展开双栏或三栏工作台。

主要功能：
• 流式对话、Markdown 展示、消息搜索、独立会话与分支；多个会话可同时执行任务。
• 在设置的实验室中开启本地小程序后，可收藏页面并保存数据，支持页面更新、恢复和全屏查看；默认关闭。
• 后台网络传输与任务完成通知，点击通知返回对应会话。
• 平板工作台：按窗口宽度并排会话、对话、文件与预览，会话栏可收起为图标栏。
• 反馈与建议：按类型提交问题或建议，可选图片与脱敏日志，并查看处理状态与开发者回复。
• 内置必应搜索：无需单独配置搜索密钥，支持浏览器验证后继续。
• 存储空间管理：查看占用与明细，确认后清理建议项目。
• 系统语音输入，支持按住说话、滑动取消与编辑。
• 手动备份到华为云空间，并在同一华为账号下恢复为独立副本。
• 每条消息最多 10 个附件，支持系统文档分享；保留原文件，按需提取 PDF、DOCX、XLSX、PPTX 文字，预览 CSV 和引用选段。
• 会话工作区支持文本搜索、按行读取、编辑、差异预览及恢复。
• 通过表单补充任务信息，查看任务计划、表格和图表。
• 提炼、编辑并确认长期记忆，管理常用提示词模板与 Skills 文档。
• 连接远程 HTTPS MCP 工具，调用前展示确认信息。
• 查看模型实际返回的 Token 用量、时间趋势和会话/轮次明细，导出会话或备份并恢复为新副本。
• 编辑 USER.md 全局用户偏好；首轮聊天自动生成简短标题。
• 按会话选择模型支持的思考档位，支持 OpenAI 兼容协议、Anthropic Messages 和 Gemini 原生协议。
• 通过受限的本机 JavaScript 工具计算数据；引用其他会话的文字快照，或使用 /compact 压缩上下文。

使用说明：
本应用需要你配置可用的模型服务地址、模型及凭据（部分本地服务无需密钥）。应用不内置免费模型额度，也不在手机本地运行大模型。服务可用性、模型能力及费用由相应服务提供方决定。
图片理解与推理设置需要模型服务支持。PDF 扫描件暂不提供 OCR，Office 附件保留原件并按需提取文字。HarmonyOS 6（API 20）未提供系统 PDF 组件，仍可导入并保留 PDF 原件，读取时明确提示不支持文字提取，可改用页面截图或 Office/文本文件；沉浸光感材质同样只在 HarmonyOS 7 提供，HarmonyOS 6 使用普通界面。
语音输入依赖设备的系统识别引擎；云备份需登录华为账号并在系统云空间开启 Tinybot。
会话与工作区文件默认保存在本机，主动云备份时会上传快照至华为云空间；使用模型或远程工具时，相关消息、附件内容、工具参数/结果会发送至你配置或请求访问的服务。备份包含经华为账号信息加密的模型 API Key，同账号可恢复；MCP 与搜索凭据不导出，对话与文件不加密。
