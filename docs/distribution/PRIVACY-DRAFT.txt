1. 应用与服务
Tinybot 是由个人开发者提供的原生 AI 客户端。应用没有 Tinybot 账号注册与登录系统，不内置模型服务账号或免费额度。用户选择并配置外部模型或远程工具服务，通过手机直接发起请求。

2. 在本机保存的信息
应用在本机沙箱中保存聊天消息、草稿、附件副本、文件工作区、会话分支、摘要、记忆、模板、Skills 文档、服务配置和模型用量记录。用量记录包括模型名称、请求时间、状态、耗时及服务报告的 Token 数据。
主动引用其他会话时，会将所选对话的文字快照保存在当前会话中；原会话后续修改或删除不会同步删除已经保存的引用快照。思考档位随会话保存。
模型 API Key、MCP Token 与 OAuth 凭据使用系统 Asset Store 保存；应用配置禁止这些凭据跨设备同步。手动导出的备份不包含这些凭据。
本版本没有集成广告、商业行为统计或独立的开发者遥测 SDK。错误诊断可能由本机系统日志记录；用户主动分享日志或资料时需自行确认内容。

3. 向外部服务发送的信息
当用户发送消息、压缩上下文、提炼记忆或启用自动记忆时，为完成相应操作，会把必要的消息、已有上下文、已选记忆、附件文字/图像以及工具结果发送给所配置的模型服务。手动提炼会发送所选消息及必要的前一条用户消息，候选经确认后才保存；自动记忆是单独的可选设置。
读取网页会向指定站点发送访问请求。远程 MCP 调用会把相应工具参数发送给该服务，返回结果可能继续发送给模型。图片生成/编辑会向所选图片模型发送提示词和必要的参考图片。OAuth 登录通过授权服务完成，相关令牌用于连接选定的 MCP 服务。
发送带会话引用的消息时，所选文字快照会作为上下文发送给当前模型服务。JavaScript 执行工具在本机运行所提供的代码及 JSON 输入，代码运行时不开放网络、文件或宿主工具 API；执行结果和日志会作为工具结果提供给模型，并可能随对话记录保存在本机。
网络接收方会获得完成网络通信所需的信息，如 IP 地址。外部模型、MCP 服务、访问的网站和授权服务分别适用自己的隐私政策、保存期限与服务条款。具体接收方、处理地区和可能的跨境情况取决于用户的服务选择，开发者不能对所有自定义服务作统一保证。

4. 权限与系统选择器
当前清单仅申请 INTERNET 网络权限。图片、文档通过系统选择器或系统分享授予的 URI 导入，不申请整个图库、通讯录、定位、麦克风或相机的读取权限。导出和分享由用户主动操作并选择目标位置或接收应用。

5. 可选功能与操作控制
自动记忆、自动模型路由和任务结果归档默认关闭，可在助手设置中启停。用户可管理手动记忆、模板、Skills、模型及 MCP 配置；远程工具和图片生成调用会展示确认。停止任务会尽力取消未完成的本机请求，不代表撤销远程服务已经完成的操作。

6. 保存、删除与备份
会话和资料按功能需要保存在本机。用户可以在应用中删除会话、记忆、模板、服务配置及工作区文件。当前“删除会话”不会自动删除保留的工作区文件，附件副本和用量记录也不随每条消息删除而即时回收。需要清理全部本机沙箱资料时，可使用系统应用数据清除能力；卸载或系统清理的具体行为由操作系统管理。
用户主动导出的备份、分享的材料及外部服务已接收的数据，需在对应存储位置或向对应接收方另行处理。本应用当前关闭系统自动备份恢复，提供用户主动的文件备份功能。
