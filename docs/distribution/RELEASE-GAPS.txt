Tinybot 正式发布前待完成项
版本更新后需重新运行发布准备脚本，生成与 0.1.4 / 10004 一致的软件包和校验信息。

已准备
• 个人发布路线，包名 com.sudojacky.tinybot，版本 0.1.4 / 10004。
• Release APP/HAP、商店图标、符号表、应用文案、测试说明、隐私内容草稿。
• 包内 debug=false，SDK 与 pack.info 标为 Release，权限为 INTERNET 和按需申请的 MICROPHONE。
• 新增 arm64-v8a / x86_64 沙箱库检查及匹配 Build ID 的原生调试符号，随包附 QuickJS MIT 许可。

正式提交前仍需完成
1. 发布签名与软件包上传：在 DevEco Studio 26 的 Upload Product 中关联 AGC 应用，使用云管理证书重新签名并上传；或提供合法的发布签名配置。现有本地 debug Profile 不是发布签名。
2. 个人开发者资料：补充对外开发者名称、真实联系邮箱及平台要求的实名信息。工程 vendor=SudoJacky 不等于已确认的法定主体资料。
3. 隐私政策：补齐草稿，选择 AGC 隐私托管或可公开访问的 HTTPS URL；在应用中接入相应的展示/同意流程和可再次查看的入口。当前代码未实现专门的隐私政策入口或签署流程，文稿本身不等于已完成接入。
4. 资质：按最终发布地区、分类和当前 AGC 审核要求核对应用备案、名称/图标权利及生成式 AI 相关申报材料；本应用采用用户自配模型，不能据此推断自动免除有关要求。不要将个人调试证书指纹当作发布备案使用的证书指纹。
5. 审核体验：提供审核专用、可访问、限额可撤销的模型服务配置，否则审核/自动测试无法完整体验核心功能。
6. 素材：交付附带工程使用的 512×512 图标，上传前按 AGC 实际字段核对尺寸，必要时补充高清原始素材；重新拍摄 0.1.4 实际界面截图并检查内容。填写年龄分级、价格、地区、分类及当前必填项。截图尺寸和数量以实际字段为准。
7. 云测试：选择 API 26 手机，获取并处理兼容性、稳定性、隐私、安全等实际报告；本地测试通过不代表云测试或上架审核通过。
8. 版本：若 AGC 已使用 versionCode=10004，增加构建版本后重新打包，不要重用冲突版本号。
9. 安装后首次启动：0.1.2 历史模拟器首次自动检查遇到安装 PACKAGE_CHANGED 事件后的场景销毁，重启及再次安装复验正常；保留记录并在云手机验证首装、升级后首次启动，详见 CLOUD-TEST.txt。

实现边界需如实披露
• 华为云空间手动快照与恢复已接入；真实账号上传和跨设备恢复尚未验证。语音输入依赖系统引擎，尚未验证实际人声转写准确率。
• 不提供内置模型额度；联网 AI 体验依赖用户/审核人员配置的外部服务。
• PDF 扫描件无 OCR，Office 为文字提取。
• 应用删除会话后仍保留其工作区文件，附件和用量记录也不是逐条即时回收；隐私声明不能声称“删除会话即删除全部关联数据”。
• MCP OAuth 和图片服务的真实端到端兼容性仍需所选服务验证。
• JavaScript 沙箱为同进程 QuickJS 解释器隔离，不是独立操作系统进程；不提供 Python、TypeScript 转译、网络、文件或宿主 API。超时和内存限制仍需在云手机 ARM64 环境回归。
