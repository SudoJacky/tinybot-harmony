# 关于与帮助

聊天输入框下方以 12 fp 小字显示“AI可能会犯错，请仔细鉴别。”，使用系统明暗主题的次要文字颜色，不随消息滚动。英文模式使用对应英文提示，允许自动换行。

设置首页底部新增“关于”分组。这些入口不受模型任务运行状态限制：

- **使用帮助**：模型配置、附件与语音、个人偏好与记忆、文件备份、连接问题；可打开首次使用指引。
- **评分和评论**：直接打开华为系统评价弹窗，可评分或打开“写评论”表单。不收集问题描述或诊断资料。
- **关于 Tinybot**：图标、名称和实际安装包的版本名称/版本号；更新说明、公告、评分和评论、首次使用指引、用户协议、隐私政策。评分入口与设置首页共用同一调用。

更新说明与公告当前随应用打包，不接远程公告后台；公告暂为空状态。首次使用指引为可随时重看的说明页，目前不在启动时自动弹出。用户协议与隐私政策没有正文和链接，保留禁用入口并标记“待补充”，不构造同意记录。

## 应用市场接入

`services/AppInformation.ets` 使用 `bundleManager.getBundleInfoForSelfSync` 读取当前包名与版本。

评分和评论使用 `@kit.AppGalleryKit` 的 `commentManager.showCommentDialog(context)`，由系统呈现当前应用的评分弹窗与评论表单，处理用户提交。

依据华为官方[应用内拉起应用市场评论页示例](https://developer.huawei.com/consumer/cn/doc/doccenter-industry-solutions/comment-0000002292394860)。开发者回复能力见[AppGallery Connect 互动评论说明](https://developer.huawei.com/consumer/cn/agconnect/business-service/)。

设置和关于页直接打开系统弹窗，不增加中间评分页、不预填星级。`showCommentDialog` 返回值不代表用户提交成功，因此不显示“已评价”状态或持久保存已评价标记。调用期间阻止重复打开；失败显示错误及原始错误码，关闭后可重试，不自动回退到另一流程。

入口仅由用户主动点击，不自动弹出评分、不收集或发送聊天、配置及日志。页面不再显示反馈说明、问题收集文案或上架提示。当前没有应用内私密工单或回复收件箱。

弹窗与表单是否可用由系统服务决定。打开表单不代表评价已发布，发布结果由系统处理。

## 验证

```powershell
node scripts/build-locales.cjs --check
$env:DEVECO_STUDIO_HOME = 'C:\Program Files\Huawei\DevEco Studio'
node scripts/test-i18n-native.cjs
node scripts/test-system-bars-native.cjs
devecocli check arkts
devecocli build
```

真机验收：

1. 检查空对话、有消息、键盘展开和收起时的底部提示；切换明暗主题及英文，确认可读且不截断。
2. 从聊天更多菜单或侧栏打开设置，滑到底部，依次打开帮助、评分和评论、关于；检查子页返回及评分弹窗取消。
3. 核对“关于”版本与安装包；打开更新说明、公告、首次使用指引，确认内容可滚动；协议和政策不能打开或产生同意记录。
4. 从设置与关于分别点击“评分和评论”，确认直接打开 Tinybot 的系统弹窗；点击“写评论”检查表单，取消后可再次打开。测试不应选择真实星级或提交评论。
5. 平台调用失败时检查错误提示和重试；实际发布与开发者回复需市场侧联调，不能以静态检查代替。

### 2026-10-07 首轮真机验证（原反馈入口）

在 Mate 70 Pro+ 上覆盖安装 0.1.4 / 10004 调试包，构建、安装及启动成功。已验证已有对话和空会话中的 AI 提示、键盘展开/收起、中英文、明暗主题，以及聊天菜单/侧栏设置入口、帮助页滚动、关于各子页与返回、实际版本和禁用的协议占位。

验证时发现运行中切换主题会让状态栏文字颜色滞后一拍：`onConfigurationUpdate` 的新主题已更新，`context.config` 仍为旧主题。现改用回调参数设置状态栏颜色；双向切换已在真机复测，`test-system-bars-native.cjs` 覆盖启动和上下文尚未刷新时的双向回调。

反馈、查看评论与回复、评分均可打开华为应用市场，但市场显示“此应用暂不支持在当前设备安装”。这只证明跳转成功，不代表评论提交与开发者回复可用；完整市场流程仍待应用具备上架/设备可用条件后验证。未提交真实评论。缺少市场处理程序时的错误传播已由模拟平台适配检查覆盖，未在真机卸载/禁用系统应用进行测试。

### 2026-10-07 评分和评论入口复测

将反馈入口改为“评分和评论”，移除页面中的上架提示，改用系统应用内评价 API。最终版本已构建并覆盖安装至同一真机，启动 Smoke PASS。

设置和关于两个入口均直接打开带 Tinybot 图标和名称的系统弹窗，显示未选中的五星、“写评论”和“以后再说”。取消后回到原页面，可从另一入口再次打开；“写评论”可打开 Tinybot 的星级与评论表单，关闭后返回关于页。全程未选择星级、填写或发布评论；真实发布和开发者回复未验证。旧版市场详情页的不可安装提示不能用于推断新版系统评价表单不可用。
