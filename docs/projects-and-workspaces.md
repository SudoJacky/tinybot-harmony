# 项目、会话与共享工作区

[文档索引](README.md) · [项目首页](../README.md)

## 项目归属

- **项目**：左侧栏以可折叠的项目分组显示会话，未归属项目的会话放在“普通聊天”；空项目保留标题与新建入口。顶部可新建项目，各项目菜单可编辑名称与说明、打开项目文件。项目旁的加号在该项目内新建会话，顶部“新对话”和“普通聊天”旁的加号创建无项目归属的会话。在项目内新建会话共享同一工作区和项目指令，对话历史、附件、模型与 MCP 设置保持各自归属；引用其他会话优先显示同项目会话。项目会话的分支与重新生成沿用当前文件，不复制或回退代码。删除会话保留项目和文件。旧会话默认无项目归属，不搬文件；首版不提供旧会话转入、项目移动或删除。

## 目录与生命周期

- 普通会话的默认工作区位于应用级 `ApplicationContext.filesDir/workspace/`，每个会话使用 `<会话ID>/` 子目录，无需额外存储授权。当前会话未编辑且归属与目标相同时，重复点击“新对话”复用当前会话，不重复创建会话或目录。有草稿、附件、引用、待发送输入、消息、手动名称、置顶或分支归属时仍新建；跨项目也正常新建。新建空会话立即保存，重启和切换沿用同一目录；已有会话启动时自动补建目录。
- 工作区路径在运行时推导：普通会话使用会话 ID，项目会话使用项目的稳定 workspaceId（均位于 workspace/ 下）。项目目录丢失会明确报错，不自动补建空目录。拒绝路径穿越和符号链接目录。创建目录失败会明确提示；删除会话保留工作区文件，卸载应用或清除应用数据仍会清除这些文件。

## 会话分支与重新生成

- **重新生成** 从所选回答的上一条用户消息创建分支并再次发送，保留原回答、后续历史和原草稿；附件、会话引用和 MCP 停用设置随分支保留。**分支** 保留所选助手消息及之前内容。普通聊天分支使用独立空工作区，历史文件不复制；项目内分支继承项目归属，使用同一份当前文件。模型会收到相应说明。运行中或存在保存错误时不可创建分支或重新生成，保存新分支失败时不发起生成。

## 文件审阅与恢复

- **文件**：浏览当前会话工作区、打开子目录、新建/编辑/删除文本、导入材料、保存到系统文件夹和分享。删除需确认；导入使用新文件名。每次文本首次修改前持久保存基线，可预览增删行、保留修改或恢复；恢复前检查当前内容是否变化。项目工作区的待审基线包含各会话累计修改，恢复会明确提示；聊天中的“本轮修改”仍只描述该轮历史差异。新建文件恢复时删除该文件。CSV/TSV 表格预览及文本选段可引用到草稿。

工作区工具的路径、版本校验与修改回执见[工具执行与权限](tools-and-permissions.md)。备份中的项目归属和共享文件恢复见[云备份](cloud-backup.md)。
