# 华为云空间备份与恢复

在「设置 → 备份与恢复」使用个人华为账号的云空间保存手动快照。应用采用 Core File Kit 的端云文件协同，不需要 Tinybot 账号、服务器或 WebDAV 配置。

## 使用

1. 在系统「设置 → 云空间」登录华为账号并开启 Tinybot；应用提供「打开华为云空间」入口，无法跳转时按页面提示手动前往。
2. 点「备份到华为云空间」创建当前数据的快照。后续修改需要再次备份，打开页面不会自动创建备份。
3. 查看每份备份的状态。**仅保存在本机，等待上传**尚不构成云端备份；只有文件位置为云端或本机及云端时才显示**已上传云端**。
4. 另一台设备登录同一华为账号、安装 Tinybot 并开启云空间开关后，点「刷新备份列表」。点击备份并确认，下载完成后恢复为独立副本，现有对话不会被覆盖。
5. 每份备份右侧的删除按钮可删除该快照。确认框会显示备份日期；取消不做修改。删除会同步到云端及其他设备，不影响当前对话和设置，无法在 Tinybot 内撤销。网络失败或同步超时会明确提示删除尚待同步，可稍后刷新重试。

每份备份最多 20 MiB，沿用本地 `tinybot-harmony.backup.v1` 格式，包含对话、附件、工作区文件、Skills、模板、记忆和用户文档。配置中的 API 密钥、Token 与凭据别名不导出；恢复保留本机已有密钥、服务设置和助手选项。模型服务按协议及完整服务地址匹配（忽略地址末尾斜杠），MCP 按完整 URL 匹配，优先使用原服务 ID；没有原 ID 时只复用唯一匹配项。恢复的对话、历史消息、团队模型及会话 MCP 禁用项会指向匹配的本机服务，不增加重复服务。无法匹配或存在多个候选时，导入为停用副本，配置凭据后才能使用。本机模型列表不被覆盖，恢复对话所选模型不在本机列表时需重新选择。对话和附件本身的内容保留原文。语言偏好和请求用量账本不在备份范围内。

本地导出与导入仍可独立使用。第一版没有定时备份、实时数据合并、密钥同步或自动清理旧备份；每次手动备份会占用额外的云空间。

## 实现

- `AppScope/app.json5` 的 `cloudFileSyncEnabled` 声明接入端云文件协同。
- `services/Backup.ets` 共用快照生成与文件恢复逻辑；文件选择器只负责本地导入、导出入口。序列化时复制输入，避免脱敏修改运行中的配置。
- `model/BackupRestore.ets` 在会话服务提交导入前匹配已有服务、重映射引用，只修改独立的导入副本；匹配时不读取、写入或删除本机凭据。导入保存失败不切换当前配置。
- `services/CloudBackup.ets` 只使用 `UIAbilityContext.cloudFileDir/tinybot-backups`。原生云目录不可用时明确失败，不创建替代的本地「云目录」。
- 快照以时间戳及 UUID 命名；完整写入临时文件后重命名，列表只收录完成的 `.json` 文件，不覆盖历史备份。
- 列表与恢复先用 `lstat()` 排除符号链接及非普通文件，再用 `stat(path).location` 查询云端位置。真机系统文件库读取 `lstat()` 结果的 `location` 会触发原生空指针崩溃，不能通过 ArkTS 异常捕获恢复。
- `FileSync.start()` 只表示请求已发起。订阅同一个实例的完成/失败回调，等待上限 30 秒；超时后仍按文件的 `location` 展示真实存储状态，系统可继续上传。「刷新」会重试待上传快照并获取其他设备元数据。
- 恢复云端文件时，等待 `CloudFileCache` 对应 URI 的下载完成回调，上限 60 秒；失败/超时会停止该下载并移除监听，不导入不完整文件。恢复前校验文件名、大小、格式、引用和工作区路径，使用新的会话与附件 ID。
- 原生同步/下载操作全局串行；页面重开也不会重复并发调用。关闭页面不会自动生成快照。
- 删除同样使用全局操作锁，校验备份文件名与文件类型后仅 `unlink()` 指定快照，再请求同步；不下载云端文件，不删除工作区、对话或其他备份。文件删除成功但同步失败会明确区分本机删除与云端同步结果。
- 系统 `BackupExtensionAbility` 是另一项能力，本次不启用它，也不宣称应用可主动触发系统整机备份。

## 验证

`node scripts/test-productivity-native.cjs` 使用实际 ArkTS 服务、真实临时文件和可控的原生回调，覆盖快照脱敏与不变性、上传状态、配额失败保留快照、写入失败清理、等待下载完成、错误 URI 隔离、恢复为独立副本、非法路径拒绝、超时和并发锁释放。文件适配器区分 `lstat` 与 `stat` 的位置属性，覆盖已有备份重复加载及非普通文件拒绝。删除测试覆盖三种文件位置、只移除选中快照、失败保留文件、同步失败重试和并发限制；真实导出/读取/导入路径验证服务配置复用。`SessionService.test.ets` 还验证恢复后模型请求使用原 Key、MCP Token 不变、账户歧义与地址变更不误用凭据、保存失败不改变本机状态。使用 `DEVECO_STUDIO_HOME` 指定 DevEco Studio 安装目录。

真实上云与跨设备恢复需要两部支持端云协同的设备、同一华为账号及已开启的 Tinybot 同步开关。原生适配测试不能代替这项验证。官方适配说明要求 HarmonyOS 6.0.0.115 及以上、云空间 6.0.0.300 及以上，详见[端云文件协同适配指导](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/app-cloud-sync-filesync)。
