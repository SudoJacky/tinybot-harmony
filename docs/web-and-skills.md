# 网页、搜索与 Skills

[文档索引](README.md) · [项目首页](../README.md)

## 网页读取

在聊天中发送“读取并总结 https://example.com/”，模型可使用 `read_web`。网页读取默认启用，可在 **设置 → 允许联网** 关闭；停用后既不向模型提供工具，也不接受该工具调用。

- 网页读取仅支持 HTTP/HTTPS GET，搜索使用独立接口；网页读取不携带模型密钥、登录 Cookie 或自定义认证头。地址不能包含用户名和密码；每次重定向重新校验协议，最多跟随 5 次。
- 一次读取含重定向最多 30 秒，响应最多 1 MiB；HTML 提取静态正文与标题，文本、Markdown、JSON 等按文本返回。正文最多 20000 字符、链接最多 30 个，超过时分别标记截断。
- 脚本、样式等不进入 HTML 正文；不会执行 JavaScript、绕过登录或验证码。PDF、图片、无正文页面、不支持的编码和 HTTP/网络错误会明确返回失败。
- 网页结果带有来源 URL 和 `trust: untrusted`，作为资料交给模型；停止会销毁正在进行的网络请求，阻止后续工具。网页内容仍可能不完整或过时，引用应保留来源并说明截断。
- 网页读取将网站声明的 favicon 地址保存为独立的界面元数据（未声明时使用站点 `/favicon.ico`），不放入发给模型的工具结果；旧版结果中的该字段在加载时迁移。工具行在允许联网时加载并显示原色图标；加载失败、旧记录没有图标信息或关闭联网时保留通用图标，不重新读取网页，也不通过第三方图标服务查询。

## 应用内浏览器

`browser_open` 获取或复用独立的浏览器操作会话。`publish_preview` 发布的 JS/HTML/SVG 在聊天消息内嵌入隔离预览，不申请或改变浏览器会话，也不继承其网络、存储和控制权；详情见[交互预览](interactive-ui.md)。

Tinybot 操作网页时，可以展开浏览器观看并自由滚动或缩放，任务继续执行。点击网页、编辑输入、修改或提交地址、执行后退/前进/刷新，或点击「接管浏览器」时才切换为用户控制；任务等待明确「交还给 Tinybot」后继续。已经发出的网页操作会完成，不会因接管而撤销或自动重放。

聚焦地址栏、选择或复制地址不会接管。没有历史记录时后退、前进按钮禁用，也不会暂停任务。系统返回先退出地址编辑；用户控制时优先网页后退，历史到头才收起；Tinybot 控制时直接收起观看面板，任务继续。收起保留网页，关闭会结束浏览器。

滚动、缩放、窗口大小变化或目标控件的内容、位置变化后，旧快照不能继续用于点击或输入，Agent 必须重新读取页面。浏览器仅支持 HTTP/HTTPS；网页内容作为不可信资料发送给当前模型，密码及验证码控件需要用户接管。

## 内置 Skills

应用提供五个默认启用的文本 Skill，可由模型按任务选择，也可在 **设置 → 管理 Skills** 点击“在对话中使用”，或直接输入 `/skill:名称`：

聊天输入框中输入 `$` 可唤起 Skill 列表，继续输入中文显示名称、英文名称或用途关键词来筛选；列表只包含已启用的 Skill，也包含只能手动调用的 Skill。点击后转换为现有的 `/skill:名称` 命令，保留其他已输入内容并回到输入框，不自动发送。一条消息选择一个 Skill，再次选择会替换之前的选择。支持光标处插入；`$20` 和 `US$20` 等金额不会唤起列表。

| Skill | 名称 | 用途 |
| --- | --- | --- |
| 资料速读 | `document-brief` | 阅读文档、文章和截图，提炼结论、依据及待核实项 |
| 联网调研 | `web-research` | 搜集并核实来源，比较方案，保留时间和适用范围 |
| 随手记整理 | `notes-to-actions` | 整理口述、会议与零散想法，区分决定、待办和问题 |
| 数据分析 | `data-analysis` | 检查 CSV/JSON/文档表格的数据口径，计算并展示结果 |
| 草图变原型 | `sketch-to-prototype` | 将手绘、截图或布局说明变成可预览的 HTML/SVG 或交互演示 |

内置 Skill 只提供工作指导，不增加工具或权限。联网调研仍需开启联网；搜索需配置搜索服务；图片理解仍需视觉模型；原型沿用现有预览沙箱，不能联网、调用设备能力或安装为原生应用。

首次启动和旧版升级时，内置内容作为本地副本保存，不覆盖同名的用户 Skill、联网设置或已有文档。可停用、编辑、重命名或删除，重启不会恢复这些操作；修改后的正文视为自定义内容，不再显示“内置”标记。后续应用更新不覆盖这些已安装副本。已有 Skills 数量或资料总量达到上限时，暂缓安装未放入的条目，腾出容量后下次启动继续安装。备份与导入沿用现有 Skills 合并规则，保留本机已有条目。

## Skills 导入与调用

在 **设置 → 管理 Skills → 添加** 导入单个 `SKILL.md` 或粘贴其内容，检查后保存。例如：

```markdown
---
name: page-summary
description: 总结用户提供的网页，提取要点并保留来源链接
---

先读取用户提供的网址，再整理三个要点。保留来源 URL；读取失败或正文截断时明确说明。
```

Skill 引用 `references/guide.md` 等文件时，在编辑页填写相同的相对路径，再导入或粘贴参考文本并点击“添加参考文件”。这些内容作为副本保存在本机；没有持续的外部目录授权。当前不批量导入目录或 ZIP，不运行 Shell、Python、Node.js 或 Skill 内脚本。

- 元数据支持 `name`、`description` 的普通/引号文本及 `|`、`>` 多行文本；不是完整 YAML 实现，对这些字段中的对象、引用或无效值明确报错。其他元数据保留在文档中，不授予工具权限。
- 支持 `disable-model-invocation: true`，该 Skill 只在用户显式调用时提供给模型。点击“使用”会把 `/skill:名称` 放入聊天草稿，也可手动输入 `/skill:page-summary 读取这个链接……`。
- 默认仅把已启用、允许本轮使用的 Skill 名称和简介加入上下文；`read_skill` 读取正文时列出参考路径。未导入参考文件、越界路径、重复名称或未启用的 Skill 均明确报错。
- 每次运行固定可用 Skill 及其正文副本；工具结果按现有检查点落盘并参与历史回放。之后停用或删除不会删除旧对话里已经读取的资料。
- 最多保存 20 个 Skills，每个最多 16 个参考文件。单个文档最多 32000 字符，所有文档合计最多 512000 字符；文件选择器单次导入只接受最多 64 KiB 的 UTF-8 文本。

## 联网搜索

- **设置 → 联网搜索**：通用 `search_web` 接口支持 DeepSeek 原生搜索和 Tavily，分别适配请求与结构化来源，统一返回标题、URL、摘录及可用的来源时间。DeepSeek 使用固定的官方 Anthropic Messages 搜索接口和内置搜索模型，不再提供额外的地址、模型或独立密钥输入。只有一个使用官方地址、已启用且配置了 API Key 的模型服务时自动复用，多个时仅需选择已有服务。保存时检查密钥，运行时解析服务引用以跟随密钥轮换；服务删除、停用或改为非官方地址时明确失败。Tavily 保留独立地址和密钥配置。搜索默认关闭，“允许联网”同时控制网页读取和搜索。搜索密钥不进入模型上下文、日志或备份；辅助请求单独记录用量，服务未报告 Token 时保持未知。DeepSeek 只接受结构化原生搜索结果，不将模型自由回答作为来源。

## 搜索适配

`WebSearchTools` 只依赖统一 `SearchTransport.search()`；`NativeSearchTransport` 负责凭据解析、超时、取消、禁止重定向及用量记录，`services/search/DeepSeekSearchProvider.ets` 与 `TavilySearchProvider.ets` 各自编码请求和解析结构化结果。新搜索服务在此层适配，不修改 Agent Loop。

Tavily 请求字段参考 [Search API](https://docs.tavily.com/documentation/api-reference/endpoint/search)；DeepSeek 搜索协议对照本地 DeepSeek Harness `packages/web/web-search-deepseek`。接口和账号是否实际支持原生搜索需联调确认；普通聊天接口可用不表示搜索一定可用。

## 验证

`node scripts/test-browser.cjs` 覆盖浏览器权限、任务等待与恢复、观看手势和历史导航；构建后运行 `node scripts/test-browser-panel.cjs` 验证实际编译的地址栏与系统返回回调。`node scripts/test-browser-dom.cjs` 使用真实浏览器验证 DOM 操作、滚动/缩放后的快照保护和目标变化，需提供 Playwright（可通过 `NODE_PATH` 指向本机安装）。触摸回调与 ArkWeb 点击的先后顺序仍需真机验证。

本地测试包含 Skill 元数据/资料校验、手动调用限制、工具启停、网页正文提取、截断与错误、取消，以及通过真实 Agent Loop 读取 Skill 和网页后保存、恢复调用结果的流程。

内置 Skill 源文档位于 `skills/<名称>/SKILL.md`，目录及显示名称由 `skills/catalog.json` 管理。修改后运行 `node scripts/build-builtin-skills.cjs` 生成 ArkTS 文本包，`--check` 检查同步；已纳入 `scripts/test.ps1`。`node scripts/test-resources.cjs` 覆盖实际 SessionService 启动安装、持久化失败重试、同名保护、容量限制、显式调用、读取，以及编辑/重命名/停用/删除后的重启行为。确定性测试验证接入与状态，不代表真实模型的任务质量评测。

构建后运行 `node scripts/test-skill-completion.cjs`，验证 `$` 查询、中文/名称/用途筛选、金额边界、停用与手动调用限制、光标处替换、现有命令切换，以及实际编译后的列表点击与延迟聚焦；已纳入 `scripts/test.ps1`。键盘遮挡、输入法与光标交互需在真机验证。

运行 `node scripts/test-harness-features.cjs` 验证搜索提供方、密钥复用与轮换、设置提交失败回滚、取消和重定向、文件回执恢复、引用快照隔离、重复调用提醒及有限重试；已纳入 `scripts/test.ps1`。测试使用真实业务代码与确定性网络/存储适配，不消耗在线额度。
