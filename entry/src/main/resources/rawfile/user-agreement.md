# Tinybot 用户协议

版本日期：2026年10月26日

本协议适用于由顾志豪提供的 Tinybot 鸿蒙版应用。请在使用前阅读，尤其注意以加粗方式提示的第三方费用、AI 输出风险、工具操作、数据保存及责任条款。如有疑问，可通过本协议末尾的邮箱联系我们；如不同意，可停止使用本应用。

## 1. 服务范围与使用资格

1.1 Tinybot 是开源 AI 客户端，提供聊天、文件与工作区管理、模型连接、记忆、Skills、工具调用和备份等功能。具体可用功能以安装版本、设备能力和您启用的设置为准。

1.2 本应用不自营基础模型服务。需要模型或远程工具的功能由设备连接您配置的实际服务地址；您应依法取得相应服务的使用资格，遵守适用的服务条款。本应用中的服务名称、预设或兼容协议说明不代表有关第三方为 Tinybot 提供担保、授权背书或共同运营。

1.3 您应具有与使用行为相适应的民事行为能力。未满18周岁的用户应在监护人的同意和指导下使用，由监护人协助管理付费服务、个人信息及高风险操作；第三方服务另有合法年龄要求的，还应遵守其要求。

1.4 当前版本无需另行注册 Tinybot 账号；使用 AI 生成功能前需登录华为账号，包括聊天、标题、摘要和记忆提炼。未登录时可查看本地会话、准备草稿和配置模型服务。华为账号登录不代表本应用已经核验用户真实姓名或身份证件。第三方模型、授权登录及华为云空间账号由相应提供方管理，请妥善保管设备、API Key、令牌和其他凭据，不向无关人员提供访问权限。

## 2. 服务费用与第三方服务

2.1 当前版本不提供 Tinybot 会员订阅、自动续费或应用内购买，也不赠送或转售第三方模型额度。未来如新增收费服务，会在购买前说明价格、权益、期限、取消及退款规则，并依法取得确认；本协议本身不构成扣费授权。

**2.2 模型调用、工具服务、网络流量或云空间可能产生第三方费用，按照您与对应提供方的约定结算。测试连接、获取模型列表、自动标题、上下文压缩、记忆提炼、模型分工和团队任务也可能发起请求。取消或停止任务不代表第三方已执行的操作或计费一定撤销。**

2.3 请核实实际服务地址、模型、权限及费用。第三方可能变更接口、价格、地区限制或可用性；发生故障时，您可调整配置或停止使用相应功能。第三方条款与本协议分别约束各自服务，不因此免除我们依法应承担的责任。

## 3. 输入、输出与内容权利

3.1 您提供的消息、文件、图片、记忆、Skills 及其他输入，应具有合法来源，并取得完成相应处理所需的权利或授权。不得违法提交国家秘密、商业秘密、他人个人信息或受保护的内容。

3.2 您对输入原有的权利保持不变。我们不因您使用本应用而取得您输入或生成内容的所有权；仅在提供您请求的功能、依法履行义务所必需的范围内，依照隐私政策处理有关内容。本协议不授予我们将您的对话用于模型训练、公开传播或出售的概括授权。

3.3 生成内容能否获得知识产权保护、如何使用以及是否包含第三方权利，应结合适用法律、具体内容和实际模型服务条款判断。**我们不保证生成内容具有独创性、排他性或不侵犯他人权利，也不能转让我们并不享有的权利。**

3.4 发布、分享或商业使用前，请核实内容和权利来源，并保留依法需要的来源说明、许可及标识。

## 4. AI 输出风险与生成内容标识

**4.1 AI 输出可能存在事实错误、遗漏、过时信息、虚构引用或不适当内容。生成内容不代表开发者意见，不构成医疗诊断、法律意见、投资承诺或其他专业服务；涉及人身、财产或他人重要权益的决定，应由具备相应能力的人核实，不得仅依赖自动输出。**

4.2 本应用通过聊天中的助手身份及输入区下方的“AI生成内容可能有误，请仔细鉴别。”提示，说明相关回复由 AI 生成。请仔细阅读相关提示，区分 AI 回复、工具结果与您自己的输入。

4.3 复制、导出或向其他平台分享后，应用内提示可能不会随正文展示，不能据此将 AI 内容冒充为人工原创或已核实事实。您使用网络信息内容传播服务发布生成合成内容时，应依法主动声明，并使用该平台的生成合成内容标识功能；不得恶意删除、篡改、伪造或隐匿依法设置的标识。

4.4 标识义务依照适用法律和具体功能履行。本协议中的风险提示及用户义务，不替代本应用或相关服务提供方依法应履行的内容标识、技术措施及其他义务。

## 5. 工具、Skills 与任务授权

5.1 模型可能根据任务读取或修改允许访问的工作区文件、运行本地代码、访问网页，或调用您配置的远程工具。Skills、网页及第三方返回内容可能包含错误或不可信指令，请结合任务核实来源。

**5.2 请在授权前核对任务范围、文件、参数、接收方及可能的影响。启用模型、导入 Skill、接受本协议或提出一般性问题，不等于授权任意支付、发布、删除、对外发送资料或扩大系统权限；需要您确认或授权的操作，仍应遵守具体功能的提示和要求。**

5.3 工具结果可能有误，部分远程操作无法回滚。请及时查看执行结果，对重要资料保留备份；发现误操作时可停止任务并通过实际服务核实处理情况。本协议不将由我们过错造成的后果一概转由您承担。

6.1 不得利用本应用从事违法活动，包括危害国家安全、诈骗、侵犯隐私或知识产权、传播违法信息、恶意攻击或未经授权访问他人系统，以及其他侵害合法权益的行为。

6.3 请勿借助 AI 冒充他人、伪造事实或实施欺骗，不得未经适当核验将输出用于对个人具有重大影响的自动决策。对发现的漏洞、违法内容或侵权问题，可向我们提供必要线索；请勿在反馈中发送完整密钥或无关敏感资料。

## 7. 隐私、保存、删除与备份

7.1 个人信息处理规则请阅读“设置 → 关于 Tinybot → 隐私政策”：该入口打开华为托管的隐私政策全文（需要网络），并可在同一入口撤回隐私授权。模型请求、辅助请求、记忆、远程工具、授权及备份所涉及的信息，按照隐私政策、具体功能告知和适用法律处理。

**7.2 接受本协议不代替系统权限授权、个人信息处理所需的有效同意，或依法要求的单独同意。阅读本协议或隐私政策页面本身，不会自动生成同意记录。**

7.3 重要会话、工作区、附件和配置请按需备份。卸载、清除应用数据、设备损坏或误操作可能导致本机资料丢失。手动备份不包含配置中的 API Key、令牌等凭据，恢复后部分服务需要重新配置；对话正文或文件中由您自行填写的秘密信息仍可能进入备份。

7.4 删除某项本机数据不当然删除已经形成的其他独立副本、记忆、引用、导出文件、云端备份或第三方已接收的数据。请结合各功能说明，分别管理对应资料，并向实际接收方行使相关权利。
