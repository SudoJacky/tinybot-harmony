## 5. 个人信息处理清单

### 5.1 模型配置与身份验证

您添加或编辑模型服务时，本应用保存服务名称、服务地址、协议、模型名称、能力及参数设置、默认模型和模型分工等配置。您填写的 API Key 用于向对应服务进行身份验证；部分服务可不使用 API Key。测试连接、获取模型列表及调用模型时，会向配置的实际服务地址发送完成请求所需的身份验证信息。仅填写“OpenAI 兼容”等协议名称，不代表信息一定发送给该品牌的官方服务。

### 5.2 聊天与附件

为保存和继续对话，本应用在设备上处理您的消息、草稿、待发送任务、模型回复及其返回的推理内容、会话标题、分支、引用快照、时间及会话标识。您选择图片或文档后，本应用处理选定文件的名称、类型及内容；图片可能经缩放、转码后保存，文档可能提取为文字副本。导入或选择文件本身不代表立即发送给模型。

当您发送消息或继续任务时，为完成该请求，本应用向本轮实际使用的模型服务发送输入、选定的历史上下文或摘要、有关图片或附件文字、用户文档、适用的记忆及已经读取的工具结果等必要内容。接收方会获得 IP 地址、请求时间及相关协议字段等通信所必需的信息。没有提供相关消息内容时，模型服务无法完成该次生成；不提供附件不影响纯文字功能。

### 5.3 标题生成与上下文压缩

首轮聊天符合自动命名条件时，本应用会另行调用该轮实际使用的模型，根据首条用户输入的有限片段生成会话标题，当前片段上限为 4000 个字符，该请求不以聊天回复成功为前提。自动或手动压缩上下文时，会将需压缩的历史内容发送给相应模型生成摘要。压缩不会自动删除本机完整历史。这些辅助请求也是向模型发送数据的处理，并可能产生额外服务费用。

### 5.4 长期记忆与用户文档

手动记忆：您可以直接填写、编辑或删除记忆；使用“提炼记忆”时，所选消息及必要的相关用户消息会发给您指定的记忆模型，未指定时使用当前模型。候选内容经您确认后保存，可选择用于当前会话或所有会话。

自动记忆：开启后，聊天成功完成时，本应用会额外将本轮用户消息的文字内容发给您配置的专用记忆模型，未配置时使用该轮聊天的实际模型，提炼偏好、背景或其他长期信息，并自动保存为可用于所有会话的记忆，无需逐条再次确认。当前版本配置预设为开启；该预设不构成您的同意，我们会在首次自动提取前让您明确选择，未取得有效授权前不进行该可选处理。您可以在设置中关闭“自动提取长期记忆”。

用户文档：您在 USER.md 中填写的称呼、背景和偏好保存在本机，从下一轮起可加入所有会话及团队任务的模型上下文，清空后停止后续注入。

适用的已保存记忆可在后续任务中加入模型上下文；当您更换服务商、使用模型分工或团队功能时，相关信息可能发送给不同的已配置模型服务。关闭自动提取仅停止后续自动提取，不会删除已有记忆，也不会自动停止已有记忆在其他任务中的使用；您需另行删除有关记忆或调整其适用范围。删除原会话也不等于删除已形成的全局记忆、引用快照和用户文档。

### 5.5 工作区文件 技能与本地代码执行

本应用在当前会话工作区中保存您导入、编辑或由任务生成的文件，以及必要的修改基线和任务产物。模型调用文件工具后，读取到的文本及操作结果会作为上下文发送给相应模型。工具访问范围限于本应用所允许的会话工作区，不因您同意本政策而取得任意外部目录权限。

您导入或编写的 Skills 文档、参考材料及提示词模板保存在本机；启用或调用后，名称、简介、按需读取的正文、参考材料或套用后的内容可能进入模型上下文。JavaScript 代码工具在本机受限运行环境中执行代码和输入；执行结果及日志会成为工具结果，可能保存在对话中并回传模型。

### 5.6 模型分工与团队任务

启用自动路由时，本应用根据是否含图片、文本长度及任务特征，选择您配置的快速、深度或视觉模型。使用团队任务时，会将任务要求、必要的背景、子任务及交接结果提供给参与该任务的模型。实际接收方以本次任务使用的服务配置为准，不必始终与当前会话手动选择的服务相同。您可关闭自动路由、调整模型分工或停止团队任务。该功能用于任务处理，不用于广告推荐或差别定价。

### 5.7 网页读取 远程工具与图片生成

网页读取：当前“允许读取网页”配置默认开启。开启后，模型可为完成任务请求访问指定 HTTP 或 HTTPS 网页；目标网站会收到目标网址（包括可能存在的查询参数）及网络通信信息。读取结果可能继续发送给模型。本功能读取静态内容，当前不提供独立搜索服务，不登录网站或执行网页脚本。您可在设置中关闭。网页读取涉及的个人信息处理仍应在有效告知和适当授权范围内进行。

远程 MCP 工具：您配置或启用远程工具服务后，连接测试、服务初始化、工具发现及实际调用会与对应服务通信。实际工具调用前，本应用展示确认；确认后发送工具名称、相应参数及必要的授权信息，服务返回结果可能继续发送给模型。服务地址、工具描述、会话标识和执行记录可能保存在本机。调用可能使第三方读取、修改或发送数据，请核对具体工具及参数。

OAuth 授权：您选择 OAuth 登录时，本应用与相应资源或授权服务器交换授权所需的客户端信息、回调地址、授权码及验证参数，并处理返回的访问令牌、刷新令牌和期限等。登录由相应授权服务完成；您应通过其正式授权页面核实授权范围。

图片生成或编辑：您配置图片模型并确认相应工具调用后，本应用向该服务发送提示词及编辑所需的参考图片，接收图片或下载地址，并可能向返回的图片托管地址请求下载。生成结果可保存在当前工作区并展示。图片服务及图片托管方都可能成为相应网络请求的接收方。

### 5.8 本机用量与运行记录

为显示使用情况和排查请求结果，本应用在本机保存服务及模型名称、请求用途、时间、状态、耗时、服务返回的 Token 用量、会话和轮次标识、会话标题、用户输入片段（通常为每轮输入的前 80 个字符）、团队任务标题或成员名称，以及工具和 Skill 活动等记录。这些片段未经概括或脱敏，记录可能关联具体对话，不能视为匿名统计。当前版本没有集成广告、商业行为统计或独立的开发者遥测 SDK；不能因此推断模型提供方不会记录其收到的请求。

设备系统日志可能记录应用生命周期和错误信息，由系统机制管理。我们不通过本应用将其默认上传至自建诊断服务器。您主动提交反馈时，我们会处理您的联系邮箱、问题描述及您选择提供的截图、日志或其他资料，仅用于答复、解决问题和履行有关义务。

6.1 本应用的会话、配置及文件主要保存在您使用的设备上，设备所在地可能变化。模型与工具请求由设备连接所选服务；向外发送后的处理地区及保存地点取决于实际接收方和服务配置，不能仅凭“国内品牌”“兼容协议”或域名推断。

6.2 选择境外服务、境外代理或实际在境外处理的服务时，相关请求可能构成个人信息跨境提供。对于我们依法需要承担义务的跨境处理，我们会在处理前告知境外接收方名称或姓名、联系方式、处理目的、方式、信息种类，以及向其行使权利的方式和程序，取得依法要求的单独同意，并履行适用的个人信息保护影响评估及数据出境程序。

6.3 您自行填写境外地址、同意本政策或接受第三方条款，不代替我们应履行的义务。在有关条件未满足前，不开放相应的个人信息跨境传输。您可选择符合要求的其他服务，或继续使用不依赖该传输的本机功能。
