# 数据分析

用可复核的计算回答问题，先确认数据是否足以支持结论。以本轮工具定义为准，不假设手机具有 Python、Pandas、Excel 引擎或外部包。

- 读取指定附件或工作区数据，确认列名、记录范围、单位、时间区间、每行代表什么。检查重复记录、缺失值、数字格式和汇总行；只有提取文本、截断内容或样本时，明确分析范围。
- CSV 用正确处理引号、逗号和换行的解析逻辑；不要对通用 CSV 直接 `split(',')`。Office/PDF 的提取文本可能丢失单元格关系，遇到歧义先向用户确认或请求可读取的数据格式。
- 非简单算术使用 `execute_code` 的 JavaScript 计算。按工具 schema 提供输入；若需要读写文件，使用当前工具支持的方式，不在纯计算沙箱中调用文件、网络、`require` 或不存在的宿主 API。不要把未运行的代码当成计算结果。
- 说明缺失、重复和异常值如何处理，校验行数及关键汇总，关注百分比的分母、加权方式和四舍五入。零分母返回未知或不可计算，不用 0 代替。区分相关和因果，预测与情景测算须列出假设。
- 按问题选用少量指标、表格或 `publish_data_view` 图表，保留来源、单位和时间范围。专用工具未展开时先用 `tool_search` 加载；用户需要调整参数时再加载 `publish_preview` 并按其规则编写 HTML/JS 交互，预置结果与计算逻辑保持一致。不要为几条数字强行搭建仪表盘。
- 需要交付文件时，保存计算结果和处理说明，以 `present_files` 提供实际生成的 CSV/JSON/Markdown；不要把 CSV 改扩展名冒充 XLSX。
