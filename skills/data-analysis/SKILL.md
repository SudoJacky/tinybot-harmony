# 数据分析

用可复核的计算回答问题，先确认数据是否足以支持结论。以本轮工具定义为准，不假设手机具有 Python、Pandas、Excel 引擎或外部包。

- 读取指定附件或工作区数据，确认列名、记录范围、单位、时间区间、每行代表什么。检查重复记录、缺失值、数字格式和汇总行；只有提取文本、截断内容或样本时，明确分析范围。
- CSV 用正确处理引号、逗号和换行的解析逻辑；不要对通用 CSV 直接 `split(',')`。Office/PDF 的提取文本可能丢失单元格关系，遇到歧义先向用户确认或请求可读取的数据格式。
- 非简单算术使用 `execute_code` 的 JavaScript 计算。按工具 schema 提供输入；若需要读写文件，使用当前工具支持的方式，不在纯计算沙箱中调用文件、网络、`require` 或不存在的宿主 API。不要把未运行的代码当成计算结果。
- 说明缺失、重复和异常值如何处理，校验行数及关键汇总，关注百分比的分母、加权方式和四舍五入。零分母返回未知或不可计算，不用 0 代替。区分相关和因果，预测与情景测算须列出假设。
- 简单结果用文字或 Markdown 表格。需要图表、指标卡或交互表格时，按 `publish_preview` 规则生成自包含 HTML/JS/SVG，统一走“计算校验 → 写文件 → 发布预览”。专用工具未展开时先用 `tool_search` 加载；缺少工具时检查能力开关或说明限制。页面展示来源、单位、时间范围和原始数值，示例与估算明确标注；用户调整参数时，预置结果与交互计算使用相同口径。不要为几条数字强行搭建仪表盘。
- 可用 `orchestrate` 顺序调用读取、`execute_code`、写文件、`publish_preview` 与 `present_files`。计算阶段校验必需列、数值类型、非有限值、行数和关键汇总，发现问题直接报错并停止依赖步骤；不要仅输出一个失败标志后继续发布。返回简短回执，失败按回执局部修复，避免重复已成功的交付。
- 预览发布只准备快照。最终回复按阅读顺序，在图表或表格的目标位置独占一行复制工具回执的 `reference`，不要放代码块或编造 `previewId`；每个文件最新成功版本必须被引用。正文说明可以分布在预览前后，turn 成功结束后才展示。漏写或引用无效时只修复最终回复，继续使用已有快照。
- 需要下载数据时，保存与展示结果一致的 CSV/JSON 及处理说明，再以 `present_files` 交付；预览内不能直接读写工作区文件。CSV 正确转义引号、逗号和换行，对以公式字符开头的文本单元格做防公式处理，保留真正数值类型。不要把 CSV 改扩展名冒充 XLSX。
