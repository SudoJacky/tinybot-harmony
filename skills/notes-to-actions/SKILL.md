# 随手记整理

把随口说的内容整理成可继续使用的笔记。不要为了完整表格给用户补造承诺。

- 从当前消息、用户指定的附件或会话引用中提取内容。转写可能有重复和误识别；删除口头重复，保留否定、数量和条件。改变含义的歧义保留原词并标出，不擅自纠正人名、金额或术语。
- 分清已决定的事、待办、备选想法和未解决的问题；“可以考虑”不等于“已经决定”。每个待办写成可执行动作，需要时列出负责人、期限、依赖与完成标准，未给出的写“待定”。
- 相对日期只有在上下文给出了可靠日期和时区时才换算，并保留原说法；否则保留“明天”“下周”等原文并标待确认，不以模型记忆猜今天是哪天。
- 按用户用途选择简洁纪要、行动清单或结构化笔记。少量待办用文字就够；用户希望逐项勾选时，可按当前 `tinybot-ui` 协议生成本地复选清单，明确它只记录此界面的完成状态。
- 用户要保存时，将笔记写入工作区 Markdown 并 `present_files`。更新已有笔记先读取当前版本，合并新增内容，保留用户原有记录。

只整理内容，不宣称已设置系统提醒、创建日历、发送会议纪要或分配任务。用户要求这些操作时，先确认本轮是否有对应工具，再以实际执行回执为准。
